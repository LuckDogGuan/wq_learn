# 03｜风险中性化与稳健性

## 先解释哪类暴露需要控制

常见判断是单条信号是否被市场、行业、规模或某类股票推动。先看原信号的方向、覆盖及各组贡献，再决定采用表达式内变换、设置层中性化或两者的对照。组内排名、组内标准化和组内去均值改变输出的方式不同。去均值可以用一个小样本手算：原值 2、4、6，组均值 4，调整后为 −2、0、2。这个例子说明计算方式，不代表收益能改善。

| 试验版本 | 保持一致 | 观察 |
|---|---|---|
| 基线 | 字段、Region、Universe、D1、窗口、统计区间 | 年份、覆盖、换手、头部持仓和收益来源 |
| 改一层 | 只改表达式内分组或 Settings 中性化 | 残余暴露、极端值、组大小及稳定性变化 |
| 双层对照 | 保留两个一层对照，再组合 | 是否有独立增益，是否过度压缩信号 |
| 平滑或截断 | 只改 Decay 或 Truncation | 延迟与换手、权重分布、分年得失 |

## 稳健性排查

1. 整体指标很好时，先拆分年份、子池与头部贡献。只在一段行情奏效时查原假设和样本结构。
2. 持仓过于集中时同时看信号值域、组大小、缺失和权重，分清集中出现在输入还是设置层。
3. 参数相邻变化导致结果突变时，查看实际更新频率、运行失败和约束切换，留档原配置。
4. 迁移到新地区或新样本先核对行业体系、覆盖和成本，分别报告原范围和新范围。
