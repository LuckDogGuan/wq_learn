# 35｜Advanced API 与三阶思想培训 Part 2

课程提出两个改进方向。一个方向是找有不同信息的输入字段，另一个方向是把同一类信息放入含义不同的模板。演示内容包括用 API 筛数据、写表达式工厂，以及如何处理回填、重复候选与相关性问题。

## 先判断差异来自哪里

**课堂说法**　讲师用已有 Alpha 数量除以数据字段数量，作为观察某个数据集开发程度的粗指标。课堂讨论多字段时强调解释字段关系，再把组合当成新的基础信号。

![课堂以字段覆盖和 Alpha 数量辅助比较数据集](../画面/35/00-11-50-frame-036.jpg)

*原片 00:11:50 · 课堂以字段覆盖和 Alpha 数量辅助比较数据集*

示意例子中，数据集甲有 600 个 Alpha、30 个字段，比值为 20。数据集乙有 100 个 Alpha、25 个字段，比值为 4。这个数字提示先查乙的字段含义、权限和可用性。若乙只在小范围有数据，仍需比较同一 Region、Universe 内的有效覆盖和迭代价值。

| 变化 | 固定项 | 核查项 |
| --- | --- | --- |
| 改字段 | 同一模板和 Settings | 口径、单位、数据覆盖与信息是否重复 |
| 改模板 | 同一字段和 Settings | 先后次序及信息在各步骤的含义 |
| 改成多字段 | 留一组单字段基线 | 为什么组合、是否同报告期、缺失如何处理 |

## 用工厂保留可核查的输入和输出

**课堂演示**　一个表达式工厂接收字段等变量，输出供回测的完整表达式。双字段回归示例用来解释如何填槽。课堂强调所谓三阶是一种组织思路。可以调整变换顺序，再按假设判断是否有必要保留更多层。

![双字段模板工厂的输入与输出](../画面/35/00-38-50-frame-117.jpg)

*原片 00:38:50 · 双字段模板工厂的输入与输出*

**复习练习**　给每个槽留下输入类型、占位符和窗口的记录。先手工确认一条生成的表达式，与预期的比较对象和方向一致，再挑少数候选回测。对于覆盖率好的字段保留无回填版本，再将回填窗口作为单独改动，用变更前后的覆盖、Sharpe、Turnover 和 PnL 相关性观察是否真有新增信息。工具生成的候选还要审核字段是否存在、算子是否合法和概念是否匹配。

**本项目约束**　用 D1 验证。高重复批次优先缩小搜索范围。各 Region 独立记录。缺少结果或响应异常时，按现行只读对账流程处理。课程讲到的额度、标签和成功率是当期讨论。
