# 36｜Brain Lab 数据探索与 Alpha 策略开发

讲师演示用本地表达式工具把研究假设展开成少量候选，导出带 Settings 的文件，再由模拟器读入执行。课程同时覆盖双重中性化和向量字段，两者用于说明类型和分组如何影响模板。

## 从可解释的想法开始填槽

**课堂演示**　数据字段、时序算子和普通参数可以分别作为变量。选项越多，生成的组合就越多。讲者建议按 Alpha 假设缩小搜索范围，再决定有哪些字段和窗口值得进行对照。

![编辑器分别识别字段、时序算子和窗口槽位](../画面/36/00-07-30-frame-023.jpg)

*原片 00:07:30 · 编辑器分别识别字段、时序算子和窗口槽位*

| 槽位 | 填写前的问题 | 对照方式 |
| --- | --- | --- |
| 数据字段 | 字段衡量什么，是向量还是矩阵，何时更新 | 固定模板，只换一个同类字段 |
| 算子 | 输入输出类型是否匹配，处理的是哪一轴 | 固定字段，替换一个功能可解释的变换 |
| 窗口 | 天数与数据更新频率是否合拍 | 固定表达式结构，测试少量窗口 |
| 分组及 Settings | 想移除哪些暴露，保留哪类信号 | 变更一种分组或中性化配置，与基线比较 |

**复习练习**　如果字段是一组事件观测，先确定每只股票当天该提取哪个向量统计，再把数值接入时序或分组槽。检查首批生成数量、字段类型、算子参数数及最终表达式语法。先跑一小组，记录有效样本、换手和对比结果。

## 双重中性化与可追溯的批量执行

课堂示例同时谈到国家、行业和 Settings 中的风险中性化。对于同一因子，表达式内分组与平台设置需要分别记录。可在同 Region、Universe、D1 的基线里每次变更一个位置，观察暴露、分段 Sharpe 和 Turnover。

00:19:50 的屏幕示例将这条向量管线写成三个可检查的部分。先用聚合槽把向量变成单值，再对聚合结果回填。组合分组键 `group_cartesian_product(country, industry)` 后，分组算子按同国同行业处理，最后才应用时序算子。复现时单独对照行业分组和国家与行业的联合分组，并检查两种分组下的剩余有效覆盖。窗口和字段在画面中是占位符。

![双重中性化模板将多种分组作为参数](../画面/36/00-19-50-frame-060.jpg)

*原片 00:19:50 · 双重中性化模板将多种分组作为参数*

1. 在模板工具中用有明确含义的候选构建表达式和设置，先核对组合数及示例字段。
2. 导出带设置的 JSON，记录版本、候选顺序、生成时间及 D1。
3. 模拟器读入时，核对条数、字段、实际状态与进度位置。
4. 续跑使用同一份文件，记录已核实的任务结果和下一索引。遇进度未明，按项目的只读对账规则执行。
