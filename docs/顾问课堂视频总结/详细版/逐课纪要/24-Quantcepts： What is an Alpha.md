# 24 | Quantcepts — What is an Alpha（定义短课）

> 一天的 Alpha 输出是什么？怎样给股票权重的正负和大小一个合理解释？

| 术语 | 课程中的意思 |
|---|---|
| Universe | 要计算信号的一组股票 |
| Alpha 输出 | 每个日期都有一组与股票对应的数值 |
| 正负号 | 体现持仓的多空方向 |
| 数值大小 | 反映该股票相对于其他股票的权重强弱 |

## 课堂走读与练习

1. 先看股票集合，然后理解每日横截面的信号怎样由数据与公式产生。课程指出应有一条关于未来收益的经济假设。
2. 正例：同一天甲为正、乙为负，先检查这是否符合假设方向，再看同侧股票的权重分布。
3. 反例：把信号数值 0.8 直接写成预测股票上涨 80%。这个数值首先服务于相对配置，预测尺度需要独立定义和验证。

## 检查与回看

- 写出股票池、字段、计算日期、方向和 D1 设置，再核对数值在同一天的截面分布。
- `00:00:03` 定义；`00:00:16` 股票池；`00:00:28` 正负与大小；`00:00:41` 经济假设。
