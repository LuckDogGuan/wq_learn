# 19 | Quantcepts — What is an Alpha（合辑）

> 一条研究假设如何变成每日持仓？用哪些视角判断它有继续研究的价值？

## 先看懂这几个词

| 术语 | 本课的含义 |
|---|---|
| Universe | 某次研究所覆盖的股票集合 |
| Alpha | 根据数据和公式为股票集合生成每天的信号数值 |
| 多空 | 按信号的正负方向配置股票，量级反映相对持仓大小 |
| 市场中性示例 | 讲师用等额多空说明如何比较相对收益 |
| 子股票池 | 原股票池内更小的一组股票，可用来检查结果是否依赖较边缘的标的 |

## 课堂走读

1. 从经济假设出发。课程先定义 Alpha，再指出表达式要体现关于股票未来表现的判断。假设写成一句话时应包含信息、预测方向和比较对象。
2. 按交易日生成横截面。每只股票每天有对应数值，课程用符号表示持仓方向，以大小表示相对权重。举例，某天甲、乙分别为正与负，说明两者所在侧不同。数值的绝对值本身无需解释成未来涨跌百分比。

*原片 00:00:10 · Quantcepts 对 Alpha 的定义和示意曲线*

3. 用等额多空建立相对收益直觉。课程示意多头和空头本金相等。若多头股票上涨 2%，空头股票上涨 1%，忽略成本时仍可获得两者的差额。实际收益还取决于持仓构造、换手和费用，用结果里的多空分布补全判断。
4. 检查收益、风险、实施与重复程度。收益波动可看 Sharpe，交易频繁程度看换手，损失路径看回撤，信号重复程度看相关性，持仓分布看权重集中度。子池表现有助于确认信号在主要可交易股票中的稳定性。

![子股票池的表现需要单独检查](../画面/19/00-03-30-frame-011.jpg)

*原片 00:03:30 · 子股票池的表现需要单独检查*

5. 合辑用两类数据落地。量价例观察从开盘到收盘的变化，提出短期反转。基本面例将经营现金流与市值相除，提出市场估值与经营现金创造能力可能错配。后段的动量、季节性和领先滞后说明相同框架也适用于其他经济机制。

## 研究练习

| 问题 | 做法 | 检查 |
|---|---|---|
| 短期超跌收回吗 | 在同一股票池用可得的开收盘数据构建反转假设，保留原方向做对照 | 核查信号方向、换手和分期表现 |
| 高经营现金流收益率有溢价吗 | 核实经营现金流口径、市值时点和币种，再检查高比值组 | 同时看有效覆盖、行业集中、缺失和负现金流组 |
| 好结果是否稳定 | 将可比设置固定，记录整体和子池结果并看持仓分布 | 避免只根据单个指标或单段样本决定保留 |
