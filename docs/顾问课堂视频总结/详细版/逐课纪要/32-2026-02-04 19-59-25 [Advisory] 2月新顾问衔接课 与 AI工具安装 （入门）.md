# 32｜2 月新顾问衔接课与 AI 工具安装

课程前半段介绍顾问论坛中的工具、环境及安装路径，后半段讨论中性化方式、不同相关性池和多维分散，最后回答环境排错及研究工具分工的问题。

## 工具先分层确认，再开始研究

**课堂说法**　当时的工具安装涉及运行环境、客户端、模型服务和认证。论坛里的安装说明与工具版本相关。找灵感入口以数据集为输入，给出表达式或想法。对话入口可继续解释、修改和检查候选。



**复习练习**　当命令行找不到模块时，先用安装时选定的 Python 查看 `python -m pip --version` 和软件版本，再做一次最小导入，区分解释器位置、包安装、客户端连接这几个环节。到研究阶段先记录 Dataset、字段范围和研究问题，将模型生成的字段、算子与平台说明对照。挑一条能解释的候选做小规模 D1 检验，让回测实际响应决定下一步。

## 中性化从希望保留的信号出发

**课堂说法**　中性化有传统分组方式，也有不同风险暴露的处理方式。讲者用快慢信号说明，设置会改变因子最终保留的共同暴露。对照时记录到底希望移除行业、风格，还是其他共同成分。

**复习练习**　假设研究的是行业内相对盈利能力。先固定表达式、Region、Universe、D1 和 Decay，做一组行业或更细分组的对照。每次只改一项中性化，记录分段 Sharpe、Turnover、行业集中程度和与既有候选的 PnL 相关性。若换设置后表现锐减，回看原信号主要来自行业差异还是行业内差异。

## 分散性与相关性检查

| 研究环节 | 可记录信息 | 对照方式 |
| --- | --- | --- |
| 候选归档 | Region、Universe、数据集、字段、模板、风格 | 在同 Region 比较；跨 Region 另开记录 |
| 结果对账 | Sharpe、Turnover、分段收益、已完成状态 | 保留相同 Settings 下的基线 |
| 相关性解释 | 相比的是自己的历史候选、其他顾问还是某类池 | 分开记检查类型、样本区间和真实结果 |
