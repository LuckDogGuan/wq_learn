## 字段探查从定义走到可检验的观察

定性层回答字段代表什么、谁产生以及更新节奏如何。定量层检查有效股票数、数值尺度、符号、极端值和分位分布。课堂从是否进入某一数值范围的示例讲到十分位、百分位。筛选条件会改变可见样本，记录筛选前后的覆盖比只看均值更有用。

**操作顺序**

1. 记录 Data Field、单位、可访问范围和更新频率。先查同一批股票的原字段。
2. 分开统计有值、缺失、零值、负值和极端值。若大部分股票落在很窄的区间，再用分位检查是否应改用相对值或排序。
3. 记录每项运算改变前后的分布。检测字段原貌时区分原值和模拟设定带来的变化。复现研究保持 D1。
4. 若仿照课堂做一次字段替换，保留原表达式和原设置，比较覆盖及收益差异，再决定后续是否扩大。

## 算子在比较什么

| 研究关系 | 课堂例子 | 实验对照 |
| --- | --- | --- |
| 同一个交易日比较股票 | rank 进行横截面排序 | 看排名前后分布、并列值、有效股票数 |
| 同一只股票和它的过去比 | ts_delta、ts_rank | 明确交易日窗口，记录短历史和缺失影响 |
| 同一口径下两量的比例关系 | 基本面量相对市值 | 确认分母口径、零值和公司尺度 |
| 两个量在窗口内一起变化 | 用时序相关查看共同变化 | 保持窗口、样本和单位明晰，与简单基线分开比较 |

套模板前先判断字段语义。课堂指出，比例关系适合部分基本面问题，共同变化则可能更适合另一个数据集。对两种构造应写不同的研究假设，再观察它们是否给出不同的覆盖、持仓和 PnL。

## 字段查询无结果时怎么检查

| 现象 | 先看什么 | 再做什么 |
| --- | --- | --- |
| 看得到数据集，表达式找不到字段 | Dataset ID 与具体 Data Field 的区别 | 读字段清单并核对权限 |
| 在另一个地区能找到，本次查不到 | Region、Universe、Delay 是否一致 | 在当前 D1 环境重新查询，保存查询范围 |
| 换字段后结果几乎相同 | 字段是否近义、分组后权重是否重合 | 对照覆盖与相关性，归并重复研究路径 |
| AI 推荐的字段没有文档支持 | 是否有原始字段 ID 和数据定义 | 先核对字段，再决定是否生成候选 |

查询与模拟是不同动作。课堂 API 答疑用于定位字段来源，本项目对模拟异常按仓库对账约束。行政答疑和当期作业按录制背景理解。
