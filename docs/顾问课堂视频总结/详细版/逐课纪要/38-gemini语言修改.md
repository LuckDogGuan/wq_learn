# 38｜修改 Gemini 或 Google 账号首选界面的语言

录屏从 Gmail 头像进入 Google 账号管理，在语言项添加简体中文并调整首选顺序。看完后应能区分账号首选语言、当前应用实际显示的语言，以及会话输入语言。

## 操作路径

1. 从 Gmail 头像打开本人 Google 账号的管理页面，在个人信息中找到语言设置。
2. 添加简体中文，确认语言名称和区域，再在页面中调整为首选。
3. 刷新当前应用，查看页面标题、菜单和按钮是否使用目标语言。打开其他产品时，确认当前选中的确是本次修改的账号。
4. 如果界面文字仍未变化，先检查产品自身的显示语言配置。对话语言可用一条普通中文消息单独核对。

| 可观察现象 | 核查点 | 可留存的记录 |
| --- | --- | --- |
| 账号语言已更新，Gmail 也已刷新 | 当前账号与设置账号一致 | 修改日期、账号首选语言状态 |
| Gmail 与 Gemini 显示不同 | 两个产品各自的语言入口 | 分别记录实际显示语言 |
| 界面显示英语但能中文对话 | 用普通中文提示确认 | 对话可用性和界面状态分开记 |

表 1 用于回看设置后确认结果。录屏为个人账号页面，纪要保留菜单关系和状态即可。
