# 23 | Quantcepts — Types of Alpha Ideas

> 看到一段价格变化、供需关系或日历规律时，怎样把想法变成有对照的研究问题？

## 课堂给出的假设类型

| 类型 | 想检验的现象 | 练习中优先排查 |
|---|---|---|
| 反转 | 此前较弱的股票有回补 | 先写明前后观察窗口，给延续方向留对照 |
| 动量 | 此前表现较强的方向可能延续 | 固定形成期、观察期和股票池 |
| 季节性 | 按相同日历位置可能重复出现 | 多年重验，查看事件和行业是否解释现象 |
| 领先滞后 | 一类股票或信息变化先于另一类 | 核对事件时间、成分和映射关系 |
| 指数再平衡 | 成分或权重调整改变潜在需求 | 分开记录公告日和生效日，核对可得时间 |

## 怎样把一个想法写成试验

1. 用一句话固定机制。正例：供应商的信息在公开后，若与下游股票的业务足够相关，则下游同行未来表现可能变化。先列出关系映射和公开时间，再比较有、无映射的股票。
2. 反例是从多年结果中挑出表现最好的一个月份，然后在同一段区间宣布它存在季节性。先记录筛选范围和日期，再用留出区间检查；弱的年份也应保留。
3. 课堂末尾的再平衡提示关注成分或权重变化。研究里分开公告、生效和实际可用日期，在 D1 下比较有事件和没事件时的变化。
