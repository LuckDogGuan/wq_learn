# 46｜AI 赋能量化下午理论课：从原值诊断到研究队列

**这节课解决的问题**：一个字段在业务上有意义，怎样看出它能不能做研究，并把有证据的设想交给批量回测。课程用机构持仓及事件类信号举例，先做数据体检，再讨论分组、非线性残差和生成队列。

## 第一步：确认对象、单位和信息时点

机构持仓的列可能是股数、比例或金额。要先弄清每列测量什么、数据截止日和可观测日是否相同。派生比率前核对分母能否作为业务上相符的规模量。对事件字段还要区分事件发生、公开和平台可见三个时点。当前复现全程 D1。

| 数据检查 | 为什么做 | 需要保留 |
| --- | --- | --- |
| 全量分布与分位视图 | 极端值会让主体看不清 | 完整范围、主体分位、缺失和零值比例 |
| 观察最高持仓公司 | 某少数证券可能在很多天主导高分位 | 出现频次、日期、行业和头部份额 |
| 派生比率与两条原列并排 | 分母过小或范围不匹配会造成人为尖峰 | 分子、分母、交集样本及派生量的分布 |
| 公告与有效时间 | 财务期末日期可能早于信号真实可观测时间 | 事件字段含义和数据可得日 |

## 第二步：把基础量与后处理分开

第一轮只测试可解释的原列或派生量，固定地区、样本和设置。若整体截面弱，选择一个业务上合理的方向：看它相对自身历史是否改变，或者在同组公司里是否有特殊位置。两个方向输出含义不同，应各与基础量对照。课程也提到非线性残差，复现前需写清被解释量、控制量和残差代表什么，再检查覆盖、换手和分年表现。

## 第三步：让 AI 生成可核验的候选

1. 输入数据字典后先产出类别与字段索引，核对类别有无漏项和重叠。
2. 每条假设写明方向、被比较对象、影响时点、单位与所用字段。课堂买卖方向混淆的例子适合当检查题，人工先问指标变大时是哪一边发生变化。
3. 同类字段扩展时保留原假设和替换理由，变更字段后重新检查可用范围。每条候选记录表达式与设置的指纹。
4. 候选生产和回测消费分开。记录优先级、任务和实际返回状态。缺 ID、超时和 429 等按项目规定冷却只读对账一次。
