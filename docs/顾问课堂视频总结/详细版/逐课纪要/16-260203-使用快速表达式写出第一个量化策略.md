# 使用快速表达式写出第一个量化策略

> 课程编号 16。原片为 260203-使用快速表达式写出第一个量化策略。重点是字段探查、比较维度和小批次复现。

## 问题

从 Data Explorer 选到一个字段后，怎样判断它的类型、数值和更新特点适不适合第一条表达式？

## 术语速查

| 概念 | 核对重点 |
| --- | --- |
| Dataset | 数据集 ID、地区和覆盖 |
| Data Field | 具体字段 ID、单位、类型、更新频率 |
| rank | 同一日横向比较 |
| ts_rank | 某只股票当前数值在指定历史窗口中的位置 |
| group_rank / group_zscore | 将横向比较范围缩到组内，分别关注顺序或标准分 |
| Simulation Settings | 记录 Region、Universe、Delay 和其他影响结果的设置 |

## 课堂走读

1. **查语义和搜索范围。** 先确认数据集 ID、实际字段名和字段描述。取字段列表时同时核对 Region、Universe、Delay。录屏在 00:18:41 指出数据集 ID，在 00:54:53 提醒搜索范围输错会找不到数据。FND6 是课堂示范的数据集名，不是一个表达式字段。

![数据集描述和相关字段的查看入口](../画面/16/00-18-50-frame-057.jpg)

*原片 00:18:50 · 数据集描述和相关字段的查看入口*

2. **查样例分布。** 像课堂的 RD510 探查那样，先看原值和有效样本，再看极值、直方图、零值和缺失的比例。发现长尾时先确认量纲。若换地区或字段，重新查覆盖和更新日期。见 00:26:54–00:29:18。

![课堂按数值区间探查字段分布](../画面/16/00-29-10-frame-088.jpg)

*原片 00:29:10 · 课堂按数值区间探查字段分布*

3. **写一个可归因的基线。** 确定你要比较同一日的公司、同一公司的历史，还是同一组里的公司。分组聚合得到组统计量，组内排序得到每只股票的相对位置，二者回答不同问题。见 00:34:18、00:38:27 和 00:43:00。

![横截面 Rank 的排序与缩放示意](../画面/16/00-38-30-frame-116.jpg)

*原片 00:38:30 · 横截面 Rank 的排序与缩放示意*

4. **再做字段替换和批次。** 保留第一条跑通的表达式。在同一假设和设置下，单次只换一个口径相近的字段，记录表现和有效覆盖。向量字段先查维度及聚合含义，更新较慢的字段还要观察重复值和公布时点。见 00:45:50、01:01:40 和 01:07:16。

## 研究建议与排错

| 症状 | 优先核对 | 下一份可比较记录 |
| --- | --- | --- |
| 搜不到学过的数据集 | 地区、D1、Universe 与实际权限 | 同一配置下重新列出可用字段 |
| 分布只有少量有效点 | 日期范围、缺失、量纲和更新频率 | 保留覆盖统计和异常日 |
| 同一假设换字段表现差异大 | 定义、方向、单位和更新日是否对齐 | 固定设置保存两条实际结果 |
| API 响应缺少 Location | 请求指纹及已知任务 ID | 标记待对账，冷却后只读查一次 |

## 当前项目约束

所有模拟使用 Delay=1。课堂提到的条件开关是录屏背景，实际表达式服从项目算子限制。429、5xx、超时或缺子 ID 按项目对账规则记录，提交由用户手工决定。
