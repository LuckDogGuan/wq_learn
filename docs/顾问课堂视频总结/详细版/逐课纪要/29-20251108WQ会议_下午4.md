# 29｜2025-11-08 WQ 会议下午第四段

这段答疑主要讲两件事。第一件事是怎样把读论文变成可回测的 Alpha 假设，第二件事是怎样定位字段覆盖很高、回测结果却全零的问题。两件事都需要先确定每一步的输入和输出。

## 从论文到可检验的候选

**课堂说法**　讲师建议先找到两三篇自己能做出来的论文。能复现意味着看懂论文测量了什么、使用什么数据，以及各项计算的顺序，再请工具辅助生成与原始假设有关的几种候选。

**复习练习**　先建一张三列表，逐句记录论文定义、可用数据字段、对应的计算。假如论文研究的是预测修正，先核对预估的报告期、数据发布时间和数值口径，再尝试用少数候选表达同一假设。用同一 Region、Universe、D1 和区间比较原始版本与一种变体。分别记录信号覆盖、符号、Sharpe 和 Turnover。字段无法映射时记录缺失条件，保留可检验的最小基线。

## 覆盖率高但结果全零

**课堂问答**　有人问为何数据覆盖为 100%，回测却为零。可辨认的录音能够确认问题本身，具体字段和成因待核对。



| 检查层 | 操作 | 观察 |
| --- | --- | --- |
| 字段输入 | 同一期、同一股票池取少量日期和标的 | 非空的值是否有变化，是否实际全零 |
| 表达式 | 用最少的合法变换跑对照，逐步恢复算子 | 从哪一步开始非零比例下降 |
| 模拟输出 | 保留相同设置并查看状态、持仓和收益 | 结果确为零，还是回测尚未完成或响应缺失 |

**本项目约束**　所有例子只用于设计 D1 对照。保留原始请求和实际响应。遇状态未明，按项目的只读对账流程处理。
