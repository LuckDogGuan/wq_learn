## 课程概览

这节课把 Alpha 从金融名词落到 BRAIN 的一个实际流程。提出经济假设，确定数据字段与股票池，把想法变成每日股票得分，读取历史回测，最后用 API 追踪一次模拟。课堂案例以公司的财务杠杆说明信号的方向取决于研究假设及适用市场。

## 一条 Alpha 在研究流水线中的位置

讲师用 Alpha Factory 区分数据、研究、组合和执行。研究员使用已经整理过的数据字段表达假设，组合环节再比较许多信号的共同表现。传统金融语境里的 Alpha 可指超额收益，课程中写出来并参与模拟的 Alpha 则是一套产生股票得分的规则。得分随日期变化，同一日也因股票而异。

课堂把动量和反转并列。动量假设过去的变动有延续性，反转假设过去偏离会回归。二者需要明确被比较的量、观察窗口和预期发生的周期。同一财务杠杆指标也可能对应不同经济直觉。一种解释强调借款用于有盈利机会的扩张，另一种强调财务脆弱性。先记录两种解释，再看同一地区的正反两向结果。

## 基本面信号的课堂示例

讲师以美国 TOP3000 为背景，用资产和负债的相对关系形成公司分数，再比较两个方向的收益曲线。00:39:00 的口述提到资产除以负债，随后又把比值越高解释成相对负债越多。分子分母应以原式和字段定义确认。这里保留研究问题和比较方式，实例的精确公式列为待核对。

*原片 00:39:50 · 课堂表达式与累计表现面板*

**研究建议**

1. 为杠杆构造记录分子与分母的定义、币种、财报发布时点和覆盖。列出零分母、缺失与极端值会剩多少可比股票。
2. 固定 Region、Universe、Delay 和其他设置。分别看原方向及用 reverse 得到的对照方向，同一轮只比较方向。跨地区继续单独记账。
3. 读分年曲线时同时看 Sharpe、Turnover、Fitness 和 Return。再查负收益集中在哪一年、是否来自股票数量降低或成本上升，避免用单个终点概括整条曲线。
4. 只有方向和经济解释在相邻区间一致、且覆盖能支持组合时，再考虑调整信号。课堂中的美国样本只作为案例。

## 从接口结果回查原始请求

课堂演示中，请求带表达式和 Simulation Settings，Location 指向模拟进度，取到 Alpha ID 后可回查结果。排队状态和缺失 Location 需要分开记录。对研究者而言，每次模拟应保留表达式、设置、请求时间及已有响应，避免仅凭收益截图复盘。

**当前项目约束**

研究固定 Delay=1。对 429、5xx、超时或缺子 ID 记录指纹与状态，冷却后只读对账一次。任何回测、标签或提交动作以仓库规则为准。本纪要仅解释课堂方法。
