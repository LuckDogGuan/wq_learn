## 课程概览

本课介绍设置层 Decay 和 Vector 类型，后半讨论样本内外、相关性及交易成本。它提供了一条可复验的顺序，先解释原始信号，再了解处理后的变化，并用样本、参数和相似性检验它是否可靠。

## Decay 改善平滑度时也会改变响应

讲师用 Decay=4 的示意和等权平均对比，解释加权平滑会给较近的信号更大权重。目标通常是减小每日信号跳动，改善换手和执行成本。更长的衰减也可能磨掉短期信息，应与衰减关闭的原方向、附近较短窗口及较长窗口对比。

**研究建议**

- 固定表达式与 Region/Universe/Delay，比较一条不平滑的基线和一小组相邻设置。并列记录 Sharpe、换手、Margin、分年收益与回撤。
- 若换手下降而收益在特定年度同步缩减，进一步查对应时期的信号更新频率。考察近期信息是否被稀释，避免仅按某次换手改善选择参数。
- 课程示意只解释平滑尺度。复验仍应遵守 D1。设置层 Decay 和表达式内的时序处理分开记录。

## Vector 字段先明确一行要代表什么

同一证券同一日期的 Vector 字段可包含多条观测。课堂以多项文本观测示意，多项观测的平均值可表达整体倾向，极值可表达最强事件，极值与均值间的差可表达尾部是否突出。先按目标聚合成标量，再接普通的截面或时序算子。聚合前后记录覆盖、有效观测数与极值缺失。

## 样本内、样本外与相关性

讲师把稳健性落在两类观察。样本内可用小幅修改设置、窗口或分组看方向和曲线是否稳定。留出的样本外用来检验信号能不能延续。持续按已经看到的结果调参会改变检验角色，记录首次确定的参数与切分时间更便于复盘。

| 观察现象 | 下一步研究问题 |
| --- | --- |
| 一点参数变化使结果掉得很快 | 查收益是否集中在少数年份、几只股票或一次事件 |
| 两条表达式变了字段名却高度相关 | 查语义、样本、持仓及共同类型暴露 |
| Sharpe 较高但换手偏高 | 比较成本、Margin、异常交易日和更稳定设置 |
| 统计套利示意有短期回归收益 | 写出相对关系、回归周期与失效条件，保留样本外检验 |
