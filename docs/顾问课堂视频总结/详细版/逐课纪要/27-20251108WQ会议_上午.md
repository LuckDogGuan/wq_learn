# 27 | 2025 年 11 月 8 日 WorldQuant 会议上午场

> 把研究资料变成候选并运行时，怎样确认工具、保护自建模板和控制无意义的批量回测？

## 术语与研究材料

| 名称 | 用途 | 应保存的证据 |
|---|---|---|
| MCP | 让客户端调用研究工具的连接方式 | 本机解释器和工作目录、连接是否加载 |
| 用户模板 | 使用者自建的表达式结构和占位参数 | 导出文件、版本和少量示例 |
| Settings | 实际下发给模拟器的参数 | 地区、Universe、D1、中性化及区间 |
| 候选文件 | 计划模拟的表达式与参数集合 | 生成依据、筛选条件、文件版本和任务指纹 |

## 课堂走读

1. **定位工具配置。** 上午前段排查客户端路径。先根据本机情况找实际可运行的 Python，再核对 MCP 配置的命令及对应文件路径。客户端加载后可发起已经熟悉的只读查询，检查连接确实可用。课上展示了复制的路径与本机路径不一致的问题。
2. **为 AI 提供可核对资料。** 历史对话和论坛帖子可补背景。写出研究问题和来源范围，让工具标记它查到的帖子、字段解释和它自己的推测。手头结果与表述不一致时回看原文和平台字段说明。



3. **为模板迁移留有备份。** 更新或换客户端前导出自建模板，留下文件版本；尝试导入并打开一条已有模板，核对字段占位、Settings 和候选数。模板来自同伴时只使用允许分享的版本。



4. **根据假设缩小候选。** 讲师讨论全选组合常产生大量近似 Alpha，可能过拟合或共同暴露相同的风险。以反转模板为例，先选两三个有含义的回看窗口，在同一数据集按覆盖过滤明显不合适的字段，先跑基线和少数变化。记录候选生成数、去重数、可观测结果数和退出理由。

## 排错与对照

| 现象 | 先查什么 | 怎么留痕 |
|---|---|---|
| 客户端显示工具无响应 | Python 是否为实际解释器，命令与工作目录是否对应 | 保存脱敏配置路径，只读验证连接 |
| 升级后看不到旧模板 | 是否有用户模板导出与版本记录 | 导入旧版本后复现一小批，比较项数与设置 |
| 大批候选外观不同、表现相近 | 字段关系、假设、归一化和分期表现 | 逐批留覆盖、换手、相关性及保留理由 |
| 回测返回不完整 | 任务指纹与已有结果 ID | 遇 429、5xx、超时或缺子 ID，按项目规则冷却后只读对账一次 |
