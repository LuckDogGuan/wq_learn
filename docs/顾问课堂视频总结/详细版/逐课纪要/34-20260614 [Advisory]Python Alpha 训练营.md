## 术语和输出速查

| 项目 | 课堂中的含义 | 复现前要确认 |
| --- | --- | --- |
| Feature | 模型识别个股差异的输入，可以源自字段、派生量或已有分数 | 观测日、发布时间、缺失值和单位 |

| Store | 按日调用之间保存的状态 | 需要保存哪些权重、偏置和中间值 |

## 按日复现一个可对照的模型

**课堂演示**　回测引擎每天调用 Alpha 函数。训练样例先形成特征和收益，再用模型输出估计股票分数。课程先介绍收益预测误差，也演示把持仓、实际收益和组合 PnL 连接起来，以负 Sharpe 为一个训练目标。用中性化和归一化时要观察模型输出与实际持仓发生了什么变化。

**复习练习**　先冻结一条简单可解释的基线和全部 D1 Settings。把输入拆成三个表，分别检查证券索引、日期以及有效样本，再按日期切训练、验证和测试。每天的特征仅使用当时可获得的信息，未来收益放在评估或训练标签一侧。若模型需在线更新，记录更新前应持有的模型版本。对照实验按「同样的数据和设置、仅更换评分模型」进行。

| 阶段 | 动作 | 重点记录 |
| --- | --- | --- |
| 最小实现 | 首先产生一日一只股票的有效分数，确认持仓向量正确对齐 | 非空比例、股票池成员资格、分数分布 |
| 训练与验证 | 用时间上靠前的样本拟合，按验证区间比较控制组 | 训练与验证 Sharpe 的变化，观察早停点 |
| 推理和回测 | 保存模型状态并读取当日特征，只执行需要的前向运算 | 分段 Sharpe、Turnover、缺失及运行时间 |
| 异常排查 | 检查波动率分母、NaN、无穷值以及梯度变化 | 异常何时开始、变化的样本或步骤 |
