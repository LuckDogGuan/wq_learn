# 44｜AI 赋能量化上午实操课 1：从数据集到首批模板

**这节课解决的问题**：拿到一个分析师预期数据集后，怎样用少量回测定位值得继续验证的模板。课程演示涵盖字段搜索、矩阵与向量选择、展开参数、导出批次和查看断点。

## 先确定比较对象

讲师以 Smart Estimates 为例，把通用模板和数据专用模板放在同一条探索链。通用模板通过历史排序、变化和分组处理测试字段有没有初步信息。专用模板先问「加权预期与一致预期差异」代表什么，再配对相同指标和财报期的字段。

| 项目 | 开始前确认 | 记录到批次 |
| --- | --- | --- |
| 数据范围 | Data Explorer 中的 Region、Universe、D1 和数据集权限 | 设置与导出日期 |
| 字段配对 | 预期指标、财报期、单位、发布时间一致 | 字段 ID、定义和类型 |
| 矩阵或向量 | 本次演示模板没有向量聚合，使用 matrix | 向量变体需要独立定义聚合 |
| 同名占位符 | 两处使用同名时应绑定同一字段 | 导出前抽查展开的表达式 |

## 按顺序展开和回测

1. 用一个数据集做首轮，保留同一字段的简单基线，再增加一组有金融解释的预期差候选。在同一 Region、Universe、D1 下比较。
2. 先生成少量表达式检查占位符位置。若希望把同一输入在两处复用，就用同名占位符。若要比较两类输入，就明确它们各自的字段候选集合。
3. 从通过类型和设置检查的清单里抽样。课堂随机抽 500 条是演示规模。按当前预算决定样本数，并保存抽样种子、原始清单顺序、设置和生成日期。
4. 导出带 Settings 的批次，把日志和表达式顺序绑定。续跑前用指纹与已观测结果找剩余项。原清单顺序一旦改变，旧的序号失去定位作用。

## 用结果决定下一轮

| 现象 | 先查哪里 | 下一步 |
| --- | --- | --- |
| 展开很多条但差异很小 | 同名变量、字段别名、参数重复 | 先去重，再补一个独立假设 |
| 通用和专用都表现弱 | 字段意义、覆盖、数据发布时间 | 缩小到可解释的一支，重新问数据是否表达了假设 |
| 专用模板整体更稳 | 分年、换手、覆盖变化 | 固定字段，逐项比较平滑和分组设置 |
| 日志有断点或缺结果 | 批次指纹与实际取得的结果 | 按项目规定对账，保留未观测状态 |
