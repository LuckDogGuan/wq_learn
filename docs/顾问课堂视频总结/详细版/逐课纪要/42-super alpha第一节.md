# 42｜Super Alpha 第一节：Selection 入门

本课演示先定义可入池的底层 Alpha，再确定排名方向和入池上限。课程用 Turnover、字段数、数据集数和 Universe 等属性组织候选，并解释 Selection Handling 引起的差异。

## 先分清范围、评分和数量

| 名称 | 课堂用法 | 需要观察 |
| --- | --- | --- |
| 筛选条件 | 确定哪些底层 Alpha 有资格参与 | Region、Universe、权限、属性是否与假设相符 |
| Selection Handling | 判断筛选表达式的返回值是否允许对象入池 | 零、负数、正值分别如何处理 |
| Selection 排序 | 给符合范围的 Alpha 决定先后 | 高分是否排在前面、并列和缺失如何分配 |
| Selection Limit | 限制可选数量 | 有效池小于上限时实际入池多少 |

![Selection Handling 区别 Positive、Non-Zero 与 Non-NaN](../画面/42/00-22-50-frame-069.jpg)

*原片 00:22:50 · Selection Handling 区别 Positive、Non-Zero 与 Non-NaN*

**课堂说法**　如果排序值可为负数，Non-zero 与 Positive 的过滤标准会得到不同对象。课堂用反向排序产生的负数说明，换 Handling 前需看到实际返回值与入池列表。

**复习练习**　设三个候选分数分别为 0.3、0、负 0.2。示意中 Non-zero 会考虑前后两个候选，Positive 只考虑 0.3 的候选。实际实验需要核对负号表示信号方向、排序转换还是不合格标记。若实际结果空池，就从原始分数和分组权限查起，再核对限额与缺失值。

## 如何比较不同 Selection

1. 写明组合想补哪种特征。例如要观察和惯常低换手基本面不同的一组信号，先定义一组可比较属性。
2. 保持同一 Region、Universe 和 D1。先固定筛选范围，用同一个简单组合方式导出基线和排序变化后的入池列表。
3. 比较入池数量、Turnover 分布、数据集集中程度、PnL 相关性和组合收益。分别记录本次动到的是过滤范围、排序方向还是入池限额。
4. 调整前后保留实际被选中的候选 ID。若看不出改进，先查改动后的池是否真的发生变化。
