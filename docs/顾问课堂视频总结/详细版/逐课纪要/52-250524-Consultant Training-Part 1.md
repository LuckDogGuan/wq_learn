## 两个常见步骤各自改变什么

先量化每只证券的指标相对自身历史的位置或变化，再与同组证券比较。前一步的关键是窗内有没有真实数据变化。后一步的关键是分组是否带来了可比对象。以盈利与规模为例，两列同单位时可构造可比比率。先检查原始盈利、规模及两列交集，防止分母过小把离群值放大。

## 走读：批量配对实际值和预期值

1. 在已选 Region、Universe 和 D1 下查询数据描述，用字段后缀或元信息整理候选。抽查后缀究竟是报告期、统计口径还是合约特征。
2. 先匹配同一指标、报告期和单位。分别记录实际、共识、最高和最低预估，保留能够证明它们在指定日期可用的元数据。
3. 只生成通过配对检查的变体。保存各类型未匹配原因，杜绝把相似命名当作经济含义相同。
4. 先用简单变换做基线，确认收益方向、覆盖和时序稳定性，再围绕分组和窗口做局部对照。

## 排错速查

| 现象 | 先检查 |
| --- | --- |
| 两个窗口的结果相同 | 低频列在两段窗口中的实际更新次数 |
| 变体过多又接近 | 候选是否使用同一字段别名或同类指标 |
| 各地区差异明显 | 权限、有效覆盖和统计区间是否一致 |
| 字段返回向量 | 明确单条证券的观测维度及选择聚合方式 |
