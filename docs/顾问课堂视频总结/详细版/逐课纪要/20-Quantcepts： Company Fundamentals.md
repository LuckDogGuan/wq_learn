# 20 | Quantcepts — Company Fundamentals

> 公司财报能提供哪些信息？经营现金流除以市值为什么能提出相对估值假设？

## 术语速查

| 报表或指标 | 看什么 |
|---|---|
| 资产负债表 | 某一时点的资产、负债和权益 |
| 利润表 | 一段期间的经营成果 |
| 现金流量表 | 一段期间的现金流入和流出 |
| 经营现金流 / 市值 | 用市场对权益的定价比较经营活动产生的现金规模 |

## 课堂走读与练习

1. 讲师先区分三张财报，再以现金流量表里的经营现金流为例。它描述经营活动现金创造能力，分母用市值，把不同规模公司的数值放到相对可比的尺度。
2. 课程提出高比值可能对应相对低估。假设两家公司采用同币种和同期间，甲经营现金流 8、市值 100，乙为 4、市值 100，甲的比值较高。这提供一个横截面排序方向，未来结果需要模拟验证。
3. 反例是拿甲的单季度现金流和乙的全年现金流直接排序，或在财报尚未发布的日期就把新数据用于历史模拟。比值看似合理，比较基础已经改变。

## 检查清单

- 核对现金流口径、报告周期、公开可得日、市值时点和币种。
- 分开记录有效覆盖、分母异常、负现金流与缺失值。初步研究固定股票池和 D1 设置，比较高低分组及行业集中度。
- 短片给出的是研究假设。行业适用性和分组处理由独立试验确认。
