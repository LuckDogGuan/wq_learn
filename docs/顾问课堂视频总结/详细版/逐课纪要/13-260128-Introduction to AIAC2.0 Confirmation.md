## 会议概览

说明会讲录制时的 AIAC 2.0 资格与归档要求，再通过 Notebook 说明怎样把 ACE 返回的算子、数据集和字段提供给 LLM，让输出有可核对的结构。适合复用的是输入来源、输出结构、单变量试验和样本外检查。

| 课堂元素 | 作用 | 如何复核 |
| --- | --- | --- |
| ACE 数据 | 提供实际可选的 Operator 和 Data Field | 核对返回所对应的 Region、Universe、D1 与权限 |
| 经济假设 | 约束模型只表达能解释的预测 | 记录预期方向、事件时点和失败条件 |
| Pydantic | 统一候选对象的结构 | 校验表达式、字段、算子与解释逐项匹配 |
| Test Period | 给结果留出独立观察期 | 保留首次切分、同设置基线和留样结果 |
| Alpha JSON | 记录课程示例中的结构化字段 | 对照当期模板字段名和真实来源 |

## 按 Notebook 走读

1. 从允许的输入开始。课堂通过 ACE 拉取 Operator 及 Data Field ID，再选相关的数据集说明。将字段语义、可用范围和研究假设一起交给 LLM。
2. 要求候选按固定结构返回。示例把表达式、英文解释、用到的字段和算子放在同一个对象里。验证结构后还要核对账号能否访问字段、实际式子是否与解释一致。
3. 先固定假设改一个变量。讲师用 model 110 数据集示意，也提出保持假设不变、只改 Dataset ID 以观察候选差异。若数据原本不支持该经济含义，在生成前先淘汰。
4. 对通过字段和算子检查的少量候选做同设置对照。记录回测状态、覆盖、Sharpe、换手与相关性。将观察结果交给模型时，指明哪项改变造成了变化以及仍需保留的约束。
5. 为生成实验留出独立测试期。课上的样本外评分提醒说明高 IS 表现不是充分证据，复盘时把改动前后的 IS 和 OS 数据都留在同一个记录中。

## 常见问题与核查清单

| 问题 | 处理 |
| --- | --- |
| 字段或算子无法查询 | 检查环境设置和实际权限，保留查询来源，替换后再验语义 |
| JSON 结构通过，表达式解释与结果对不上 | 对照具体字段 ID、方向和实际设置，保留失败原因 |
| 不同数据集候选几乎相同 | 比较字段定义、覆盖、持仓和相关性，先定位同一信号来源 |
| 结果集中在训练期 | 核对 Test Period 是否独立，分开报告 IS 与 OS |
| 按竞赛说明回找材料 | 区分历史资格、实际模型记录、Notebook 模板和展示要求，查当前规则 |
