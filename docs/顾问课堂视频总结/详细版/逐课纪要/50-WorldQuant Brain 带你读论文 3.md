## 现金研究先拆开定义和实现

| 对照项 | 论文记录 | 平台实现前核对 |
| --- | --- | --- |
| 现金与现金流 | 指标是存量、流量或未观测的收益 | Cash 与 Cash Flow 的单位、作用、财政期 |
| 规模与回报代理 | 归一化和控制变量的口径 | 市值和收益字段的更新、单位与共同覆盖 |
| 估计窗口 | 控制项、训练窗口与构造频率 | 年频或季频现金列在短窗口里是否有信息更新 |
| 组合口径 | 原论文可采用单边持有 | 平台多空样本和分组边界，分别留档 |

## 用两类问题验收算子知识库

1. 收集与任务相符的 Learn 文档、算子表和经核对的实验备注，记录版本。
2. 选一个文档明确回答的问题，要求返回对应条目、签名、输入和示例的适用条件。
3. 选一个资料未覆盖的问题，观察模型是否标注缺失依据以及需要查哪份资料。
4. 将回答逐条与源文档和实际字段类型核对；表达式另走项目已有语法和规则检查。
