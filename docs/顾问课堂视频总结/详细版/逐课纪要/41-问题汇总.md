# 41｜Gemini 登录和账号状态排查

这段录屏汇总手机号使用次数提示、额外身份核验与账号停用三种个案。复习时先识别提示对应的账号和阶段，再找官方入口处理。

## 用页面原文确定排查方向

| 场景 | 怎样核对 | 可执行的下一步 |
| --- | --- | --- |
| 页面提示号码使用次数 | 查提示是否出现在添加号码、验证或创建流程，记录发生时间 | 根据该提示使用官方帮助或等待页面明确说明 |
| 验证页面要求身份确认 | 核对登录的账号、设备和页面实际提供的方法 | 用本人已启用的官方验证方式 |
| 页面显示账号停用 | 检查是整个账号状态还是当前产品的访问问题 | 从停用页面进入官方申诉，记录受理与处理状态 |
| 反复尝试仍出现相同提示 | 保存提示出现的位置和时间，识别重复的状态 | 用相同记录和受理编号检查下一步 |

表 1 将录屏中的个案按处理入口列出。手机号限额和重置时间属于讲者当时对个案的判断，实际规则由官方页面和帮助中心确认。

**复习练习**　排查记录可写成「何时发生、哪一阶段、提示摘要、官方入口、当前状态」五项。用于团队沟通时保留流程问题和错误类别，账号材料由账号本人在官方页面处理。
