## 课程概览

这段录制从回查已有 Alpha 的答疑进入表达式入门。讲师把经济直觉拆成 Data Field 和 Operator，使用资产与负债的比率示意，还解释为什么 AI 需要研究范围、历史结果和个人因子池上下文。

## 先定位结果，才能讨论改哪里

答疑先用 Alpha ID 和时间在网页上回看记录。查找时应同时记下状态、表达式版本和设置，防止拿未完成或其他阶段的条目对照。课堂有当期作业和顾问邀请说明，本项目继续执行人工审阅及网页端手工提交约束。

## 把经济直觉拆成两个可检验的问题

课堂以资产和负债比率示意，同一个数字既能表达公司结构，也能依研究方向赋予不同的信号符号。第一步要确认分子分母和对应的财务含义。第二步写清楚高值预测什么、低值预测什么，再做固定设置的两个方向对照。

| 检查项 | 比率示例中的做法 | 常见误判 |
| --- | --- | --- |
| Data Field | 在数据目录核对字面名、范围、单位和更新日 | 拿数据集名或近义字段名代替具体字段 |
| Operator | 从 Learn 核对输入及输出的含义 | 因为表达式能运行就认为经济解释正确 |
| 方向 | 在同一个测试环境比较原信号与 reverse 对照 | 用另一地区的历史方向替代本地区验证 |

讲师把基本面和量价数据并列介绍。量价侧提到 Average Daily Volume。看见 ADV 一类名词时先核对其定义和时间窗口，再解释它为什么可以反映流动性或成交活跃程度。

## 怎样给 AI 足够的研究上下文

讲师举例，把一个 Alpha 发给 AI 并只要求改成能过检的版本，模型并不知道研究员当前地区、现有池子和下一步候选。它可能产生一个在语法上不同、在同一经济机制上高度重合的式子。

**建议的询问顺序**

1. 提供地区和 D1 设定、已核对的数据字段含义及方向假设。用候选概要替代账号和敏感凭据。
2. 让模型先解释当前表达式每个处理步骤的目的，再只提一个可对照的变动。
3. 比较改动前后的覆盖、Sharpe、换手和 PnL 相关性。查看方向是否稳定，再判断候选是有效扩展还是重复。
4. 正式运行坚持本项目算子约束。课程用于理解研究顺序，课上推荐的个别工具与资格要求按当时背景理解。
