# 09｜Ready for Genius，顾问权限、回测诊断与组合多样性

## 课程概览

课程从顾问账号可用的地区、Universe 和风险中性化选项讲起，再用多空数量、Margin、换手与相关性诊断候选。后半讲个人池的多样性和 Value Factor、Genius、Power Pool 的录制时口径。

## 开始研究前先定环境和比较对象

讲师展示地区和股票池差异，提到交易成本与 Margin 在一些市场的约束更大。记录当前 Region、Universe、D1 和字段权限。一地经验适合作为新研究问题，换市场时需要独立复验。课堂把风险中性化解释为尽量去除已知共同暴露，保留策略特定部分。可以用同一表达式对照无该处理、行业分组和风险中性化，比较收益消失在哪里、覆盖有没有减少以及杠杆和成本解释有没有变化。

## 如何读 Long Count、Short Count 和换手

讲师以 1600 左右股票的池子示意，约 800 对 800 看起来较均衡，1000 对 600 或 1200 对 400 要再检查。数字用于诊断直觉，具体分配受 Universe、缺失、信号和设置影响。多空股票数不代表两边权重均匀，同样还要查看集中度与实际风险。

| 现象 | 先查的证据 | 下一步对照 |
| --- | --- | --- |
| 多空数量强烈失衡 | 字段缺失、有效股票数、分组后分配 | 同设置看基线与改变后的持仓覆盖 |
| 年度平均换手正常却有异常起伏 | 日度分布、异常日和 Margin | 检查高换手日期是否也是亏损和持仓集中日期 |
| 更换风险中性化后收益明显下降 | 被移除的共同风格或行业暴露 | 对照分年曲线、分组数量和相关性 |
| 相关性结果尚未算出 | 状态与对应的比较池 | 按当前规则保留待计算状态，适时只读核查 |

Production correlation 与 Power Pool correlation 使用不同的比较集合。课堂提醒频繁触发计算会拖慢过程。项目中 PC 空响应记录待计算，不能将空体当成通过。本课还介绍了 Value Factor 与评估窗口，历史计算口径应按当前平台核对。

## 从一条高分候选扩展到研究池

1. 记录每个候选的原始数据类、经济机制、模板、中性化与换手分布。
2. 对照候选与同类现有池的持仓及 PnL 相关性。讲师举换手约 5% 和约 30% 的组合作为异质性示意，具体数字不等于方向独立。
3. 观察加或移一条信号后，组合回撤、分年曲线和留样表现怎样变化，再决定研究下一条独立线索。
