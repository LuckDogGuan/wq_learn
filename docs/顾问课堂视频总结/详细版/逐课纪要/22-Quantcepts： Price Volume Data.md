# 22 | Quantcepts — Price Volume Data

> 怎样从最常见的量价字段提出一个可检验的短期反转假设？

| 字段 | 做什么 |
|---|---|
| Open、Close | 描述开盘到收盘的价格变化 |
| High、Low | 描述当日价格范围 |
| Volume | 反映该统计期间内的成交量 |

## 课堂走读与练习

1. 短片用开盘与收盘的相对变化解释量价数据，也列举日内最高、最低以及成交量。先把研究窗口定清楚，记录当日变化方向。
2. 课堂提出日内走弱股后续可能反弹的假设。同样开在 100，甲收在 98，乙收在 102。练习记录甲为候选反转方向，在 D1 条件下比较后续可观测表现；留存相反排序作对照。
3. 一个反例是事先读取日末收盘价后，把交易写成在同一价格成交。另一个是把隔夜收益和开盘至收盘收益混成同一口径。开始模拟前，从字段说明核对时间基准、调整口径与可得时点。

## 检查与回看

- 记录方向、换手、分期表现。价格极小、停牌或缺失等影响覆盖的情形单列。
- `00:00:00` 常见量价字段；`00:00:28` 开收盘变化与反转假设。
- 课堂给出假设起点。当前研究按 D1 复现，未来表现由独立对照检验。
