## 先把研究环境写清

顾问侧可选择的数据、股票池及设置可能与用户阶段不同。打开平台先记录 Region、Universe、D1、成本假设、Neutralization 和数据权限。比较两个市场的 Sharpe、Margin 或换手时，把市场和设置带上。单一高 Sharpe 若主要由一两个年份推动，还需拆看各年和样本范围，排查换手与成本变化。

## 区分候选类型和相关性比较对象

| 名称 | 课堂讨论的对象 | 复核时记录 |
| --- | --- | --- |
| Regular 与单数据集类候选 | 候选结构、数据来源和表达复杂度 | 记录表达式、数据集及字段数量口径，查当期类型要求 |
| 个人 Self Correlation | 自己历史池与候选的 PnL | Region、比较池日期、共同样本范围 |
| Power Pool Correlation | 对应 Power Pool 比较池 | 保留当期类别和比较范围，独立于普通自相关 |
| Production Correlation | 平台生产池 | 记录服务端状态。结果缺失保留待复核 |

## 怎样判断这条候选在组合里做什么

1. 用一句话写经济直觉。例：研究的是报告后预期是否变化，而后续必须确认使用的是可观测的预期。
2. 为每个字段补一句选择理由。记录对象、度量单位、更新频率、选定样本的实际覆盖。
3. 为每一步算子写明它改变什么。按原值、变换、分组递进做对照，记录稳定性和覆盖。
4. 看候选和已有池的相似性。把高收益但高度重复的研究保留为历史记录。当前项目的相关性判断执行本地初筛与平台只读复核，正式提交由用户手工完成。
