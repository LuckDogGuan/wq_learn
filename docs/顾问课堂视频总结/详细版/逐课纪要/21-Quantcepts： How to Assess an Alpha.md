# 21 | Quantcepts — How to Assess an Alpha

> 回测曲线好看以后，怎样检查风险、交易代价、集中度和与现有信号的重复？

## 指标速查

| 指标 | 检查 | 应并列留存 |
|---|---|---|
| Sharpe | 收益相对波动的表现 | 分期 Sharpe 和记载的计算口径 |
| Turnover | 持仓更新的频繁程度 | 换手分布与交易成本假设 |
| Drawdown | 净值从高点回落的深度 | 回撤时段、原因和恢复情况 |
| Correlation | 与已有信号的相似程度 | 对照池、样本窗口、返回状态 |
| 权重与子股票池 | 是否集中于少量股票，子池内是否同样有表现 | 最大权重、有效覆盖与子池结果 |

## 课堂走读与练习

1. 先记录风险调整后收益、换手和回撤，课程提到收益相对于回撤的一个经验判断。原视频的经验值用于理解，平台门槛与指标口径须在当期项目中核实。
2. 检查相关性、权重集中度和子股票池表现。例：两个候选整体 Sharpe 接近，甲换手更低、持仓更分散、主要子池表现稳定，可把甲留下继续分析成本和相关性。反例是乙的收益主要来自少量重仓股，而且只在整体池看起来好，如此应先调查集中来源。
3. 本项目将不可观测的相关性结果保留为待核对。相同地区、Universe、D1 和测试区间下再比较候选，把成本和回撤放在同一张记录表。
