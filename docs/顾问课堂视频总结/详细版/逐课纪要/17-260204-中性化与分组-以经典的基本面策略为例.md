# 中性化与分组，以经典基本面策略为例

> 课程编号 17。原片为 260204-中性化与分组-以经典的基本面策略为例。重点是看清中性化发生在哪一层，以及自定义分组是否有效。

## 问题

如果想比较行业内毛利率改善的公司，同时减少不同杠杆组的共同暴露，要在哪一步做组内比较，在哪一步去均值？

## 术语速查

| 处理 | 作用位置 | 预期核对项 |
| --- | --- | --- |
| 设置层 Neutralization | 对最终输出计算 | 最终的去除范围，以及是否还有目标敞口 |
| group_rank | 表达式中的指定组内 | 保留同组公司的相对顺序 |
| group_neutralize | 表达式中的指定信号和组标签 | 检查每组去均值是否消掉预期共同部分 |
| rank 后接 bucket | 自定义分位组的步骤 | 各桶样本数、空桶和边界 |
| densify | 处理组标签编码 | 确认标签属于哪个分组，观察实际组数 |

## 课堂走读

1. **先算一次市场或组内去均值。** 课堂用 2 和 4 的平均值 3 演示处理后变成 −1 与 1。若扩到不同行业，每组按本组均值计算。设成 Market 或 Sector 时去除范围不同。仅检查原始字段符号时，单独留一份原值记录，把设置层中性化的影响排开。见 00:25:23–00:31:41。

2. **把连续量变成有足够样本的组标签。** 课堂先说明按等宽区间划分可能让样本挤在少数桶，再展示按排名切桶。先核对杠杆分母口径，记录缺失与并列值，对多个交易日统计每组规模。组内只有很少股票时，单组的效应更容易由个别值主导。见 00:37:14–00:40:20。

## 研究建议与对照

| 分组与处理 | 固定条件 | 主要观察 |
| --- | --- | --- |
| 基础毛利率变化 | 同地区、D1、股票池和样本期 | 方向、覆盖、分日收益 |
| 只加行业内比较 | 同一变化信号和样本期 | 行业依赖、相对表现及换手 |
| 再加杠杆分组处理 | 前一步完全一致 | 桶大小、组内均值、目标信号是否还存在 |
| 另测设置层 | 使用同一候选和区间 | 两层叠加后收益与相关性的变化 |
