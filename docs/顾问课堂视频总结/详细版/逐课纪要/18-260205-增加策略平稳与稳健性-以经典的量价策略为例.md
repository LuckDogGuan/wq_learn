# 增加策略平稳与稳健性，以经典量价策略为例

> 课程编号 18。原片为 260205-增加策略平稳与稳健性-以经典的量价策略为例。重点是匹配信号时间尺度、复核字段类型和参数扰动。

## 问题

一个在样本内表现好的量价候选，怎样判断改善来自合理平滑，还是恰好选中了对某段历史有利的参数？

## 术语速查

| 术语 | 可测试的问题 |
| --- | --- |
| Decay | 平滑后换手与反应速度怎样变化 |
| Matrix 字段 | 每只股票每天是否只有一个对应值 |
| Vector 字段 | 同一股票同一日有多条记录时，该怎样聚合 |
| IS 与 OS | 哪段用于开发，哪段用于独立检查 |
| 高相关 | 两条策略是否实际依赖同一个信息来源 |

## 课堂走读

1. **把衰减与信号周期对齐。** 课程从中性化完成后的信号讲起，对比 Decay 为 0 与 3 的处理。0 跳过这个设置层的平滑，3 用近期历史平滑这个输出。如果研究的是短期反转，窗口过长可能把反应拖到信息已经衰减以后。见 00:03:07–00:04:53、00:09:02。

2. **先处理 Vector 的多条记录。** 视频把 Vector 与 Matrix 放在一起说明。同一股票同日若有多条观测，先依据金融含义明确取均值、计数或其他课程允许的聚合；再比较聚合后覆盖、缺失和个别观测是否主导。若平台提示输入类型不合，回到字段类型和实际算子签名。见 00:10:05–00:14:41。

3. **在 IS 检验扰动，给 OS 留独立空间。** 课程用 Decay 5 与 10 说明一个可复跑的扰动。保持表达式、股票池、地区、D1 和其他设置相同，先看两个结果的收益方向、换手和回撤；范围定下来后才检查留出的样本外。若 OS 结果用于反复选参，应重新留一个独立区间。见 00:34:20–00:38:18。

## 研究建议与排错

| 观察到的现象 | 优先对照 | 保存的读数 |
| --- | --- | --- |
| 降低换手的同时收益明显变弱 | 同一信号下改用较短平滑 | 换手、收益方向、回撤与行情阶段 |
| 一个参数突出、邻近设置普遍弱 | 先查看是否受极个别日期或股票影响 | 逐年走势、子股票池及有效权重 |
| 两条候选高度相关 | 找出共享字段、处理结构或相同的暴露 | 相关性、覆盖、两条收益曲线 |
| Vector 报类型错误 | 核对聚合前后输入形状 | 数据字段类型、所用聚合口径和失败信息 |

## 当前项目约束

回测固定 Delay=1。窗口和算子选择遵守仓库规则，相关性以实际观察到的平台结果为准。历史课例的数字用于说明检查方法。

## 回看与检查

- [ ] 比较同一个候选的邻近 Decay，而不是同时移动多个参数。
- [ ] 固定最终方案后再检查留出的样本外。
- [ ] 00:42:02 与 00:45:06 回看高相关和边界调参。平台指标门槛以地区与对应规则复核。
