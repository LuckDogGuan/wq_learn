## 回答前

1. 写清本次要判断的是字段定义、表达式语义、实验效果还是平台状态。只补会改变判断的范围，例如 Region、Universe、D1、数据集／字段、设置、样本期、RA/PPA。
2. 读对应主题。精确字段、公式、参数和数字回查该条的原始证据。读清屏幕数字对应的是代码参数、坐标、表现读数还是候选数量。源与源有冲突时，保留冲突和能确认的部分。
3. 给出**结论、适用条件、最小对照、来源位置**。样本外效果仍未知时，给出何种观察会推翻假设。历史活动的权限、额度、阈值按当期记录核对。

资料用于只读查证和拟定验证方案。若要实际运行，权限和项目条件来自当前任务。仓库研究固定 D1，按项目算子约束执行，Alpha 提交由用户在网页端手工完成。
