# 数据与论文复现

## 字段是否能表达假设

先写清比较对象、方向和可观察时点，再把口述概念映射到字段。区分 Dataset、Data Field、Operator、Template、Expression、Simulation Settings、Alpha。两条名字相似的字段可能分别是报告期末数值、披露日观测和更新事件。换 Region 或 Universe 时重新核查实际权限、覆盖和输入类型。来源 [项目术语表](../../../official_guides/BRAIN_OFFICIAL_GLOSSARY.md)、[第 36 课 00:07:33–00:12:52](<../../原始转录/36-250708-数据篇-Brain Lab数据探索与alpha策略开发.txt>)。

| 核对项 | 具体检查 |
| --- | --- |
| 粒度与类型 | 用证券、日期到实际值的例子确认 Matrix。Vector 还要解释多个元素代表什么，决定聚合后哪种统计量与假设相符。 |
| 时间与口径 | 区分财务期、事件日、公开日和策略可见日。比率或预期差的两列需要量纲、期间、证券和日期可配对。 |
| 缺失与零 | 分开记录缺失率、零值率、回填后覆盖率以及最后一次有效更新距今天数。零是数值，缺失是观测状态。 |
| 长尾与重复头部 | 同时保存原值和分位视图。极值压缩只改变视图时应标注。按证券统计进入头部的次数，防止把同一批证券在不同日期的贡献当作多份独立证据。 |
| 派生值 | 保留两条原字段和派生值基线。用共同可观察样本做对照，记录异常分母及样本差异。 |

字段变化很快时，先检查回填值是否已过时。新闻举例的重点是旧事件被当成当日信息，回填天数取决于信息寿命。相反，财报低频列要先看窗口内有几次真实更新。来源 [第 46 课 00:48:04–00:53:40](<../../原始转录/46-AI赋能量化下午理论课.txt>)、[第 50 课 00:12:35–00:13:32](<../../原始转录/50-WorldQuant Brain 带你读论文 3.txt>)。

## 可定位案例

- **卖空成交占比。** 第 12 课画面在 USA / TOP3000 / D1 下用 `shrt36_svol`（卖空成交量）和 `shrt36_totalvolume`（总成交量），历史信号方向是原比率取负。比率本身通常应在 0 到 1，前提是同口径下分子属于分母、分母为正。卖空成交量描述流量，无法单凭它推断空头存量、平仓或下一期收益。复验固定同一交集样本，分别观察两个原字段、原比率和方向变体。来源 [第 12 课 00:17:50 原图](<../../详细版/画面/12/00-17-50-frame-054.jpg>)、[第 46 课 01:05:30 分布原图](<../../详细版/画面/46/01-05-30-frame-197.jpg>)。
- **加权预期与共识预期。** 第 11 课的 `analyst10` 是数据集，画面是 GLB / TOPDIV3000 / D1，两类预期列仍为占位符。课堂分别用 63 日回填和 `winsorize` 参数 4，以两类估计的差值为分子、共识绝对值加防零项为分母，再做组内标准化，20 日线性衰减是可选项。应对齐财报期、指标、估计可见时间和分母近零样本。先比较水平值和变化值，再单独增加清洗、分组或衰减。上述窗口是演示参数。来源 [第 11 课 00:23:30 原图](<../../详细版/画面/11/00-23-30-frame-071.jpg>)、[第 45 课 00:01:50 变化值原图](<../../详细版/画面/45/00-01-50-frame-006.jpg>)。

## 论文映射

- 先记录样本期、市场、入选范围、原变量定义、估计模型、观测日、再平衡和持仓方向。缺原字段时说明代理替换了哪个概念。以论文原方法为完整复现标准，简化实现另记录新增假设。
- 第 48 课的 **OC residual** 来自 OC 对情绪与控制项的回归。残差是观测值减拟合值。先确认因变量、解释变量和估计样本，再核对用残差排序与回归系数排序的区别。若平台实现省掉控制项，将它记录成简化基线，单独验证。来源 [第 48 课 00:47:45–00:56:00](<../../原始转录/48-WorldQuant Brain 带你读论文 1.txt>)。
- 盈余或营收惊喜研究要保存公告前可见的预期，配对同一指标和财报期，明确收益观测起点。先复现主信号，再单独加情绪、规模或成长条件。原论文多空方向、窗口和样本外口径以原文为准。来源 [第 49 课 00:32:42–00:41:17](<../../原始转录/49-WorldQuant Brain 带你读论文 2.txt>)。
