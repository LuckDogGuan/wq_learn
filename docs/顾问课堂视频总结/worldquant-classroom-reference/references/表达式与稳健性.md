# 表达式与稳健性

## 从模板槽位到最小对照

模板标出字段、向量聚合、算子、窗口、分组和 Settings。先验一个实际展开样本，核对同名占位符是否绑定同一变量、算子的输入输出以及调换顺序是否改变含义。截面排名比较同一天的证券，时序排名比较同一证券的历史值。相邻窗口和字段别名通常属于同一实验族。来源 [第 44 课 00:26:07–00:37:29、00:57:28](<../../原始转录/44-AI赋能量化上午实操课-1.txt>)。

| 问题 | 最小对照 | 判读 |
| --- | --- | --- |
| 改善来自字段还是后处理 | 原字段或原始派生量、加入一种变换 | 固定样本、D1 和其余设置，查覆盖和年度贡献 |
| 改善来自中性化哪一层 | 基线、只改表达式分组、只改 Settings，必要时两层同时比较 | 比较暴露、组内样本、覆盖和分年表现，解释过度处理的代价 |
| 衰减或截断有无稳健性 | 保留基线和邻近配置，一次只动一项 | 并看 Turnover、Margin、估计滞后、集中度和子池 |
| 组合后表现变化 | 同条件单支基线与项目允许的双支融合版本 | 检查第二支是否真有独立信息，按项目规则构造 |

组内排名给组内顺位，组内标准化比较偏离的尺度，组内去均值消除各组均值。联合分组可能导致小组或覆盖变化。分析高 Sharpe 时先查是否由少数证券、年份或单个设置推动。中性化和平滑的效果用相同 Region、Universe、样本期与实际结果比较。来源 [第 07 课组内去均值](<../../详细版/画面/07/00-26-30-frame-080.jpg>)、[第 08 课稳健性](<../../详细版/画面/08/00-42-10-frame-127.jpg>)、[第 53 课 01:27:53–01:51:10](<../../原始转录/53-250524-Consultant Training-Part 2.txt>)。

## 可定位案例

- **毛利率与杠杆桶。** 第 07 课先用收入扣除销售成本、再除以收入得到毛利率。计算相对 180 日前毛利率的变化并做行业内排名。另按负债／权益横截面名次形成十个杠杆桶，最终对排名结果按桶去均值。图中设置是 ASI / MINVOL1M / D1，Decay 0、Truncation 0.01、设置层 Neutralization None。要验证自定义分桶的增量，先对照只保留行业内排名的版本，核对收入、权益、历史毛利率近零或符号变化以及组大小。来源 [第 07 课 00:39:30 原图](<../../详细版/画面/07/00-39-30-frame-119.jpg>)。
- **向量和国家×行业交叉分组。** 特定模板先聚合向量，再对标量回填，随后在 `group_cartesian_product(country, industry)` 联合组内变换，最后做时序处理。截图只固定了顺序和联合分组键，字段、分组算子、回填长度和时序窗口仍是槽位。组内变换依赖各联合组的有效成员。国家与行业交叉分组和先国家后行业做两次变换应分开测试。来源 [第 36 课 00:19:50 原图](<../../详细版/画面/36/00-19-50-frame-060.jpg>)。
