课程概览

讲师从数据和模板两个方向拆解常见三阶流程，讨论候选字段的稀缺性、多字段信号的经济含义、表达式生成工厂，以及覆盖率和相关性答疑。

小结

1. 先决定在哪一层创造差异。同样的公开字段和通用变换，容易与已有候选重合。可以寻找信息来源不同的字段，也可以让同一字段进入含义不同的模板。课上用“已有 Alpha 数量 ÷ 字段数量”作为筛查拥挤程度的粗指标，仍需结合覆盖和信息内容。
2. 多字段结构先定义一个能解释的基础信号。为两个输入说明各自扮演的角色，再检查口径、期限和量纲。比如用第二项解释第一项的规模差异或构造差值，再把基础信号送入后续变换。需要 AI 辅助时，提供候选字段含义和允许算子，人工复核组合是否真的有意义。
3. 把模板写成可复用工厂。把数据字段、窗口和其他可变项作为明确的输入，把完整表达式作为输出。讲师以双字段回归模板示范输入与组合的关系。可以调换不同变换的顺序，是否保留某一阶由假设和试验决定。
4. 先做有代表性的小批回测。是否回填要看实际数据覆盖和更新时间。覆盖率好时先留一组无回填基线。初筛表现差时回看字段和模板，避免一次铺开大量高度重复的表达式，再对有证据的候选扩大验证。
5. 区分实现路径与研究逻辑。课程答疑建议能简洁表达的信号优先用 Fast Expression，把 Python 留给有明确需要的复杂状态和变换。相关性、地区差异以及回测额度属于课程当时的讨论，研究中按工作区现行 D1 流程单独验证。
