课程概览
AIAC 英文说明会介绍了以 Parent Alpha 为种子，生成并验证 Child Alpha，组合成 Super Alpha 的参赛研究流程，并演示了分轮回测、复盘和 Notebook 记录。

小结
1. 先理解种子因子的逻辑、数据与表现，再让 AI 生成可解释的变体。可以分开改算子、窗口等因素，便于把表现变化归因到具体的调整。
2. 各变体的回测设置、结果、研究批次及 Parent ID 要有稳定的本地对应关系。课程所示的标签便于筛选整个因子家族以及可视化；比赛标签和提交操作应按当前规则及项目授权执行。
3. 汇总原种子与变体的表现及修改理由，再把有效做法、失败原因和未验证方向写进下一轮提示。讲师举例称更换算子可能有益，而把窗口从 20 拉到 60 可能变差，结论只适用于该例，复盘应保留失败记录与停机条件。
4. Super Alpha 阶段看组合表现和完整的测试区间。课程强调每轮产出数量不确定，研究应优先提高可信结果的质量。
5. 当期说明中样本内得分为 25%，样本外为 75%，还要求能够复核过程的 Python Notebook。该数字、地区、标签和比赛资格是录制时的规则。
