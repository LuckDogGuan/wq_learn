课程概览

AIAC 2.0 说明会讲了当期参赛材料、Notebook 复现要求，以及怎样让 LLM 使用平台的字段、算子和研究假设生成结构化 Alpha 候选。

小结

1. 参赛条件属当期规则。会议说明评估指定 D1 地区的 Regular Alpha，要求记录实际使用的 LLM，描述与表达式匹配，并提交可复现的 Notebook 与展示文件。比赛时间、数量、说明长度和评分权重仅作历史记录。
2. 先准备模型可查的知识。课程示例经 ACE 读取算子，保留名称、类别和使用说明，再将相关数据集描述、可用字段与具体假设一起用于提示。
3. 结构化产出便于核对。用 Pydantic 约束表达式、经济说明、字段和算子的结构，再接到已有模拟流程。交付物以模板中约定的 Alpha JSON 结构为准。
4. 用可对照试验验证生成方式。讲师举例固定研究假设，更换 dataset ID 观察候选差异。也可把事件驱动基本面、价值或动量拆成不同研究主题，并检查模型有无用错字段。
5. 复核样本外和多样性。课程建议用 Test Period 留一段时间做独立检查，避免只挑 IS 高分。竞赛没有把模型的建议视为可直接使用的结论，本项目保留人工审阅和网页端手工提交。
