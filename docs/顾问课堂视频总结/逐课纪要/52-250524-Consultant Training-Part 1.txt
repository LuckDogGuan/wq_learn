课程概览

课程用基本面、舆情、期权和分析师数据解释 Alpha 模板。讲师示范如何把一个金融假设改写成有明确输入的表达式，并用 API 查看字段、匹配同类字段和生成候选。

小结

1. 模板是一组能够解释所测信息的运算。经典例子先量化字段相对自身历史的变化，再将它与同组证券比较。允许替换字段和算子时，保留对每一步输入、输出和分组意义的解释。
2. 多字段输入需要统一口径。课堂用盈利相对公司规模的比率解释跨公司比较。基本面数据更新可能较慢，过短且接近的窗口可能得到相同信号。先看字段实际更新时间和缺失情况，再选择检验窗口。
3. 舆情要区分事件与信息来源。演示从正负情绪的差异切入，查看新闻、舆情等数据集中各字段的具体含义。短周期事件与低频财报分开设定时序窗口，按同样选股及分组条件做对照。
4. 读懂期权字段的测量对象再建模板。课堂讲到价格敏感度、隐含波动率及相关字段，并用 API 练习查看字段结构。把量纲、合约维度和期限核对后再进行组装，避免把含义不同的字段当成可互换的输入。
5. 分析师数据可从预期偏差提出信号。实际值与一致预期或高、低估计形成的差异，先按指标、报告期和可获得时间对齐，再讨论跨公司的尺度或行业比较。按字段命名规律写工厂生成候选，保留配对检查。
