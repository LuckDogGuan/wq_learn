课程概览

这场新顾问衔接课从模拟界面的权限变化讲起，串联 Region、Universe、风险中性化和回测诊断，后半结合个人 Alpha 池讨论 Value Factor、Genius 与 Power Pool。

小结

1. 熟悉权限后再扩展研究范围。先确认可用的 Region、Universe 和模拟设置，再按地区独立验证信号。CHN 难度等说法来自讲师当时的经验，筛选仍看实际回测与交易成本。
2. 风险中性化可用来检查信号来源。课堂区分 Sector、Industry 等分组处理和去除已知风险暴露的设置，建议比较处理前后表现，判断收益是否主要来自风格或行业。
3. 一起看 Long Count、Short Count 和换手。课上用大盘池举例，多空数量极度失衡可能意味着有效覆盖不足。高换手候选要看 Margin 能否支撑，并观察换手是否在个别日期集中。
4. 分清相关性检查的比较对象和节奏。Power Pool correlation 与 Production correlation 面向不同池子。课上提醒频繁请求会拖慢计算，结果未就绪时等待再核对。
5. 从单条高分转向组合互补。把数据类别、模板、风险处理中性化和换手分布一起纳入个人 Alpha 池记录，再看组合表现和样本外稳定性。Value Factor 的更新、Genius 条件与 Power Pool 主题属当时口径。
