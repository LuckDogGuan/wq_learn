课程概览
本课用基本面和量价数据演示 Fast Expression，讲字段的语义、更新频率及取值分布怎样影响表达式，并演示字段替换与 API 批量回测。

小结
1. Dataset 是字段集合，表达式使用具体 Data Field。读文档时核对字段描述、覆盖环境和更新频率。多字段构造还要核对数据含义和量纲。
2. 用简化设置探查字段的正负、极值和分布。课堂以 RD510 的字段示意观察取值范围，收盘价、原油等例子用于提醒结论依赖标的和样本范围。
3. 根据比较目的选算子。普通 rank 比同日股票，ts_rank 比同一股票在过去窗口的位置，group_rank 或 group_zscore 则比较同组股票。向量字段另需检查输入类型与聚合口径。
4. 用同一假设比较语义相关字段。课堂演示 FND6 并提到 Analyst4。API 取字段时核对 Region、Delay、Universe，保留一条已跑通的基础表达式作单变量对比。
5. 回测响应缺少 Location 时记录响应和请求标识，按仓库规则只读对账。课程展示的条件开关保留为讲解背景，实际研究执行仓库算子限制。
