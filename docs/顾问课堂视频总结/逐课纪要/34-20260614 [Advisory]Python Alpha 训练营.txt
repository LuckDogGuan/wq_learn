课程概览

本课以神经网络 Python Alpha 为例，讲解历史特征、每日持仓输出、训练与验证切分、组合损失函数和模型状态的维护。后半段答疑涉及 Brain Lab、网页和 API 的回测入口，以及 Python Alpha 的字段支持。

小结

1. 先定义输入特征和输出。数据字段、派生特征甚至已有 Alpha 可作为输入。模型每天为股票输出一个向量，经过必要的中性化、归一化和股票池处理再形成持仓。已有 Alpha 改写为 Python 时，先对齐实现和设置，再比较回测指标。
2. 按日期分开训练、验证和测试。讲师演示先用历史数据训练，在验证区间观察 Sharpe 和过拟合迹象，再看后续区间。回测引擎按日调用 Alpha 函数，在线预测只使用该日可获得的特征和先前保存的模型状态。
3. 对齐训练目标和组合测量。预测收益可用均方误差衡量，组合策略也可以用持仓和实现收益计算 PnL，再用负 Sharpe 作为损失。关注缺失值、股票池成员资格、收益对齐和分母过小时的梯度问题。
4. 先把最小模型跑通。课程演示了线性层与非线性激活，以及小批量训练、梯度裁剪、早停和异常值检查。验证和每日推理只执行前向计算时，无需更新梯度。训练算法和轮次是示例配置。
5. 明确跨日保存的状态。示例把模型权重、偏置及需要复用的中间数据保存在 Store。先在 Lab 完成试验，再按课程文档核对网页或 API 仿真的入口，固定 D1 设置，比较同一股票池和时期的结果。
