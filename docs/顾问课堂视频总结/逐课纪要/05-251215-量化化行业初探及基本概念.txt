课程概览
本课用 Alpha Factory 说明研究员在数据、信号、组合与执行链条中的位置，演示基本面杠杆信号、BRAIN 回测结果和单笔 API 回测。

小结
1. 把数据字段组合成可以回测的信号。讲师区分传统金融学的超额收益和 BRAIN 课堂里作为研究产物的 Alpha，后者给每个股票打分。组合环节再把多个信号放在一起评估。
2. 动量关注过去表现是否延续，反转关注偏离是否会回归。讲师以企业经营和负债解释信号方向可以随市场环境改变。课堂用美国 TOP3000 展示基本面杠杆分数的正负方向，换地区时应重新检验。
3. 把收益曲线和分年结果与 Sharpe、Turnover、Fitness、Return 放在一起读。演示数值来自当堂设置，复现实验需记录 Region、Universe 和 Delay。
4. 回测 API 先发送表达式和 Settings，接到 Location 后用它查询回测进度，完成后取 Alpha ID。缺失 Location 时按仓库的指纹留存和只读对账规则处理。
