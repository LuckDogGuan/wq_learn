### 一、课程导入与学习建议  
讲师在 〔语音 00:00:00〕 中提到，如果学员已经参加过类似课程或认为自己已经掌握相关内容，可以不参加下午的课程。但若未参加，则建议学习下午内容。下午课程的核心是“数据核查”与“数据字段的金融含义”，旨在帮助学员理解如何利用数据字段的金融含义来构建策略。  

讲师在 〔语音 00:01:00〕 中强调，课程重点在于利用数据字段本身的金融含义和信息，而不是单纯地将数据输入模型。这为后续的数据核查和策略构建奠定了基础。  

### 二、研究流程的第一步：数据集描述阅读

**操作建议**：

### 数据字段分类的意义与操作  

讲师在〔语音 00:06:00〕中提到，分类数据字段的目的是为了建立一个“high level”的框架，帮助学习者对数据集有一个体系化的理解。就像看地图一样，分类可以让人对数据集的结构有大致的把握，从而更好地进行后续分析。  

在实际操作中，讲师通过〔语音 00:06:30〕和〔语音 00:07:00〕展示了如何将数据字段分为不同的类别。例如，某些字段属于时间相关的数据，如文件的更新频率和时间；另一些字段则涉及美国证监会（SEC）文件的分析，包括舆情分析和情绪打分。  

讲师强调，即使不是相关领域的专家，也可以通过询问大模型来理解这些字段的含义，如〔语音 00:07:30〕中提到的，大模型可以解释这些字段的含义，帮助学习者快速掌握数据集的结构。

讲师还提到，单字段的一二三阶（如一阶差分、二阶差分等）也是构建Idea的重要方式。通过这些操作，可以挖掘出数据中的潜在规律，从而形成有效的交易策略。

3. **检查分类逻辑**：确认分类是否合理，如时间字段是否被正确归类，舆情分析是否被归入合适的组别。  

通过以上步骤，学习者可以更好地理解数据字段的结构，并基于此构建有效的Idea。

## 00:12:00–00:18:00　多数据自断的Alpha空间挖掘

### 多数据自断的Alpha空间定义  

在课堂中，讲师提到，单数据自断的Alpha空间已经被大量挖掘，许多顾问已经提交了相关策略，因此难以再找到具有高相关性的Alpha。〔语音 00:12:00〕  

然而，讲师指出，仍然存在一些未被充分挖掘的Alpha空间，特别是“多数据自断”的Alpha空间。〔语音 00:13:30〕  

多数据自断指的是至少使用两个不同的数据字段，通过它们之间的关系来提供新的信息。这种信息可以是数据比率、加减乘除等操作，也可以是事件驱动型的信号。〔语音 00:14:00〕  

### 多数据自断的构建方式  

讲师强调，多数据自断的核心在于利用两个数据字段之间的关系，而不是单独使用一个字段。例如，可以使用两个数据字段的比率，或者通过加减乘除等操作，来捕捉新的市场信号。〔画面 00:14:10〕  

一个具体的例子是使用“short volume”（卖空成交量）和“total volume”（总成交量）的比率，作为基础信号。〔语音 00:17:00〕  

这个比率可以表示为：  
`shrt36_svol / shrt36_totalvolume`  

这个信号的含义是：某只股票在一天内被卖空的成交量占总成交量的比例。比例越高，说明卖空行为越活跃，可能预示市场情绪较为悲观。〔语音 00:17:30〕  

### 多数据自断的回测与效果  

在课堂中，讲师展示了该信号的回测结果。〔画面 00:16:50〕  

- **基础信号**：`shrt36_svol / shrt36_totalvolume`  
- **信号含义**：当日被卖空股票数量与总成交量的比值  
- **回测结果**：该信号在回测中表现出从左下角到右上角的预测效果，即信号值越高，后续收益越高。  
- **操作**：未添加任何operator，仅使用基础信号进行交易。  

### 多数据自断的优势  

讲师指出，多数据自断相比单数据自断具有以下优势：  
1. **信息更丰富**：通过两个数据字段的关系，可以捕捉到单字段无法表达的信息。  
2. **更不容易过拟合**：由于信号基于金融经济学的逻辑，因此更不容易出现过拟合现象。  
3. **更容易找到Alpha**：多数据自断的信号更贴近市场本质，因此更容易找到具有实际意义的Alpha。〔语音 00:16:00〕  

### 复验建议  

1. **验证信号逻辑**：检查`shrt36_svol / shrt36_totalvolume`是否符合金融逻辑，是否能够反映市场情绪。  
2. **回测参数核对**：确认回测设置是否为`USA/D1/TOP3000`，时间周期是否为`day`。  
3. **信号操作验证**：尝试在不同市场或资产类别中测试该信号，观察其表现是否一致。  
4. **信号扩展**：尝试使用其他数据字段的比率，如`short interest / total shares outstanding`，观察是否能捕捉到新的Alpha。

## 00:18:00–00:24:00　多数据字段Idea（Gem）实例与表达式构建

### 多数据字段Idea（Gem）实例与表达式构建  

在课程中，讲师通过多个实例说明如何通过多数据字段构建有意义的信号。他首先提到一个比率的概念，这个比率是基于多数据字段的，具有明确的金融含义。例如，他指出“sort volume”和“total volume”两个字段单独使用都没有信号，只有将它们结合，才能捕捉到有价值的信息。这说明数据字段的选择必须基于一定的金融理解，才能生成有说服力的信号。  

讲师在 〔语音 00:18:00〕 中指出：“你拿这数据算去除，你去除另外一个可能不是total volume的一个东西，他我相信他就不会有这样的一个信号。” 这说明，如果数据字段之间没有逻辑关联，计算出来的结果是没有意义的。因此，在构建信号时，必须确保数据字段之间有合理的金融含义。  

### 表达式构建与信号验证  

在 〔画面 00:18:10〕 中，讲师展示了具体的表达式构建过程。他使用了“shrt36_svol”（短期卖空量）和“shrt36_totalvolume”（总成交量）两个字段，计算它们的比值，作为信号。这个信号的含义是“当日被卖空股票数量与总成交量的比值”。  

在 〔画面 00:19:30〕 中，讲师进一步展示了另一个表达式，使用了“insd3_xzhou_insider_acquire_raw”（内部人士买入量）、“insd3_xzhou_insider_disposal_raw”（内部人士卖出量）和“insd3_xzhou_insider_holding_raw”（内部人士持有量）三个字段，计算“净买入量与持有量的比值”。这个信号的含义是“内部人士净买入量与持有量的比值”，反映了内部人士对公司未来前景的判断。

### 复验建议  

1. **验证数据字段的金融含义**：确保所选数据字段之间有合理的金融逻辑，避免无意义的计算。

## 00:24:00–00:30:00　多数据字段Idea（Gem）实例与数据核查

### 多数据字段Idea（Gem）实例与数据核查  

在课程中，讲师通过一个具体的例子，展示了如何通过多个数据字段的组合来构建一个策略，而不是仅仅依赖单一字段。这个例子涉及的是“Definitive Proxy Statement”（确定性代理声明）和“Form 〈数值待核〉”（表〈数值待核〉）数据字段。  

讲师提到，如果只使用一个字段，比如高管的买入量，其表现可能并不理想，甚至与使用买入量减去卖出量的结果相似。这说明，单字段的策略难以捕捉到数据的深层信息。因此，讲师强调，要通过理解数据字段之间的关系和含义，才能更好地利用数据集提供的信息。〔语音 00:24:00〕  

讲师指出，如果只是“刷数据字段”，即使刷得再久，也无法得到有价值的结果。这是因为数据字段之间存在复杂的关联，而单字段无法反映这些关系。例如，一个高管的买入量和卖出量可能共同反映其对公司的看法，而单独使用其中一个字段可能无法准确判断其意图。  

### 数据字段的组合与策略构建  

在〔画面 00:24:10〕中，讲师展示了如何通过组合多个字段来构建一个策略。例如，使用“insd3_spd”（高管买入量）和“insd3_form4_svol”（表〈数值待核〉卖空量）来构建一个策略。  

讲师提到，当“insd3_spd”大于某个阈值时，策略会跟随“insd3_form4_svol”进行卖空操作。具体公式为：  

```  
if_else(insd3_spd > [数值回看], -[数值回看] * insd3_form4_svol, [数值回看])  
```  

这个公式表明，当高管买入量超过某个数值时，策略会以该数值乘以卖空量进行卖空操作，否则保持中性。  

### 数据字段的含义与背景  

在〔画面 00:25:30〕中，讲师进一步解释了“Definitive Proxy Statement”和“Form 〈数值待核〉”的含义。  

“Definitive Proxy Statement”是公司每年召开股东大会前，向所有股东发出的一份文件，内容包括公司上一年的业绩总结、未来的发展计划、高层人事任命等。这份文件是监管要求的，股东有权通过这份文件了解公司的重要信息，并参与投票。  

“Form 〈数值待核〉”则是公司内部人士（如高管）买卖公司股票的记录，通常用于披露内幕交易信息。  

讲师指出，通过结合这两类数据，可以构建出一个基于事件驱动的策略。例如，在公司发布“Definitive Proxy Statement”时，如果高管大量卖出股票，可能预示公司未来表现不佳，因此可以采取卖空策略。〔画面 00:25:30〕  

### 失败原因与验证建议  

如果策略失败，可能的原因包括：  
1. 数据字段选择不当，未能准确反映市场行为；  
2. 阈值设定不合理，导致策略在不同市场环境下表现不一致；  
3. 忽略了数据字段之间的关系，导致策略逻辑不完整。  

**复验建议**：  
- 检查数据字段的定义和来源，确保其准确性；  
- 对比不同时间段的数据表现，验证策略的稳定性；  
- 尝试调整阈值，观察策略在不同市场环境下的表现；  
- 结合其他数据字段，构建更复杂的策略逻辑。  

### 对照表：数据字段与策略逻辑  

| 数据字段 | 含义 | 策略逻辑 |  
|----------|------|----------|  
| insd3_spd | 高管买入量 | 当买入量 > 阈值时，进行卖空 |  
| insd3_form4_svol | 表〈数值待核〉卖空量 | 以阈值乘以卖空量进行卖空 |  
| Definitive Proxy Statement | 公司年度总结文件 | 事件驱动策略触发点 |  
| Form 〈数值待核〉 | 内部人士买卖记录 | 用于判断高管行为 |  

通过以上分析，可以看出，构建一个有效的策略需要深入理解数据字段的含义，并合理组合多个字段，以捕捉市场中的潜在信号。
