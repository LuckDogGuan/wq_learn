讲师提到，对于非理工科背景的同学来说，模型可能让人感到害怕，但其实模型就是一个函数，有输入和输出。例如，一元二次函数Y=2X，输入X=1，输出Y=2，这就是一个简单的函数。  

### Alpha的组成与表达式  

Alpha可以理解为一个由数据（Data）和运算符（Operator）组成的表达式。例如，上一节课展示的例子是“Liability / Assets”，其中Liability是负债，Assets是资产，除号是运算符。  

讲师强调，虽然两个表达式可能看起来相似，但它们并不一定代表相同的Alpha。例如，用资产除以负债，和用资产除以股东股本金，虽然都是除法，但得到的分数是不同的。  

### 平台相关性与Alpha表达式  

讲师指出，平台上的相关性并不是看两个Alpha表达式是否长得一样，而是看它们最终计算出的PNL（盈亏曲线）是否相似。因此，即使两个表达式看起来相似，但若使用了不同的数据或运算符，它们可能代表完全不同的Alpha。

讲师展示了学生作业中的一个常见错误，标题为“不要混信号”。这个错误指的是学生在构建Alpha时，将多个信号混合在一起，而没有进行充分的验证。

讲师进一步解释，时间序列operator（如ts_sum、ts_delta）适用于纵向处理，而横截面operator（如rank、sign、scale）适用于横向处理。这些operator的分类在〔画面 00:48:50〕中也有明确说明，其中列出了如rank、ts_rank、zscore等operator的名称和用途。

在〔语音 00:53:00〕中，讲师以ts_sum为例，说明其作用是计算过去n天的成交量均值。例如，如果要计算过去20天的成交量均值，可以使用ts_sum(volume, 20)。

讲师展示了几个关键的时间序列运算符，包括：

- **ts_corr(x, y, n)**：计算x和y在n天内的相关系数。〔画面 00:54:50〕

这些运算符可以帮助我们识别数据的分布特征，例如最大值、最小值、标准差和相关性，从而为后续的策略构建提供依据。

4. **调整参数n**，以优化数据的分布和策略的稳定性。

### 失败现象与核对办法

在实际操作中，可能会遇到以下问题：
