〔语音 00:07:00〕指出，GLB Region是全球市场，其最大特点是容易获得weight，但回测速度较慢且占用资源较多。weight决定了Alpha在基金中的表现，而GLB的weight通常较高，但回测资源消耗大。

## 00:18:00–00:24:00　风险中心化与回测结果解读

### 风险中心化与Max Trade的定义  

在课程中，讲师首先介绍了**风险中心化（Risk Neutralization）**的概念，并指出其在实际交易中起到的作用。风险中心化通常包括**Fast, Slow, RAM, Statistical, Crowding**等方法，这些方法在交易速度上有所不同。  

讲师提到，**Max Trade** 是一种基于**ADV20**（过去〈数值待核〉天的平均成交量）的交易限制机制。它决定了在实际交易中，一个Alpha策略最多可以交易多少股票。  

> **〔语音 00:19:00〕**：ADV20是一个Volume的数据资段，Max Trade指的是你现在的所有Alpha如果这个东西关门的是Off，那么所有的Alpha最终会在一个理想环境下或者纸链环境下带来的结果。如果开成On，它会考虑到真实的市场情况。  

**操作说明**：  
- 在BRAIN平台中，Max Trade的设置会影响Alpha策略的交易限制。  
- 通过设置Max Trade为On，可以更贴近真实市场环境，但可能会对Sharpe Ratio和Margin产生影响。  

**失败现象**：  
- 如果Max Trade设置为Off，Alpha策略可能在回测中表现良好，但在实际交易中无法执行。  

**核对办法**：  
- 在回测结果中查看是否出现**Investable Constraint P&L**线，这表示Alpha策略在真实市场中的表现。  

### 回测结果中的多条线与Investable Constraint  

讲师指出，在回测结果中，如果启用了风险中心化，通常会出现**三条线**：  
1. **蓝线**：表示Alpha策略在理想环境下的表现。  
2. **绿线**：表示Investable Constraint P&L，即在真实市场中的表现。  
3. **其他线**：可能表示不同的风险中心化方法或交易限制。  

> **〔语音 00:21:30〕**：如果你的中心化选项选成的是Sector或者这些情况下，通常你会有一个如果Risk Neutralize，它那条线会是什么样。  

**操作说明**：  
- 在回测结果中，观察蓝线和绿线的走势是否一致。  
- 如果蓝线和绿线偏离较大，说明Alpha策略在真实市场中可能无法实现预期收益。  

**失败现象**：  
- 如果绿线表现很差，说明Alpha策略在真实市场中存在执行限制。  

**核对办法**：  
- 在回测结果中查看**Sharpe Ratio**、**Turnover**、**Margin**等指标，判断Alpha策略是否符合实际交易要求。  

### 回测结果中的Sharpe Ratio与Margin变化  

讲师提到，启用Max Trade为On后，通常会对**Sharpe Ratio**和**Margin**产生影响。  

> **〔语音 00:23:00〕**：通常情况下，你这个开成On了以后，它会对Sharpe有一点伤害，但是通常情况下它也会降低Turnover，降低Turnover，同时会通常情况下可能会提高一定的Margin。  

**操作说明**：  
- 在回测结果中，查看Sharpe Ratio的变化是否显著。  
- 如果Sharpe Ratio下降，但Turnover降低，说明Alpha策略在真实市场中更稳健。  

**失败现象**：  
- 如果Sharpe Ratio下降且Turnover上升，说明Alpha策略在真实市场中表现不佳。  

**核对办法**：  
- 在回测结果中查看**Sharpe Ratio**、**Turnover**、**Margin**等指标，判断Alpha策略是否符合实际交易要求。  

### 复验建议  

- **验证Alpha策略是否符合真实市场条件**：通过对比蓝线和绿线，判断Alpha策略在真实市场中的表现。  
- **检查Max Trade设置是否合理**：确保Max Trade设置为On，以更贴近真实市场环境。  
- **关注Sharpe Ratio与Margin的变化**：确保Alpha策略在真实市场中具备稳健性。  

通过以上步骤，可以更全面地理解风险中心化与回测结果的关系，并确保Alpha策略在实际交易中具备可行性。

## 00:30:00–00:36:00　具体教学主题

### 一、Portfolio概念与Alpha的综合表现  

讲师在〔语音 00:31:00〕中强调，成为顾问后，必须学会建立自己的Portfolio概念。Portfolio指的是你在某个Region内已经提交的所有Alpha的集合。例如，如果你有100元资金，有10个Alpha，每个Alpha分10元，这就是Portfolio的含义。  

**操作与验证：**  
- 在BRAIN平台中，进入“Unsubmitted Alphas”页面，查看所有未提交的Alpha。  
- 选择一个Alpha，点击“Open alpha details in new tab”打开详情页。  
- 在详情页中，注意“Portfolio”相关字段，如“Turnover”、“Return”、“Drawdown”等，这些指标会体现Alpha对整体Portfolio的影响。  

**失败现象：**

Value Factor是基于顾问过去三个月提交的alpha在样本外的表现进行计算的，且每月会滚动更新。例如，当前平台使用的是〈数值待核〉月、〈数值待核〉月、〈数值待核〉月这三个月的alpha表现，当更新到1月底时，会变为〈数值待核〉月、〈数值待核〉月、12月的数据。这种滚动机制意味着顾问需要持续提交高质量的alpha，以维持或提升自己的Value Factor。  

讲师在〔语音 00:56:00〕中提到，Value Factor的计算是基于滚动的三个月数据，因此顾问需要关注自己的历史表现，并确保alpha在样本外具有良好的表现。如果Value Factor低于0.5，可能意味着顾问的alpha质量较低，此时即使提交大量alpha，收益也不会很高。  

### Value Factor与收益的关系  
讲师在〔语音 00:55:30〕中强调，Value Factor直接决定了顾问能赚取的钱的上下限。如果Value Factor较低，即使提交大量alpha，收益也不会很高。例如，当Value Factor低于0.5时，顾问可能每天只能赚取1到2美元，收益非常有限。  

讲师在〔语音 00:57:00〕中提到，如果Value Factor处于较低水平，建议顾问不要急于提交大量alpha，而是每天提交一个即可。因为多交alpha并不会显著提升Value Factor，反而可能稀释优质alpha的表现。因此，顾问应注重质量而非数量，选择最优质的alpha进行提交。  

### Value Factor的提升策略  
讲师在〔语音 00:57:30〕中指出，Value Factor的计算公式会将所有人的总得分进行排序，越接近高分的人越接近60美元的收益，而低分的人则接近1美元。因此，顾问需要通过提升自己的Value Factor来获得更高的收益。
