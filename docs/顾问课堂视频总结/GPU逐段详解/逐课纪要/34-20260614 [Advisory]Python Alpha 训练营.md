## 00:12:00–00:18:00　使用深度学习生成Alpha向量

### 特征输入与神经网络学习过程

在本节课程中，讲师介绍了如何利用神经网络来生成Alpha向量。他指出，神经网络可以接受原始数据或复杂数据作为输入，并通过学习历史数据中的特征关系，输出一个Alpha向量。这个向量为每个公司赋予一个权重，表示其在投资组合中的相对吸引力。〔语音 00:12:00〕

讲师提到，传统的Alpha表达式需要人工编写公式，而神经网络可以自动学习这些复杂的非线性关系，从而发现人类研究员可能忽略的规律。例如，线性Alpha可能只关注动量强的股票，而神经网络可以结合动量、成交量、市值、波动率等多个特征，生成更复杂的条件判断，如“在市场整体波动率低时，买入动量高、成交量高且小市值的股票”。〔语音 00:13:30〕

### 特征选择的重要性

讲师强调，特征的选择对神经网络的学习效果至关重要。他指出，如果输入的特征与价格预测无关，神经网络将无法学习到有效的模式。因此，应尽量选择逻辑上与价格预测相关的特征，如动量、成交量、市值、波动率等。〔语音 00:16:00〕

他举了一个例子，说明如果输入的特征是无关的，神经网络将无法学习到有效的模式，从而导致预测效果不佳。因此，在使用神经网络生成Alpha向量时，必须确保输入的特征具有逻辑上的相关性。〔语音 00:16:30〕

### 模型与损失函数

讲师还介绍了模型和损失函数的概念。模型是深度学习网络的公式，用于运算特征并生成输出。损失函数是优化的目标函数，用于衡量模型预测结果与实际结果之间的差异。例如，可以使用Sharp Ratio作为目标函数，以优化Alpha向量的收益风险比。〔语音 00:17:00〕

他提到，模型可以是简单的两层隐藏层网络，也可以是更复杂的LSTM模型，用于处理时间序列数据。损失函数的选择会影响模型的训练效果，因此需要根据具体任务进行调整。〔语音 00:17:30〕

## 00:18:00–00:24:00　数据核查与训练验证集划分

### 训练集与验证集划分  

讲师在课堂中提到，训练集（training set）和验证集（validation set）是机器学习中非常重要的两个概念，它们用于防止模型过拟合（overfitting）〔语音 00:19:00〕。  

**问题**：为什么需要将数据划分为训练集和验证集？  
**讲师采用的理由**：训练集用于模型学习，而验证集用于评估模型在未见过的数据上的表现，从而判断模型是否过拟合。  

**操作或公式走读**：  
- 训练集是模型学习的“教材”，模型通过训练集学习特征与涨跌之间的关系 〔语音 00:18:30〕。  
- 验证集是模型的“考试”，用于测试模型是否真的掌握了规律，而不是仅仅记忆了训练集 〔语音 00:19:30〕。  

**所见结果**：  
- 讲师提到，验证集可以像操作系统（OS）一样，流出几年作为验证集，用于验证模型是否在学习规律，而不是过拟合 〔语音 00:19:30〕。  
- 例如，可以将〈数值待核〉年到〈数值待核〉年作为验证集，训练集则使用〈数值待核〉年之前的数据 〔语音 00:20:00〕。  

**核对办法**：  
- 在实际操作中，可以使用平台提供的训练集与验证集划分工具，设置验证集的比例（如〈数值待核〉）或具体时间段。  
- 通过观察训练集和验证集的性能差异，判断模型是否过拟合。  

### 防止过拟合的策略  

**问题**：如何防止模型在训练集上过拟合？  
**讲师采用的理由**：使用验证集和早停（early stopping）机制，可以有效防止模型在训练集上过拟合 〔语音 00:20:00〕。  

**操作或公式走读**：  
- 早停（early stopping）是指当模型在验证集上的表现不再提升时，停止训练，防止模型过度适应训练数据 〔语音 00:20:00〕。  
- 例如，如果模型在训练集上的表现持续提升，但在验证集上表现下降，说明模型已经过拟合 〔语音 00:20:30〕。  

**所见结果**：  
- 讲师提到，如果模型在训练集上表现越来越好，但在验证集上表现变差，说明模型已经过拟合 〔语音 00:20:30〕。  
- 举例说明，当模型的参数（如DK）调整时，训练集（IS）表现上升，但验证集（OS）表现下降，说明模型已经过拟合 〔语音 00:20:30〕。  

**核对办法**：  
- 在实际操作中，可以设置早停的阈值（如验证集损失不再下降超过一定范围），并监控训练集和验证集的损失变化。  
- 通过对比训练集和验证集的损失曲线，判断模型是否过拟合。

**问题**：什么是在线学习？

## 00:48:00–00:54:00　Sharpe Loss 与 Alpha 模型训练

### 选择 Sharpe 损失函数的原因  
讲师指出，单纯使用 MSE 损失函数预测股票的收益率（return）并不一定能带来好的 alpha 表现。因为即使预测准确，如果股票的收益率在零附近波动，也无法实现盈利。因此，直接优化 Sharpe 比率（Sharpe）作为损失函数，可以更直接地追求模型的盈利能力。〔语音 00:48:00〕  

### Sharpe 损失函数的定义  
Sharpe 损失函数是通过计算 PNL（Profit and Loss）的均值与标准差来定义的。具体来说，Sharpe 比率是 PNL 均值除以 PNL 标准差。为了将其作为损失函数，需要对 Sharpe 比率取负数，因为模型训练的目标是 **最小化损失**，而不是最大化 Shar，因此损失函数为 -Sharpe。〔语音 00:49:30〕  

### 如何计算 Sharpe 损失  
讲师提到，可以使用一个时间窗口（如 66 天）来计算 Sharpe 损失。在每个时间窗口内，模型会为每一天的股票生成一个 position（仓位），然后根据第二天的实际收益率计算 PNL。接着，对整个时间窗口内的 PNL 计算均值和标准差，最终得到 Sharpe 损失。〔语音 00:51:00〕  

### Sharpe 损失的实现步骤  
1. **生成 Position**：模型根据输入特征（features）生成一个 score，然后通过中性化和归一化（neutralize_and_normalize）处理，得到 position。〔画面 00:52:50〕  
2. **计算 PNL**：使用 position 与实际收益率（actual_returns）相乘，得到 PNL。〔画面 00:52:50〕  
3. **计算 Sharpe 损失**：对 PNL 计算均值和标准差，取负数作为损失函数。〔语音 00:49:30〕  
4. **反向传播**：使用 `loss.backward()` 进行梯度下降，更新模型参数。〔画面 00:53:30〕  

### 对比 MSE 损失与 Sharpe 损失  
讲师指出，使用 MSE 损失函数时，模型只是在预测收益率，但无法保证最终的 Sharpe 比率。而使用 Sharpe 损失函数，模型会直接优化 Sharpe 比率，从而更有可能实现盈利。〔语音 00:48:00〕  

### 复验建议  
- **验证 Sharpe 损失函数的实现**：检查是否对 Sharpe 比率取了负数，并确保损失函数是可微的。  
- **检查 PNL 计算是否正确**：确认 position 与实际收益率的乘积是否正确，以及是否考虑了时间窗口内的所有天数。  
- **测试不同时间窗口的影响**：尝试使用不同的时间窗口（如 〈数值待核〉 天或 〈数值待核〉 天），观察 Sharpe 损失的变化。  

### 对照表：MSE 损失 vs Sharpe 损失  
| 项目 | MSE 损失 | Sharpe 损失 |  
|------|----------|-------------|  
| 目标 | 预测收益率准确 | 提高 Sharpe 比率 |  
| 计算方式 | (predicted_return - actual_return)² | PNL 均值 / PNL 标准差 |

### 失败现象与解决方法  
- **失败现象**：模型训练后 Sharpe 比率未提升，可能是因为损失函数未正确实现。  
- **解决方法**：检查损失函数是否正确地使用了 Sharpe 比率，并确保反向传播过程无误。  

### 总结  
通过使用 Sharpe 损失函数，模型可以直接优化 Sharpe 比率，从而更有效地实现盈利。这一方法在实际回测中表现优于单纯的 MSE 损失函数。〔语音 00:49:30〕

为了处理大量数据，讲师强调了使用 Ring Buffer 的重要性。Ring Buffer 是一种固定大小的数组，可以循环地覆盖数据，从而节省内存并提高效率。  

- **Ring Buffer 的作用**：Ring Buffer 可以不断更新数据，将最新的数据放在前面，而旧的数据则被覆盖。这种方式可以避免内存溢出，同时保证数据的连续性。

1. **数据结构**：Ring Buffer 通常由两个数组组成，一个用于存储特征（features），另一个用于存储下一日的收益率（next-day returns）。
