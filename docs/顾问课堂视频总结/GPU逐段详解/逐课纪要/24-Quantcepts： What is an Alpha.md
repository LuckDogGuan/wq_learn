## 00:00:00–00:01:02　What is an Alpha

### Alpha 的定义与数学模型  
〔语音 00:00:00〕 中提到，Alpha 是一个数学模型，用于预测各种金融工具的未来价格变动。该模型输出的是一个向量，包含宇宙（universe）中所有股票的预测值。宇宙可以是基于流动性定义的美国股票组。每个值每天都会变化，并具有两个属性：方向（direction）和幅度（magnitude）。方向决定了是否做多或做空该工具，而幅度决定了资金在宇宙中各工具之间的分配比例。  

**验证步骤**：  
- 确认 Alpha 的定义是否为数学模型，参考 〔语音 00:00:00〕。  
- 确认 Alpha 的输出形式为向量，包含预测值，参考 〔语音 00:00:00〕。  
- 确认 Alpha 的两个属性为方向和幅度，参考 〔语音 00:00:00〕。
