### 一、Decay 参数的设置与 N 值的影响  

在课堂中，讲师通过屏幕演示了 Decay 参数的设置，并指出 N 值的设定对信号权重的影响。例如，当 N 设置为 4 时，信号的权重分配为：最近一天乘以 3，前两天乘以 2，前三天乘以 1，分母为 4 + 3 + 2 + 1 = 〈数值待核〉。这种权重分配方式不同于等全平均（即简单平均），它更强调近期信号的权重，同时保留了平滑信号的能力。  

讲师指出，如果 N 设置得过大，例如 200，那么早期信号的权重会变得非常小，甚至接近于 〈数值待核〉。例如，200 天前的信号权重为 1，而最近一天的权重为 200，两者差距极大。这种情况下，早期信号对最终 Alpha 值的影响几乎可以忽略，相当于忽略了部分历史信息。  

**验证步骤**：  
1. 在平台中设置 Decay 参数为 4，观察信号权重的分配。  
2. 尝试将 N 设置为 200，观察早期信号的权重变化。  
3. 比较两种设置下 Alpha 值的差异，确认是否出现信号平滑或权重失衡的情况。  

**失败现象**：  
- 如果 N 设置过大，可能导致信号过于依赖近期数据，忽略长期趋势。  
- 如果 N 设置过小，可能导致信号波动较大，影响策略的稳定性。

### 一、Vector Data与Matrix Data的区别  

在课堂中，讲师首先强调了**Vector Data**与**Matrix Data**之间的关键区别。

- **Matrix Data** 是一个二维数据结构，表示一个股票在某一天只有一个值，例如收盘价、成交量等。  

讲师通过〔语音 00:18:00〕指出：“是不是就一个值 就一个值吧 对吧 也就是一个股票当天 他要有值的话 他就对应的就唯一的一个值 对不对 但是呢 对于vector data来说 那就不一样了 vector data的话 它是当天的这个股票对应的这个值啊 它不是一个值 它是一个列表”。  

这说明，**Vector Data** 是一个列表，而**Matrix Data** 是一个单一的值。

## 01:24:00–01:30:00　增加策略平稳与稳健：以经典的量价策略为例

### 数据核查的重要性与平台特性  

在课堂中，讲师首先强调了数据核查在策略开发中的重要性。他指出，平台上的 Sharpe 比率（即阿法）是在理想条件下计算得出的，这意味着在实际交易中，由于手续费、滑点等因素的影响，策略的表现可能会与平台显示的结果存在差异。  

讲师提到，平台上的 Sharpe 比率没有考虑交易成本，因此在实际操作中，高换手率的策略可能会因手续费而影响整体收益。他举例说明，一个 Sharpe 比率较高的策略，如果换手率很高，那么在实际交易中可能会因为手续费而“麻卷”（即收益被侵蚀），但只要 PNL（盈亏净值）足够平稳，理论上是可以加杠杆的。  

### 平台数据的理想性与现实差异  

讲师进一步指出，平台上的数据是理想化的，没有滑点，也没有交易成本。因此，用户在回测时看到的策略表现，可能与实际交易中的表现存在较大差距。他提醒学员，回撤时如果在理想条件下 margin 很低，但在现实中，加杠杆可能会导致亏损扩大。  

他提到，如果用户想查看回测代码，但由于没有准备相关材料，无法展示。这说明平台在数据展示上存在一定的局限性，用户需要自行进行更深入的分析。  

### 数据核查的实践建议  

为了确保策略的稳健性，讲师建议学员在提交 Alpha 之前，进行充分的数据核查。他提到，用户阶段提交的 Alpha 质量会影响顾问阶段的 valu factor，因此建议在提交时对 Alpha 进行标记，如使用红色标记表示质量较差的 Alpha。  

此外，讲师提到，用户需要达到一定的分数（如 1 万分）才能获得成为顾问的资格，因此在数据核查过程中，应关注 Alpha 的质量与稳定性，以提高通过审核的可能性。  

### 对照表：平台数据与实际交易的差异  

| 项目 | 平台数据 | 实际交易 |  
|------|----------|----------|  
| Sharpe 比率 | 理想条件 | 考虑手续费与滑点 |  
| 换手率 | 高 | 高可能导致手续费侵蚀 |  
| P/NL | 平稳 | 可能因手续费而波动 |  
| Margin | 低 | 可能因杠杆而扩大亏损 |  
| Alpha 质量 | 影响 valu factor | 需要标记质量差的 Alpha |  

通过以上分析，学员可以更好地理解平台数据的理想性，并在实际交易中进行更稳健的策略调整。
