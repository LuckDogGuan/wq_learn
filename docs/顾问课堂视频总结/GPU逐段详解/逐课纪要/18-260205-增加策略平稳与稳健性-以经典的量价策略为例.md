### 二、DK与Vector Data的介绍  
讲师指出，本次课程将讲解两个未完成的知识点：DK（Decay）和Vector Data。DK是平台上的一个设置，用于对信号进行时间序列上的平滑处理，即求均值。而Vector Data则涉及数据的向量化处理。  

### 三、DK的数学公式与设置  
讲师直接展示数学公式，说明DK的计算方式。他提到，DK是用于对信号进行时间序列平滑，例如，将今天的信号与昨天、大前天的信号进行加权平均。但DK的计算方式不是简单的平均，而是基于时间的加权，即Time Linear。  

讲师以一个Excel表格为例，说明DK的计算过程。他指出，表格中最左边的列是“位置”，即信号的权重。例如，如果今天是〈数值待核〉月〈数值待核〉日，昨天是〈数值待核〉月〈数值待核〉日，大前天是〈数值待核〉月〈数值待核〉日，那么将信号进行加权平均。  

### 四、Decay参数的设置与影响  
讲师提到，Decay参数的设置会影响信号的平滑程度。例如，当Decay设置为〈数值待核〉时，信号直接使用当天的值，而不会考虑其他日期。但讲师指出，设置为〈数值待核〉时，公式在除法中会出现除以零的问题，因此实际计算中不会使用该设置。  

他建议学员不要将Decay设置为〈数值待核〉，因为这在经济学上没有意义。通常，学员会设置为〈数值待核〉或更高，以获得更平滑的信号。  

### 五、数据核查与保存  
讲师强调，学员应确保数据的完整性和正确性，并建议在课程开始前保存好作业和相关数据。他提到，如果学员在作业中遇到问题，应先保存数据，再进行分析。

## 00:12:00–00:18:00　Vector Data 与 Matrix Data 的区别与处理

### Vector Data 与 Matrix Data 的定义与区别  

在课程中，讲师首先介绍了 Vector Data 的概念。Vector Data 是一种包含多个值的数据类型，例如新闻数据，它在一天内可能有多个条目，而不是单一的数值。这种数据在 Excel 中表现为一个列表，而不是一个单一的值。例如，一个新闻数据字段可能包含多个数值，如 2、3、〈数值待核〉 等，这些数值代表不同的新闻事件或信息。  

〔语音 00:12:30〕 中提到，Vector Data 不是数学中的向量，而是指数据结构上具有多个值的字段。这种数据在平台上不能直接使用，必须通过 Vector Operator 进行处理。  

### Vector Operator 的作用与使用  

讲师强调，Vector Data 必须通过 Vector Operator 进行处理，将其压缩为 Matrix Data，才能用于后续的分析和回测。Vector Operator 的名称是 Vector Tools，它能够提取 Vector Data 的统计特征，例如最后一个值、最小值、均值等。  

〔语音 00:14:30〕 中提到，Vector Tools 会从 Vector Data 中提取最后一个值，这个值通常是离收盘时间最近的值，即最新的信息。例如，如果是一个新闻数据字段，Vector Tools 会选择当天的最后一个值，作为最终的输入。  

### Vector Data 的处理错误与限制  

如果用户直接使用 Vector Data 而不经过 Vector Operator 处理，平台会报错。错误类型包括：  

1. **You take too much resources**：计算资源不足，无法完成处理。  
2. **TS Operator Expects other type of data**：TS Operator 期望的是 Matrix Data，而不是 Vector Data。  

〔语音 00:13:30〕 中提到，如果用户在使用 TS Operator 时没有先用 Vector Operator 处理 Vector Data，平台会报错，提示用户输入的数据类型不匹配。  

### Vector Data 的实际应用与重要性  

讲师指出，Vector Data 在策略开发中非常重要，因为它能够帮助找到低相关性的 Alpha。如果用户在回测或模板中直接使用 Matrix Data，而忽略 Vector Data，可能会导致相关性较低，影响 Alpha 的提交和收益。  

〔语音 00:15:30〕 中提到，很多用户因为图方便，直接使用 Matrix Data，而不使用 Vector Data，这会导致相关性较低，影响 Alpha 的表现。

## 00:18:00–00:24:00　增加策略平稳与稳健性-以经典的量价策略为例

### 数据核查与参数调整  

在课程中，讲师首先强调了数据核查的重要性。他指出，策略的稳健性来源于对数据的不断验证和参数的反复调整。例如，他提到自己从零天开始一直修改策略，持续了一百天，认为即使一点点错误也不能忽视。他强调，随着不断修改参数，无论是设置中的参数、操作参数还是表达式参数，Sharp值会不断提升，因为这是在追求更好的表现。  

### 参数调整与样本外表现  

然而，讲师也指出，提交策略后，样本外表现（OS performance）可能会下降。他以一个经典的overfitting例子进行说明：在〈数值待核〉年科技股下跌时，一些策略会通过设置条件（如行业判断、跌幅阈值）来规避风险。例如，他提到如果股票属于科技行业，且跌幅超过3%，就不再交易。但这种做法在样本外表现时可能失效，因为未来科技股下跌的幅度和时间点可能不同，导致策略表现不稳定。  

### Overfitting 与 Underfitting 的平衡  

讲师进一步解释了Overfitting和Underfitting的概念。他指出，Overfitting是指策略在训练数据上表现良好，但在样本外表现差，而Underfitting则是策略在训练和样本外都表现不佳。他强调，Fitting本身并不是负面词汇，而是适应市场的一个过程。但过度的调整会导致Overfitting，而完全不调整则会导致Underfitting。  

### 复验建议  

为了验证策略的稳健性，建议在提交前进行多次回测，观察Sharp值的变化趋势。同时，应关注样本外表现，避免策略在特定时间段表现良好，但在未来失效。此外，可以尝试在不同市场环境下测试策略，以评估其适应性。
