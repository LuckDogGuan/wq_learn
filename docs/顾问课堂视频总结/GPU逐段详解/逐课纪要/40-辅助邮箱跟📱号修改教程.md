## 00:00:00–00:01:50　辅助邮箱跟📱号修改教程

### 操作流程与界面说明  

### 〈数值待核〉. 进入邮箱修改界面  
- **操作步骤**：在用户头像旁边点击九个点，选择第一个选项进入个人设置界面。  
- **界面说明**：进入后向下滚动，找到“邮箱”选项，点击进入邮箱修改界面。  
- **证据支持**：〔语音 00:00:00〕 中明确提到“点第一个，进来之后点这一个，往下滑……这个是邮箱”。  

### 〈数值待核〉. 验证与删除原邮箱  
- **操作步骤**：在邮箱修改界面，系统会要求用户进行谷歌验证器验证。  
- **界面说明**：用户需复制 RFA（可能为 Recovery Code 或其他验证代码），并重新刷验证器。  
- **证据支持**：〔语音 00:00:00〕 中提到“还是需要这个谷歌验证器，还是复制这个RFA”。  

### 〈数值待核〉. 删除原邮箱并添加新邮箱  
- **操作步骤**：在邮箱修改界面，用户需删除原邮箱，然后添加新的邮箱。  
- **界面说明**：删除原邮箱后，用户可直接输入新邮箱地址，无需再次验证。  
- **证据支持**：〔语音 00:00:00〕 中提到“直接删掉，删掉之后，添加自己的就行”。  

### 〈数值待核〉. 验证新邮箱  
- **操作步骤**：添加新邮箱后，系统会发送验证码至新邮箱。  
- **界面说明**：用户需在邮箱修改界面输入收到的验证码以完成验证。  
- **证据支持**：〔语音 00:00:00〕 中提到“输入自己的，然后收个验证码码就好了”。  

### 〈数值待核〉. 手机号修改流程  
- **操作步骤**：手机号修改流程与邮箱类似，用户需在邮箱下方找到“手机号”选项，进行修改。  
- **界面说明**：用户可直接输入新手机号，系统会发送验证码至新手机号。  
- **证据支持**：〔语音 00:00:00〕 中提到“手机号也是一样，手机号在这个界面，这个邮箱下面，这是邮箱，这个是，添加，然后把这个东西改成自己”。  

### 失败现象与核对办法  

### 〈数值待核〉. 验证码未收到  
- **失败现象**：用户输入新邮箱或手机号后，未收到验证码。  
- **核对办法**：检查邮箱或手机号是否正确，确认是否已通过谷歌验证器验证。  
- **证据支持**：〔语音 00:00:00〕 中提到“还是需要这个谷歌验证器”，说明验证器是关键环节。  

### 〈数值待核〉. 邮箱或手机号格式错误  
- **失败现象**：系统提示邮箱或手机号格式错误。  
- **核对办法**：检查输入内容是否符合邮箱或手机号格式要求。  
- **证据支持**：〔语音 00:00:00〕 中提到“输入自己的，然后收个验证码码”，说明系统会自动验证格式。  

### 〈数值待核〉. 验证码输入错误  
- **失败现象**：验证码输入错误导致修改失败。  
- **核对办法**：重新发送验证码，并确保输入内容与收到的验证码一致。  
- **证据支持**：〔语音 00:00:00〕 中提到“收个验证码码就好了”，说明验证码是关键验证环节。  

### 复验建议  

- **建议操作**：在修改邮箱或手机号前，先确认当前邮箱和手机号是否有效，避免因格式错误导致失败。  
- **建议验证**：修改完成后，建议重新登录系统，确认邮箱和手机号是否已更新。  
- **建议工具**：使用谷歌验证器确保验证过程顺利，避免因验证失败导致修改失败。  

### 术语与字段说明  

- **RFA**：可能为 Recovery Code 或其他验证代码，用于谷歌验证器验证。  
- **邮箱**：用户当前使用的邮箱地址，需在修改前进行验证。  
- **手机号**：用户当前使用的手机号，需在修改前进行验证。  
- **验证码**：系统发送至新邮箱或手机号的验证代码，用于确认用户身份。  

### 注意事项  

- **不推荐操作**：不要在未验证的情况下直接修改邮箱或手机号，可能导致账户被锁定。  
- **不推荐工具**：不使用第三方工具进行邮箱或手机号修改，可能导致安全风险。  
- **不推荐行为**：不要频繁修改邮箱或手机号，避免被系统判定为异常操作。
