## 00:00:00–00:06:00　AIAC2.0 竞赛介绍与数据核查

### 一、竞赛背景与提交规则  

讲师在课程开始时介绍了 AIAC2.〈数值待核〉 竞赛的背景，指出此次竞赛与上一届 AIAC 竞赛有相似之处，但也存在一些关键差异。在上一届竞赛中，参赛者需要提交“超级 ALPAS”（super ALPAS），而此次竞赛则改为提交“常规 ALPAS”（regular ALPAS）。  

讲师强调，常规 ALPAS 可以是“强大的 ALPAS”（powerful ALPAS），这些 ALPAS 必须符合当前正在进行的“主题竞赛”（thematic competition）的要求。例如，当前正在进行的是“全球力量池”（global power pool）主题竞赛，因此参赛者可以提交与该主题相关的 ALPAS。  

此外，参赛者还可以提交“ATOM”或其他常规 ALPAS，只要这些 ALPAS 符合平台在提交时允许的类型。  

### 二、ALPAS 提交的条件与限制  

讲师详细说明了 ALPAS 提交的条件，包括以下几点：  

1. **必须使用 LLM 标签**：ALPAS 必须使用与之相关的 LLM 标签，并且描述应由 LLM 生成。  
2. **描述必须匹配表达式**：ALPAS 的描述必须与对应的 ALPAS 表达式相匹配，以确保其由 LLM 生成。  
3. **提交前需检查**：在提交 ALPAS 之前，必须点击“检查提交”按钮（check submission button），如果系统提示 ALPAS 与竞赛匹配，则表示该 ALPAS 符合竞赛要求。  

讲师还指出，如果 ALPAS 没有正确的 LLM 标签或描述不足 100 字符，该 ALPAS 将无法提交。此外，一旦提交，描述和 LLM 标签将被记录，无法更改。  

### 三、提交数量与平台限制  

讲师提到，参赛者可以每天提交不限数量的 ALPAS，但前提是这些 ALPAS 符合 EIC 2.0 的要求。如果 ALPAS 不符合 EIC 2.0 的要求，例如没有正确的 LLM 标签或描述不足，将无法提交。  

### 四、验证步骤与注意事项  

为了确保 ALPAS 符合竞赛要求，参赛者应采取以下验证步骤：  

1. **检查 LLM 标签**：确保 ALPAS 使用了正确的 LLM 标签。  
2. **检查描述长度**：确保描述至少有 100 字符。  
3. **检查匹配状态**：在提交前，点击“检查提交”按钮，确认 ALPAS 是否匹配竞赛要求。  
4. **避免后期修改**：提交后，描述和 LLM 标签将无法更改，因此提交前必须确保信息准确。  

### 五、复验建议  

- **检查 LLM 标签是否正确**：如果标签错误，ALPAS 将无法提交。  
- **确保描述内容准确**：描述应反映 ALPAS 的核心思想，并与表达式匹配。  
- **避免提交后修改**：提交后无法更改描述和 LLM 标签，因此提交前必须仔细检查。  
- **使用 Python 脚本自动化流程**：讲师提到可以使用 Python 脚本自动化 ALPAS 的生成和提交流程，建议参赛者熟悉相关工具。
