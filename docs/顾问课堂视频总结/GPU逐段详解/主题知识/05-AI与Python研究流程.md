# 05｜AI 与 Python 研究流程

## AI 的输入和输出都要留存

把任务写成「可验证的假设、可用数据和类型、目标 Region 与 Universe、D1、明确的候选限制」。让模型先给字段清单和选择理由，再给模板。对照 Data Explorer 查字段类型、覆盖与信息时点。表达式逐行核对变量、方向、单位和允许的算子，先过简单样例再进入现有队列。

| 阶段 | 留档 | 排查 |
|---|---|---|
| 找假设 | 人工验证过的数据字典、主信号和辅助条件 | 统计术语、正负方向和数据定义 |
| 生成 | 输入版本、占位符、候选清单、表达式与设置指纹 | 查重复、错字段、错误单位 |
| 小样本复验 | 可运行基线、日志、真实回测结果 | 版本、缺数、轴和可见时点 |
| 批量研究 | 状态、已知任务与子 ID、实际结果 | 异常后冷却只读对账一次 |
| 结果复盘 | 使用的版本、正负结果及可复现输入 | 模型引用与原始证据是否一致 |

在 [第 14 课](<../逐课纪要/14-260129-AI比赛与研究效率提升+社区新工具.md>)（00:21:30、00:39:17、00:46:03）可以回看生成草稿、批次实验和 Notebook。模型响应、平台可用字段和语法测试分开验收。结合 [第 46 课](<../逐课纪要/46-AI赋能量化下午理论课.md>)（01:35:03、01:54:14、01:58:20）看分类、方向质检和消费队列。

## Python Alpha 的对照路径

1. 留一个最小 Notebook，按证券和日期核对数组方向、索引、空值以及结果形状。
2. 用小的已知输入做纸面或 NumPy 对照，明确窗口边界、同日和次日的顺序。
3. 用相同数据口径比较简版与新增模块。保留环境依赖、输入文件、输出和生成步骤。
4. 对于已观察到的结果，写出有效和无效条件各一条。对无法观察的状态留下证据定位。
