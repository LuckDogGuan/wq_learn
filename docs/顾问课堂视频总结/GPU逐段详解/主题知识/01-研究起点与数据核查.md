# 01｜研究起点与数据核查

## 先写假设，再问数据够不够

一条研究卡要能回答：指标测到什么，为什么可能和未来收益或风险有关，在哪个时间、哪些证券能看到它，数值变大时预期方向是什么。把主信号和改善信号的辅助信息分开，有限预算先验证主信号。

| 先查什么 | 怎么查 | 出现异常时 |
|---|---|---|
| 数据粒度 | 核对 Dataset、Data Field、类型、频率和单位。向量写明每个元素代表什么 | 报告期、期限或向量观测对象不一致就单独做变体 |
| 信息时点 | 区分事件日、公开日、数据可见日。保留实际更新时间 | 不用财报期末日代替实际可见日 |
| 有效样本 | 按选定 Region、Universe、D1 统计覆盖、零值、缺失、分年变化 | 用同一交集样本重跑，排除筛走难样本造成的改善 |
| 原值与派生 | 并排记录原值分布、分位、极值、分母和派生值 | 先查分母接近零、异常值或回填陈旧值 |
| 数据集中度 | 检查高分位证券是否跨日反复出现，分组看贡献 | 追查是否由少数公司、行业或数据源驱动 |

课程 46 的数据检查演示分别看了全量范围、主体分位和头部证券的重复频次。回填前后各留一份覆盖和分布，方便比较。见 [第 46 课](<../逐课纪要/46-AI赋能量化下午理论课.md>)（00:52:06、00:53:36、01:01:47、01:05:31）。

## 案例：分析师预期差的最小实验

1. 选同一财务指标、报告期、单位和可用日期的两类预期。
2. 先测两条原字段，再测差值。用交集样本区分「派生具有信息」和「样本发生变化」。
3. 分开检验水平值、回填后水平和一段时间的变化，保存覆盖、收益、换手和分年差异。
4. 课堂案例使用 `analyst10`，界面样本为 GLB / TOPDIV3000 / D1。课堂显示加权分析师预期与共识的模板占位符、63 日回填、缩尾参数 4、分组标准化与可选的 20 日衰减。复用时逐项对照，先查目标样本的覆盖和可得性。见 [第 11 课](<../逐课纪要/11-260117-上午顾问培训ai赋能量化数据深潜与ai增强的alpha挖掘.md>)（00:23:30）、[第 45 课](<../逐课纪要/45-AI赋能量化上午实操课-2.md>)。
