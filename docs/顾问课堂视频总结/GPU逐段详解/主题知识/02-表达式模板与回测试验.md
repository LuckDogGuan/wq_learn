# 02｜表达式模板与回测试验

## 把经济假设写成可验证的输入和输出

模板槽位分为字段、算子、窗口和分组。对每个槽位记上单位、类型、候选集合和允许替换的理由。先试简单基线，随后每轮只改一个主要因素。截面排名表示每个日期在同一证券截面上的相对位置，时间序列排名表示一只证券当前值在自身历史窗口的位置。

| 走读顺序 | 核对项 | 常见问题 |
|---|---|---|
| 输入 | 数据类型、更新频率、时点、取值区间 | 把向量直接交给要求矩阵的模板 |
| 时序步骤 | 窗口具有经济含义，里面有真实更新 | 低频字段用过短窗口出现大量持平 |
| 分组步骤 | 组内样本数、空值、覆盖和收益贡献 | 不相关的分组变量造成组过小或偏离假设 |
| 输出方向 | 按一个手算样本验证正负和多空端 | 对同一逻辑反复修改符号后无法追溯 |

## 从模板到批次的操作走读

1. 先展开几条检查同名变量绑定与类型。领域数据优先匹配同一报告期和单位。
2. 固定 Region、Universe 与 D1，分别保存原始数据、表达式、Neutralization、Decay、Truncation 等设置。
3. 有预算上限时从确定的候选清单抽样，保存随机种子、原始顺序与去重结果。用相同定义记录候选数、完成数和未观测数。
4. 批次中断时先核对已观测的结果和候选指纹。排序一旦重排，旧序号只能解释旧批次。
5. 看全批的表现分布与原假设，记录未改善和只在单一期有效的配置。
