# 04｜相关性与组合研究

## 查相关性先写清跟谁比

| 名称 | 比较对象 | 记录 |
|---|---|---|
| Self Correlation | 个人历史池与候选 | Region、池版本、两条 PnL 的日期交集、最大相似项 |
| Power Pool Correlation | 适用的 Power Pool 比较池 | 适用类别、当期口径与真实响应 |
| Production Correlation | 平台生产池 | 状态、实际结果与读数来源 |
| 组合内部重复 | 异构候选池里两两比较 | 组对、存留原因和同类候选信息 |

课堂讨论的池和平台条件会随时期变化。项目按同 Region 对齐本地历史 PnL 后初筛，再对平台结果执行只读复核。空响应与排队仍属于待对账状态。参考 [第 47 课](<../逐课纪要/47-250625-用户到顾问衔接课.md>)（00:46:50）和 [第 53 课](<../逐课纪要/53-250524-Consultant Training-Part 2.md>)（01:13:43、01:16:44）。

## 组合实验分开验证 Selection 与 Combo

Selection 决定有哪些候选可以进入组合；Combo 决定如何对这些候选赋权或组织信号。先固定 Combo 比较不同 Selection，再固定同一入选池比较 Combo。逐步记录池大小、候选重叠、各类信号贡献、样本外表现与集中风险。参考 [第 42 课](<../逐课纪要/42-super alpha第一节.md>)和 [第 43 课](<../逐课纪要/43-super alpha第二节.md>)。

### 最小验证顺序

1. 检查单条信号有无稳定覆盖、实际结果和可解释的驱动。
2. 对齐 PnL 的共同日期，在同池内做初筛。遇到数据缺口记录样本数和缺口原因。
3. 看最高相似项的表达式族、收益期与持仓。保留互补信号，并为相关候选记录区别。
4. 固定一组基线比较组合增量。用各年、尾部损失和持仓集中度解释组合改善出现在哪。
5. 对项目要求的状态、标签写入与人工提交流程遵守当前项目规则。
