# ADR-0002 · 结论必须带证据等级与适用坐标

Status: accepted · 2026-11-27 · 决定人：用户（“在量化的世界没有绝对”）

**决定**：账本、报告、工单中的每条结论标 `[V]` 已验证 / `[R]` 有报告未复核 / `[C]` 条件成立 / `[U]` 未验证，并写出 Region、Universe、数据集、模板、窗口等坐标。`[C]` 条件之外使用须重验。

**原因**：此前多条规则来自单谱系或单样本（如 IMP-02 来自一条 `EUR/model25` 谱系；`T0` 校准只有一个数据集），被当成通用规则会误导选模板。

**影响**：`GLOSSARY.md` 定义标签；`OPTIMIZATION_LEDGER.json` 新条目需带标。既有条目不回溯批量改写，复用时按票 07 逐项审计。
