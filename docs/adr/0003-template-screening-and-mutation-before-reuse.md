# ADR-0003 · 模板先筛选、公开模板先变异再用

Status: accepted · 2026-11-27 · 决定人：用户；证据见 `docs/整理与研究/records/rules/TEMPLATE_SCREENING_20261127.md`

**决定**：
1. 模板的启停以“同地区、同数据集、同设置”的匹配比较为准，单次命中或总命中数不算；精修批（`S3-*`、`PC*-*`）不作模板证据。
2. 来自王哥 skill 与 Admin 帖的公开模板，先做单轴变异（分组、非线性、去暴露、中性化、融合）再使用，并用 PC 验证变异是否降低拥挤。
3. 算子永不拉黑（AGENTS.md）；降级对象是“模板在某数据集/设置下的用法”。
4. 选数据集先于选模板：近期台账 92.8% 的 Stage-3 命中来自 75 个数据集中的 5 个 `[V]`。

**未验证**：公开模板确实更拥挤 `[U]`（缺按模板的 PC 数据，见票 01、05）；变异降低 PC 只在单谱系见过 `[R][C]`（见票 06）。

**影响**：任何新增或停用模板的改动必须引用匹配证据；`wq_research_v2/config/template_register.json`（票 02）登记状态但不改变队列，直到用户批准接入。
