| :--- | :--- | :---: | :--- |

| **T2 · 双重国家 Z-Score（抗 Robust 漂移）** | `winsorize(group_zscore(ts_rank(group_zscore(ts_backfill(star_arm_score, 252), country), 20), country), std=4)`（`model26`） | `5 ops, 1 field`（`ts_backfill` 豁免） | 仅在最外层做横截面标准化会固化全宇宙分布，切到 Robust 子集时分布偏移；**在时序算子之前先加内层 `group_zscore(..., country)`** 可使信号在全宇宙与 Robust 子集下分布高度不变 |

### 2.4 默认设置与单轴故障诊断手册

- **官方推荐起始设置**：`region="ASI"`, `delay=1`, `universe="MINVOL1M"`, `neutralization="SLOW"`（或 `"COUNTRY"`）, `decay=4`, `truncation=0.08`, `max_trade="ON"`，每轮预算 **`2–4` 条**。
- **中性化切换优先级**：首选 `SLOW`（基本面/模型常提升 Sharpe 与 JPN）或 `COUNTRY`（干净跨国基线）→ 若 `SLOW` 触发 90% Robust 天花板则试 `INDUSTRY`/`SECTOR` → 降相关性试 `CROWDING` / `REVERSION_AND_MOMENTUM` → 警惕 `STATISTICAL` 导致 Robust 失败与高相关。
- **三大故障单变量修法**：
  1. **`LOW_ROBUST_UNIVERSE_SHARPE / RETURNS (< 90%)`**：换 `SLOW`/`COUNTRY`/`INDUSTRY` 替代 `STATISTICAL`；在时序前加内层 `group_zscore(..., country)`；用凸权重整形（`ts_covariance(x, x, 22)` 或 `signed_power(x, 1.5)`）、`tail()`/`quantile()` 或收紧 `truncation`（`0.015–0.05`）；避免重度 `decay=60` 与 `1 - rank(cap)` 小盘倾斜。
  2. **`LOW_ASI_JPN_SHARPE (< 1.0)`**：外层全局 `rank` 改 `group_rank(..., country / industry / market)`（日本市场 `market` 常优于 `sector`）；换 `SLOW` 或 `COUNTRY` 中性化；放宽过紧截断（如 `winsorize(..., std=5)`）；核查日本覆盖率（如 `fnd28` 在 JPN 仅约 `0.5`，应换 `fundamental23`/`17`/`analyst69`/`model26`）。
  3. **高换手 / 低 Margin / Investability**：保持 `max_trade="ON"`、换手压到 `< 30%`（目标 `8%–20%`）、试中等 `decay=4–10`，或单独开分支对比 `MINVOL10M`。

## 三、评论区高价值实战精华与反例纠偏

6 条评论中前 5 条为正向确认（认可 90% 动态 Robust 门槛、JPN ≥ 1.0 与单变量迭代），**第 6 条长评提供了 4 条极高价值的实盘反例与避坑点**：

1. **纠偏“高 Sharpe 必挂 Robust”误区**：高 Sharpe 本身不是原罪（评论者最佳 ASI Alpha 达 **`Sharpe = 4.2` 且无压力通过 Robust Universe**）。真正导致失败的是 **Sharpe 集中在少数难交易的小盘股上**；只要流动性与权重分布均衡，高 Sharpe 一样能过 90%。
2. **`STATISTICAL` 中性化的真实双刃剑效应**：评论者在 5 个不同数据集的 Robust 失败因子上实测 `STATISTICAL`——**仅修好 1 个、另 4 个仍失败**；且唯一修好的那个虽然 Sharpe 上升，但 **Returns 下降了约 30%**。结论：可作为备选测试，绝不可当万能药，并须同步检查 Returns 衰减。
3. **排行榜 Merged PnL ≠ 回测仿真 PnL（关键比赛陷阱）**：Power Pool 排行榜计算的是已标定 Alpha 的**合并均值 PnL**，且榜单疑似使用**更新的样本外/最新时间段数据**。评论者把一条已标因子替换成回测 PnL 高 `+24%` 的新因子后，榜单合并 PnL 反而下跌了约 **`-5%`**！因此冲榜时宁缺毋滥，单条弱/过拟合因子会拖垮全队均分。
4. **PPAC `< 0.5` 无法靠调参“洗白”**：同一核心思路的近似克隆在 Power Pool 自相关检查中得分高达 **`0.59–0.99`**，单纯调整 `decay` 或 `neutralization` 几乎无法降到 `< 0.5`——**必须更换新经济逻辑或新数据集**。

## 五、核心风险与避坑清单（供独立流程直接引用）

1. **D0 误发风险**：ASI 平台侧无 D0；禁止任何代码在未通过 `get_platform_setting_options` 实盘验真与人工解锁前构造 `delay=0` 请求。
2. **PPA/RA 路由假象**：符合 `≤ 8` 算子且 `≤ 3` 字段的因子提交时平台先检 PPA；若因 **PPAC ≥ 0.50** 失败回退 RA 又失败，UI 常报错 **`Prod Correlation FAIL`**，切勿误判为普通 PC 问题。
3. **拥挤老集高 PC / 高 PPAC 风险**：`fundamental23`、`model26` 经典字段全平台已产数万条 Alpha，作为常规 RA 极易撞 PC；优先用来打 **Pure PPA/Theme** 或搭配 `price_signal_dl`/`behavioral_signals`/`mmp_nlp_sentiment`/`model138`/`model25(Alphas=0)` 降相关。
4. **换手与 Margin 侵蚀**：ASI 新闻与高频深度学习量价信号换手易超 `30%`，务必开启 `max_trade="ON"` 并做短窗前置平滑（`ts_mean` / `ts_decay_linear`）或小步 `decay=4–10`，在 `MINVOL1M` 谨慎使用 `hump` 防止权重锁死。
5. **非数值/低覆盖陷阱**：`model307` 的 4 个元数据 ID、`analyst15`/`earnings6`（`cov < 0.46`）、`model207`（`cov = 35.4%`）以及 `shortinterest3`/`model77`（本账号无权限）须在零回测预检阶段直接拦截。
