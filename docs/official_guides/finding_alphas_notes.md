# 寻找Alpha：量化交易策略 - 核心Alpha与公式提炼

本书（*Finding Alphas: A Quantitative Approach to Building Trading Strategies*）由 WorldQuant 团队编写，系统性地介绍了量化交易信号（Alpha）的发现、构建与评估。以下是从书中提炼的核心量化策略、Alpha 表达式和常用公式。

## 1. 基础 Alpha 逻辑演进（均值回归策略）

在书中第 6 章的案例研究里，展示了如何从一个基础的商业逻辑逐步推导、优化出一个成熟的 Alpha：

*   **Alpha 1（基础反转）**: 
    假设短期内股价会出现回调（均值回归）。
    `Alpha1 = -(当天收盘价 - 5天前收盘价) / 5天前收盘价`
    *(表现为买入过去5天跌幅最大的股票，卖出涨幅最大的股票)*

*   **Alpha 2（行业中性化）**:
    为了规避整个行业的系统性风险，引入行业中性化（Industry Neutralization），即在同一个行业内，多头和空头仓位总和为0。
    `Alpha2 = IndNeutralize(Alpha1, IndClass.Industry)`

*   **Alpha 3（排序等级化）**:
    为了避免受极端值（Outliers）的严重影响，不直接使用收益率百分比，而是使用股票在截面上的排序（Rank）。
    `Alpha3 = IndNeutralize(Rank(Alpha1), IndClass.Industry)`

*   **Alpha 4（引入时间衰减）**:
    为了降低换手率（Turnover），将当天的 Alpha 与过去几天的 Alpha 进行加权平均，即应用衰减（Decay）。
    `Alpha4 = Decay_linear(Alpha3, 3)` 

## 2. 经典 Alpha 表达式示例汇编

根据书中第 31 章的 WebSim 示例，以下是各种常见思路的 Alpha 表达式具体实现：

### 价格与均值回归类
*   `1 / close` （价格越低，权重越大）
*   `(high + low) / 2 - close` （收盘价低于日内均价时买入，代表日内反转）
*   `vwap < close ? high : low` （如果成交量加权平价低于收盘价，取最高价，否则取最低价）

### 交易量与流动性类
*   `volume / adv20` （当日成交量与过去20天平均成交量的比值，捕捉异常放量）
*   `Rank(adv20)` （买入流动性最高的股票）
*   `Decay_linear(sharesout * vwap, 5)` （流通市值的时间线性衰减）

### 相关性与波动率类
*   `Correlation(close, open, 10)` （过去10天收盘价与开盘价的相关性）
*   `Correlation(vwap, Delay(close, 1), 5)` （成交量加权均价与昨日收盘价的 5天相关性）
*   `1 / StdDev(returns, 22)` （做多低波动率股票，低波异常现象）
*   `Covariance(vwap, returns, 22)` （量价协方差，衡量量价齐升/跌的程度）

### 极值与分布类
*   `Min(0.5 * (open + close), vwap)`
*   `Max(0.5 * (high + low), vwap)`
*   `Ts_Rank(volume, 22)` （当日成交量在过去22天中的时间序列排名）
*   `Ts_Skewness(returns, 11)` （过去11天收益率的偏度）
*   `Ts_Kurtosis(returns, 11)` （过去11天收益率的峰度）

## 3. WebSim / WorldQuant Brain 常用核心算子 (Operators)

书中列举了开发 Alpha 必备的算子，分为以下几类：

### 横截面算子 (Cross-Sectional)
*   **`Rank(x)`**: 横截面排名。对所有股票的 `x` 值进行排序，并归一化到 `0.0 ~ 1.0` 之间。
*   **`IndNeutralize(x, group)`**: 行业/板块中性化。减去该股票所在组的均值。
*   **`Scale(x)`**: 缩放算子。使所有股票权重的绝对值之和为 1。

### 时间序列算子 (Time-Series)
*   **`Delay(x, d)`**: 获取 `d` 天前的 `x` 值。
*   **`Delta(x, d)`**: `x - Delay(x, d)`，即 `d` 天内的变化量。
*   **`Ts_Min(x, d)` / `Ts_Max(x, d)`**: 过去 `d` 天内的最小值/最大值。
*   **`Ts_Rank(x, d)`**: 当前值在过去 `d` 天的时间序列中的排名（0~1）。
*   **`Correlation(x, y, d)`**: `x` 和 `y` 在过去 `d` 天的时间序列相关系数。
*   **`StdDev(x, d)`**: `x` 在过去 `d` 天的标准差。

### 信号处理与平滑 (Smoothing)
*   **`Decay_linear(x, d)`**: 对过去 `d` 天的 `x` 进行线性加权移动平均。最近的一天权重最大（`d`），最远的一天权重为 `1`。
*   **`Decay_exp(x, factor, d)`**: 指数移动平均衰减。
*   **`Pasteurize(x)`**: 信号去噪，处理无穷大或 NaN 值。

## 4. Alpha 评估关键指标
在寻找 Alpha 时，书中强调重点关注以下回测指标：
1.  **夏普比率 (Sharpe Ratio)**: 衡量风险调整后收益。通常要求样本外 Sharpe 大于 2.5 以上。
2.  **换手率 (Turnover)**: 衡量交易成本。较低的换手率（如 50% 以下）通常实盘表现更好。
3.  **最大回撤 (Max Drawdown)**: 衡量极端情况下的抗风险能力。通常要求控制在 10% 以内。
4.  **适应性 (Fitness)**: 综合了收益、换手和夏普比率的评分函数。

## 5. 不同 Alpha 策略的使用场景与适用环境 (Use Cases)

针对书中提炼的各类策略与表达式，不同的市场环境和标的池（Universe）有着不同的最佳实践场景：

1. **均值回归策略 (Mean Reversion)**
   * **适用场景**: 适用于震荡市或缺乏明显单边趋势的市场（如大部分股票市场的日内或短期周期）。
   * **适用标的池**: 高流动性、高波动率的大盘股或中盘股池（如 TOP3000）。当市场出现非理性的恐慌抛售或过度炒作时，价格更容易出现向均值回归的现象。
   * **局限性**: 在强趋势牛市或熊市中，简单的均值回归容易遭遇持续的“接飞刀”或“踏空”，必须结合动量过滤或严格的行业中性化 (`IndNeutralize`) 来保护。

2. **流动性与异常交易量策略 (Volume & Liquidity)**
   * **适用场景**: 财报季、重组并购或宏观数据发布期。放量通常意味着新信息的注入和资金的重新定价。
   * **适用标的池**: 适用于存在信息不对称的中小盘股。在大盘股中，交易量异常放大的信号噪音比通常较低。
   * **典型用法**: 当股票放出巨量且未见显著涨跌幅时，可能意味着潜在的吸筹或派发，常与价格动量或反转因子结合使用。

3. **低波动率策略 (Low Volatility Anomaly)**
   * **适用场景**: 熊市环境或经济衰退期（防御性策略）。
   * **核心逻辑**: 散户倾向于买入高波动性的“彩票型股票”，导致其被高估；而低波动的稳健型股票往往被低估，长期持有低波股的风险调整后收益更高。
   * **适用标的**: 蓝筹股或价值型股票（如大盘价值）。

4. **趋势跟随与动量策略 (Trend Following & Momentum)**
   * **适用场景**: 政策利好释放、产业生命周期初期的行业爆发阶段。
   * **结合用法**: 书中提到纯动量在某些高频周期表现不佳，但通过长期平滑时间窗（如 `Delay(close, 20) / Delay(close, 60)`）构建的中长线动量因子，在特定多头周期具有较强生命力。

## 总结
构建 Alpha 并非简单的寻找神奇公式，而是一个**“提出假说 -> 转化为表达式 -> 降低风险暴露（中性化/去极值） -> 降低交易成本（衰减/平滑） -> 回测验证”**的严谨科学过程。成功的 Alpha 往往来自于基本面、量价逻辑的细微观察，明确策略所适用的**使用场景与市场环境**，最后通过算子进行稳健的数学表达。
