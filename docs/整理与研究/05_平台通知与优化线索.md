## 2. 六条已核验的 D1 优化路径与平台细则

### 2.1 普通字段与 `Alphas = 0` 未用字段严格分队（`yjwedz7`）
- **实核规则**：普通日额度为 **5,000**；仅当表达式内**全部**经济字段在当期 Data Explorer 为 `Alphas = 0` 时免计额度（只要混入**哪怕 1 个** `Alphas > 0` 字段即计入普通额度）。
- **许可搭用的 9 个 PV1 辅助字段**：`currency`, `country`, `exchange`, `sector`, `industry`, `subindustry`, `market`, `split`, `adjfactor`。
- **操作纪律**：
  - 资料 Agent **仅针对 `Delay = 1`** 按 `Region × Universe` 抓取 `Alphas = 0` 资格快照（已实测高覆盖弹药库：`DEU/TOP500/D1` 的 `model264`/`analyst93`/`other250`/`other455`、`ASI/MINVOL1M/D1` 的 `ai_news_scores`/`model207`、`CHN/TOP2000U/D1` 的 `other496`/`analyst45`、`GBR/TOP700/D1` 的 `model26` 冒烟候选）。
  - 静态 AST 解析完整表达式的全部依赖字段，资格不明一律归入普通队列；T0 校准批在隔离广州同账号干扰后，以真实 `X-Ratelimit-Limit / Remaining / Reset` 响应头验证免额度生效。

### 2.2 Quick 初筛 + Full 复核的分账流程（`AvB9j3A`、`Rb2e5LR`）
- **实核 API 参数与返回字段**：须传 `"simulationMode": "QUICK", "visualization": false`。Quick 返回 `PnL, Sub-universe PnL, Weight Concentration, Fitness, IS Ladder, Sharpe, Returns, Turnover`，**未包含 `Margin`**，且跳过可视化、Theme、Competition 与 Correlation 检查，**不可直接提交**。
- **关键坑点**：
  1. `cnhkmcp` 批量工具及旧 `Core/sim/sim_engine.py` 均不支持 `simulationMode`（旧 `sim_engine.py` 直接抛 `ValueError`），必须由新引擎 `wq_research_v2/sim_runner.py` 原生透传。
  2. Quick 按 Regular 标准判定，合规的 `1.0 ≤ Sharpe < 1.58` Power Pool Alpha 在 Quick 下会显示 `FAIL`，必须读取具体数值而非布尔状态。
  3. **产能分账**：Quick 产出单独计入 `Quick Screened`，只有拿到完整 `Sharpe/Fitness/Turnover/Margin` 的 `Full` 结果（或 T0 实测若 Quick 实返 Margin 另行修订）计入 4,000/日严格“有效完成量”。

- 利用 Data Explorer `Date added` / `Last field added`，优先排查新上线数据集（如 `DEU/model264`、`analyst93`、`other250` 均为 `2026-07-01` 新上线）以及平台定向推荐给本账号的 6 个数据集（`y56zvK7`：`analyst10`, `fundamental23`, `global_seasonal_model`, `other696`, `pattern_scores`, `sentiment33`）。
