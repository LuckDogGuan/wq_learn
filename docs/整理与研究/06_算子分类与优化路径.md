## 1. 表达式级双分支组合 SOP：`min(rank(expr_A), rank(expr_B))` 与 `reverse(min(...))`（永久禁用 `add`/`multiply`/`trade_when`）

- **正源溯源与用户确认范式**：
  - 管理员 `WL13229` 原帖 `23906082201239` L373 给出将同量级乘法泛化为 `min(rank(A), rank(B))` 的正源；本地 `group_relative.py` #103 亦有单字段变体 `min(group_rank(x, sector), rank(ts_delta(x, 66)))`。
  - **核心升级（表达式级双分支，而非裸字段拼接）**：每个分支先各自完成 `operators(field)`（向量聚合 / 回补 / 时序差分或衰减平滑等独立预处理），再统一外包横截面 `rank(expr_A)` 与 `rank(expr_B)` 对齐 `[0, 1]` 尺度，最后通过 `min(...)` 实现双强共振（当反转方向符合经济假设时外包 `reverse(...)`）。
  - **用户实盘参考范式**：
    ```text
    reverse(min(rank(ts_delta(ts_backfill(vec_avg(snt26_top50pctranking),500),55)), rank(ts_decay_linear(ts_backfill(mad_underweight_rating_score,5),378))))
    ```
    *结构拆解*：分支 A 为事件排名向量经 `vec_avg → ts_backfill(500) → ts_delta(55)` 提炼边际动量后取 `rank`；分支 B 为低配评级分数经 `ts_backfill(5) → ts_decay_linear(378)` 提炼慢变量趋势后取 `rank`；外层 `min(...)` 强制双强共振，最外层 `reverse(...)` 翻转至目标多空方向。
- **经济假设**：“双强共振”——两条已各自完成语义变换的独立证据（方向先对齐；若分支 B 越低越好先在分支内取负或配合外层 `reverse`）同时强才给高分。例：股票 A `(0.9, 0.1)` 与股票 B `(0.5, 0.5)`，加和同为 `1.0`，而 `min` 为 `0.1` vs `0.5`，天然惩罚单边跛脚，拒绝“假组合”（反 `a + b` 单边无效，王哥 `02-conversations.md` L3405）。
- **统一坐标与永久禁令边界**：双分支锁定相同 `Region × Universe × Delay=1` 与全套平台设置；**`wq_research_v2` 永久禁用 `add (+)`、`multiply (*)`、`trade_when`**（同时维持核心信号 `<6` op 精简约束，防堆砌过拟合），严禁出现 `rank(expr_A) + rank(expr_B)` 变体。

### 表达式级双分支五步单变量消融序列（A–E，严格无 `add`/`multiply`）

| 步序 | 表达式模式（锁定 `Delay=1`，每分支封装 `operators(field)`） | 验证目的与验收取舍 |
| --- | --- | --- |
| **A & B · 单分支独立基线** | `rank(expr_A)`、`rank(expr_B)` | 先独立验证两条完整单字段分支 `operators(field)` 各自具备真实信号与有效覆盖（排除任一分支无效的假组合），记录各自 IS Sharpe、2Y、RN、Margin 与本地 SC。 |
| **C · 双强共振（优先）** | `min(rank(expr_A), rank(expr_B))`；反方向假设对照 `reverse(min(rank(expr_A), rank(expr_B)))` | 与 A、B 同口径比较收益、交集持仓覆盖、最大权重、换手、Margin、2Y/RN 与本地 SC；若相对双基线无增量或交集覆灭，退回单分支重审假设。 |
| **D · 尺度对齐 / 外层单轴变体** | `rank(min(rank(expr_A), rank(expr_B)))` 或 `group_rank(min(rank(expr_A), rank(expr_B)), industry)` *(可按方向外包 `reverse`)* | 相对 C **仅增 1 轴外层横截面重排或行业相对化**，检验去偏/均匀化权重对 2Y/RN、Sub-universe 与 PC 的改善（**严格禁用 `add`/`+` 与 `multiply`/`*`**）。 |
| **E · 单侧触发假设** | `max(rank(expr_A), rank(expr_B))` | 仅当经济逻辑支持“任一分支触发即有效”时另开独立假设卡，重点核查尾部集中度与换手。 |

## 2. ATLAS 分层五维算子分类与 D1 优化路径矩阵

严格遵循王哥 **ATLAS L1→L6 由内向外顺序（禁止前置横截面 `rank` 扭曲时序运算）** 与 **同组同元数（same-group & same-arity）替换规则**：

| 层级与功能类 | 实测可用 Gold 算子（已核 `REGULAR`） | 何时启用（诊断触发条件） | 标准单变量优化路径与同组替换 | 必防 D1 陷阱与反例 |
| --- | --- | --- | --- | --- |
| **L0 · 向量聚合** | `vec_avg`, `vec_sum`, `vec_count`, `vec_min`, `vec_max` | 输入字段为 `VECTOR`（目录标 MATRIX 报 `event input` 时亦按 VECTOR 处理） | ① 先用 `JX14975` 法判别**单值伪 VECTOR**（只测 `vec_avg`，省 80% 额度）；② 真多元素按强/量/频单选 1 个；③ **落实 `JR23144`/`SM63503` 同向极值对齐**：外层 `ts_min/group_min` 内配 `vec_min`，外层 `max` 内配 `vec_max` | 伪 VECTOR 禁用 `vec_sum`（防 OS 漂移）；`vec_avg` 仅做类型归约，本身不创造 Alpha |
| **L1 · 基础算术与双字段组合** | `min`, `max`, `reverse`, `subtract(-)` , `divide(/)`, `abs`, `log`, `signed_power` *(**永久禁用：`add (+)`、`multiply (*)` 沿用禁用**)* | 比率构造（盈利/规模）、预期分歧 `(avg-med)/abs(med)`、表达式级双强共振 `min(rank(expr_A), rank(expr_B))` / `reverse(min(...))` | 同口径/同单位先验单分支基线 → 比率/差值单测分母防零 → 双分支严格按 **A/B(`rank(expr_A)`/`rank(expr_B)`) → C(`min`/`reverse(min)`) → D(外层 `rank`/`group_rank`) → E(`max`)** 对照 | **永久严禁 `add (+)` 与 `multiply (*)`**（`expr_validator.py` 硬拦截）；严禁 `alpha * cap / close` 混杂信号；`log` 必查严格正值与缺失；`abs` 不必然导致单边持仓 |
| **L2A · 回补与频率对齐** | `ts_backfill(x, lookback=d, k=1)` | 低频财报/事件字段覆盖稀疏、存在合理披露空档 | 根据更新频率单测 1 个窗口（季报 `60–120`、年报 `252`），与原式对照新增持仓来源与滞后风险 | **严禁 `ts_backfill(x, 1200)` 5 年陈旧回填**；`ts_backfill` 不计入 Genius Tiebreaker 与 PP 8 算子上限 |
| **L2B · 时序趋势、位置与波动** | `ts_rank`, `ts_delta`, `ts_mean`, `ts_std_dev`, `ts_corr`, `ts_regression` *(注：无 `ts_median`)* | 测自身历史位置、边际变化、波动率暴露或双序列回归残差 | 先留最简单窗基线（`5/10/20/60/120/252` 选邻近 1 档），核对 2Y/RN 方向与符号（防 `qMNZ9aMA` 删负号翻盘） | `ts_ir ≠ ts_mean/ts_std_dev`；分析师字段警惕跨财年滚动（period roll）假跳跃；`ts_std_dev` 为 `ddof=0` |
| **L2C · 平滑与降换手** | `ts_mean`, `ts_decay_linear(x, d, dense=false)`, `hump(x, hump=0.01)` *(另核高 TVR 套件权限：`ts_target_tvr_decay/hump`, `hump_decay`, `ts_decay_exp_window`)* | 已有清晰收益与 2Y/RN，但换手过高（`>30%`）或 Margin 低于区域底线 | ① 初筛坚持 `decay=0`；② 降换手依次**单独对照**：小步平台 `decay`（`1/3/5`）→ `ts_mean` → `ts_decay_linear` → `hump(x, hump=0.01)` → 高 TVR 算子 | ① **`WL13229` 致命坑**：`ts_decay_linear(rank(x), d)` 默认 `dense=false` 会把缺失当 `0` 拉偏排名；② **`hump` 必须关键字 `hump=`**（位置参数报语法错）；③ **`ts_target_tvr_decay` 严禁 `lambda_max > 1`**（`JX79797` 证实反增 TVR）；④ 反例 `GreR9PXG→KPE1Z3zk`：平滑不能修 2Y/RN |
| **L3 · 条件门控** | `if_else(cond, a, b)` *(**永久禁用：`trade_when` 沿用禁用**)* | 仅在特定可见状态有效（事件更新、波动率切换、极端流动性/覆盖保护） | 事先锁定当日可见条件，与原式对照全期、2Y、参与股票数与持仓集中度 | **永久严禁 `trade_when`**（`expr_validator.py` 硬拦截）；禁止把裸布尔条件当独立表达式；`if_else(rank(cap)>0.3, alpha, 0)` 救 Sub 仅作一次性应急（复用推高 SC） |
| **L4 · 横截面标准化与保序重塑** | `rank`, `zscore`, `winsorize(x, std=4)`, `signed_power(x, p)`, `generalized_rank(x, m=0\|1)` *(按权限核)* | 统一截面量纲、压制尾部极端值，或 **PC 卡在 `0.70–0.75` 时保序降 PC** | ① 始终放于时序之后（**禁前置 `rank`**）；② 尾部集中先试 `winsorize`；③ 临门降 PC 单测 `SZ83096` 的 **`signed_power(x, p)`**（实测 PC `0.751→0.69` 保 Sharpe） | `generalized_rank` 仅用 `m∈{0,1}` 防超时；`rank` 前置会扭曲时序差分/回归语义 |
| **L5 · 分组消偏、嵌套分组与去共性** | `group_rank`, `group_zscore`, `group_neutralize`, `vector_neut`, `bucket` | 行业/国家暴露过重、**Sub-Universe 失败**、需要剥离共性或降 PC | ① 单层 `group_rank(x, industry/subindustry)`；② **`SZ83096` 嵌套分组**（内层行业细分 + 外层 `country` 救 GLB/EUR Sub-universe）；③ **王哥 `bucket(rank(f))`** 把低换手 MATRIX 转为分组降 PC；④ 剥离长短周期共性用 `vector_neut` | 避免 `group_neutralize(group_zscore(x, ind), ind)` 冗余双套壳；`group_mean/count/std_dev(..., market)` 为零方差全市场常量禁用；`bucket` 方案增加 ~5 op 须受 `<6` 约束 |
| **L6 · 尾截断与平台设置扫频** | `tail/left_tail/right_tail` *(按权限核，无则用 `if_else` 替代)*；平台设置：`Neutralization`、`Decay`、`Truncation`、`Max Trade`、`Max Position` | 仅在**第三关已具稳定信号后**启用：处理双尾噪声、救流动性/权重、或提交前稳健性扫频 | ① `SJ65808` 纪律：**`tail` 家族必先套 `[0,1]` 排名**（如 `right_tail(rank(x), minimum=0.2)`）；② 王哥提交前扫频：Decay `[0,1,3,5,10,20]` 防断崖 + 9 Neut 序列（API 必传 **`REVERSION_AND_MOMENTUM`** 非 `RAM`）；③ **终审算子消融**（`ZH87224`/`ZS59763` 拆冗余 op 保 `<6`） | 平台 `SUBINDUSTRY` 非通用银弹（反例：GBR `qMNZ` 换 `SUBINDUSTRY` 致 RN Fitness 摔到 0.89）；`NONE` 易现 `Short Count=0`；`AMR` 仅 7 项 Neut；`Max Position` 仅 `USA/ASI/EUR` |
