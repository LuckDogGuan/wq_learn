## 4. D1 四关渐进研究、算子路径与 200 样本两层止损

### 4.2 Stage-0 快速止损 + 200 有效样本两层归因与作用域停用

- **铁律**：**操作符永不拉黑（仅登记适用条件与陷阱）；仅对具体作用域下的 `(字段 / 模板方法 / 参数组合)` 执行停用**。技术错误、`SYNTAX_ERROR`、`429`、`PENDING`、`RESULTS_UNOBSERVED` 及同父式的近邻重复变体家族，**绝不计入 200 分母**。
- **Stage-0 快速探针（24–40 条 + 阳性对照）**：新字段先跑跨风格 5:5 探针并带 1 个同区已知有效对照字段。若阳性对照正常，而目标字段大批量呈厂字型（`<8` 有效年或 `≥200–250` 天平直 PnL）、零覆盖或全员极端弱信号（`max |Sharpe| < 0.6`），立即记为 `STOP_EARLY / FAST_DEMOTED` 保护预算，不盲烧 200 次。
- **Stage-1 正式归因（满 200 条去重有效完成样本）**：按单变量矩阵严格控制每次仅变 1 轴，分两层判定：
  - **Tier-1（信号有效性）**：平台官方 D1 IS 最低检查全过（`FAIL == 0` 且无阻断 WARNING）。
  - **Tier-2（拥挤度）**：仅对 Tier-1 通过者查本地 SC 与远程 PC，清晰区分“无信号”与“有信号但拥挤”。
- **自动生效与单参数挽救**：证据达标 + 阳性对照通过即写入 `records/blacklist/BLK-*.md` 与 SQLite 生效。若改 1 个参数即可出 RA，**仅停用失败参数组合**；每条停用卡强制写清：失败检查分布、对照 Alpha ID、**详尽不可用原因、不同意见与潜在改参挽救假设、一键恢复条件**。
