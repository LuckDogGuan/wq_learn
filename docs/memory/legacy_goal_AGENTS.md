# 项目执行规则

## 范围

- PPA 筛选新代码放在 `代码/ppa_screening_v2/`；不得原地修改 `代码/ppa_submit/`。
- `不同阿尔法标准/` 与 `PPA 范围/` 是本地规则配置和测试输入，不替代平台实时 Alpha 详情及检查结果。
- 默认且唯一筛选窗口为最近一个月；日期按北京时间解析，API 使用结束日之后的半开边界。两个月兼容模式已移除。

## 平台 Alpha 探索安全边界

- 在当前用户明确授权的 xxx(根据用户输入) 挖掘目标内，允许调用 `multi_create_simulation`（8 个并发）；禁止调用 `create_simulation` 或单条模拟接口。
- 每批只使用 1 个数据集、1–2 个字段，优先未点亮金字塔；除非该数据集的 Alpha 模板多样性和字段家族均已穷尽且论坛无可用方向，否则不得频繁切换数据集。
- 禁止使用 `trade_when`、`add`、`multiply`，禁止创建自动化任务。Alpha 提交始终由用户手动完成，任何情况下不得自动提交。
- 基础门槛为 Sharpe>1.58、Fitness>1、2Y Sharpe>1.6、Margin>10bp、Turnover>5% 且 <30%；风险中性化后还须 Sharpe>1、Fitness>0.7、Margin>10bp，操作符数量<6。
- 只有通过全部基础门槛、单数据集约束和实时检查后，才允许进行 robust、严格过拟合、生产相关性检查及属性设置；生产相关性缺失或大于 0.7 一律不得进入提交候选。
- 缺少实时检查、接口超时、认证失败、429/5xx 或响应结构不完整时，必须标记 `PENDING`，不能当作通过。
- 只有全部硬门槛与实时检查明确通过，才标记 `PPA_PASS`；不得自动标记 `READY_TO_SUBMIT`。

## 数据集与字段淘汰规则

- 以 `总结/优化复盘_20260802/操作符_字段黑名单登记表.md` 为唯一登记表；数据集和字段必须使用登记编号、全名、状态标签和证据 Alpha ID，禁止只写“某字段不好”。
- 操作符只作为实验维度记录，不因失败而淘汰，也不触发更换操作符；`trade_when`、`add`、`multiply` 仍因用户明确禁用而不得使用。
- 同一字段累计 200 个“有效、可观测、无语法错误、已完成指标”的不同因子，仍没有任何完整硬门槛通过时，标记 `FIELD_VERDICT = GARBAGE_CANDIDATE`，停止继续扩展该字段。
- `PENDING`、429、超时、无 Alpha ID、响应不完整和语法/参数错误不计入 200；语法错误只记录为 `SYNTAX_ERROR`，修正一次后再继续实验。
- 同一数据集内的字段达到可核实的垃圾字段标准后，汇总标记 `DATASET_VERDICT = STOP_DATASET`；在此之前只能标记 `STOP_EARLY`，不能提前宣称数据集或字段正式拉黑。
- 被标记的字段或数据集不得再进入批量模拟、robust、严格过拟合、生产相关性或属性设置；每 10 个有效批次复盘一次字段计数、数据集状态和多样性。

## 凭据与输出

- 默认凭据为 `Password/config.yaml`，只读入内存使用，禁止把账号密码写入日志、报告或提交。
- 真实测试结果写入运行输出目录；报告必须保留分类、失败原因和平台检查证据。

## 修改与验证

- 使用 `apply_patch` 修改文件，保留现有用户文件和未相关改动。


## GLB D1 Alpha 持续挖掘

- 目标范围为 GLB、TOPDIV3000、D1、REGULAR、`max_trade=OFF`；批量回测只允许使用 `multi_create_simulation`，每批最多 8 个表达式。
- 目标是从 6 个不同数据集取得 6 个完全不同风格的单数据集未提交 Alpha；候选之间相关性必须 <0.4。生产相关性未返回或 >0.7 的候选不符合提交要求。
- 平台超时、401、429、5xx、无 Alpha ID 或响应不完整时，标记 `PENDING` 或 `RESULTS_UNOBSERVED`；暂停 5 分钟后只做一次只读对账，不重复创建同一批次。
- 每批必须记录表达式、字段、universe、参数、multisim/Alpha ID、指标、平台状态、失败原因和优化方向到 `总结/active/`。每 10 批复盘操作符探索率、字段探索率、模板骨架、策略风格、预处理、收益来源和失效风险。
- 单批失败、结果待定、暂时无候选或平台冷却都不是任务完成；未达到 6 个合格且彼此相关性<0.4 的未提交 Alpha 前，应从记录断点继续。任务恢复时先读取 `总结/active/`，不得重复创建已记录的批次；仅在用户明确要求时停止、提交或创建自动化任务。
