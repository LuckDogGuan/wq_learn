## 🏢 关于 WorldQuant 与 BRAIN

WorldQuant 在广泛的资产类别和全球市场中开发和部署系统化金融策略，通过自有研究平台产出高质量的预测性信号（Alpha），聚焦市场无效性来实施投资策略。

BRAIN 使命是让量化金融变得简单，帮助全球参与者在接触量化金融、AI、机器学习概念的过程中学习成长，并有机会根据其创意的数量和质量获得报酬。WorldQuant BRAIN 为全球参与者提供了一个先进的众包平台，用于贡献信号、数据等。

## 💼 岗位职责

**研究方向：**

- 在 BRAIN 平台上创建和开发 Alpha 及其他应用算法
- 研究学术界的量化金融文献
- 识别并设计新的研究领域，产出推动该领域发展的创意

**平台开发方向：**

- 分析研究者当前可用的平台功能，识别问题并向 BRAIN 团队提供解决方案和建议
- 在 BRAIN 平台上设计和测试新功能与新数据集

**业务拓展与顾问对接方向：**

- 与 BRAIN 战略运营各国负责人及其他业务拓展合作伙伴协作，完善并落地 BRAIN 的用户及顾问获取业务策略
- 为 BRAIN 用户和顾问开展培训
- 编制并更新 BRAIN 培训课程

## 🎯 任职要求

- 熟悉并有能力使用 BRAIN 平台，有 ex-VRC Research Consultant 或 BRAIN Research Consultant 经历者优先

- 具备以下至少一种语言的编程经验：Java / C++ / C / Python / MySQL / SQL Server；熟悉 UNIX 者优先

- 对全球金融市场有浓厚兴趣
- 具备良好的英语沟通与表达能力
