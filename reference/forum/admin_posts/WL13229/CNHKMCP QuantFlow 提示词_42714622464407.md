## 帖子正文

**请课前务必操作并配置好Quantflow功能，课堂不再留时间操作！本项课前必做！**

AI 安装提示词（复制给 Claude Code / Workbuddy / Cursor 等）

> 把下面「⚠️ 复制下面的内容」之间的整段提示词复制给任意 AI 编程助手，
> 它会自动完成：安装 cnhkmcp → 找到并启动「运行打开我.py」→ 在桌面创建「Brain工作站」快捷方式。
⚠️ 复制下面的内容（从这一行开始）⚠️

```
请帮我完成以下任务，全程注意跨平台兼容（Windows / macOS / Linux 都适用），并且在每一步完成后确认结果、如实汇报：1. **检查 Python**：确认已安装 Python 3.8 或更高版本（执行 `python --version` 或 `python3 --version`）。如果没有，请指导用户先安装 Python（Windows 用 winget install OpenJS.NodeJS.LTS 不适用，应指导去 python.org 或系统包管理器）。2. **安装 cnhkmcp 包**：执行 `pip install cnhkmcp`。如果安装很慢或失败，改用国内镜像重试：   `pip install cnhkmcp -i https://pypi.tuna.tsinghua.edu.cn/simple`。   安装成功后打印已安装的版本号（例如 `pip show cnhkmcp` 或 `python -c "import importlib.metadata as m; print(m.version('cnhkmcp'))"`）。   如果已经安装且是最新版，不要重复安装（幂等）。3. **定位「运行打开我.py」**：执行下面命令拿到 APP 目录：   `python -c "import cnhkmcp, os; print(os.path.join(os.path.dirname(cnhkmcp.__file__), 'untracked', 'APP'))"`   入口脚本就是这个目录下的「运行打开我.py」（Windows 上是 `运行打开我.py`，路径含中文没关系）。4. **创建桌面快捷方式「Brain工作站」**（不依赖脚本内部逻辑，直接创建）：   - 先确认存在桌面：Windows 检查 `%USERPROFILE%\Desktop`（含 OneDrive 重定向 `OneDrive\Desktop`）；macOS / Linux 检查 `~/Desktop`（Linux 无 `DISPLAY`/`WAYLAND_DISPLAY` 则跳过并说明是无桌面环境）。   - Windows：用 PowerShell 创建 `桌面\Brain工作站.lnk`，TargetPath 指向 `sys.executable` 对应的 python.exe，Arguments 是「运行打开我.py」的完整路径（用引号包裹），WorkingDirectory 是该脚本所在目录。   - macOS：创建 `~/Desktop/Brain工作站.command`，内容为 `#!/bin/bash\ncd "<APP目录>"\nexec <python> "<运行打开我.py完整路径>"\n`，并 `chmod +x`。   - Linux：创建 `~/Desktop/Brain工作站.desktop`（Type=Application、Name=Brain工作站、Exec 指向 python + 脚本、Terminal=true），并 `chmod +x`；如桌面是 GNOME，执行 `gio set <文件> metadata::trusted true`。   - 创建后确认文件存在并告知路径；如果桌面已存在同名快捷方式，跳过创建（不重复）。5. **启动应用**：用新开的终端/后台方式运行 `python "<运行打开我.py完整路径>"`（Windows 也可用 `start` 新开窗口；macOS 可用 `open -a Terminal`；Linux 用终端模拟器或 `nohup`）。   - 等待终端输出 `Running on http://127.0.0.1:5000`（或自动回退的端口），确认 Flask 启动成功。   - 告诉用户浏览器访问地址；若 5000 被占用，以终端实际打印的端口为准。6. **汇报结果**：用简洁清单汇报：① cnhkmcp 已安装的版本；② 「运行打开我.py」的完整路径；③ 桌面快捷方式是否已创建及路径；④ 应用是否已启动及访问地址。如果有任何一步失败，说明失败原因和解决办法，不要假装成功。注意：全程不要修改 cnhkmcp 包内的任何文件；只做安装、定位、创建快捷方式、启动这四个动作。⚠️ 复制到这里结束 ⚠️---## 使用说明1. 打开你的 AI 工具（Claude Code、Workbuddy、Cursor 等），把上面的提示词粘贴给它并回车。2. AI 会逐条执行并汇报。完成后：   - 桌面上出现「Brain工作站」图标（以后双击即可打开应用）   - 应用已在 http://127.0.0.1:5000 运行3. 如果 AI 中途要权限（如 pip 安装、创建文件），允许即可。## 提示词里用到的东西- 包名：`cnhkmcp`（PyPI）- 入口脚本：site-packages 里 `cnhkmcp/untracked/APP/运行打开我.py`- 快捷方式名：「Brain工作站」- 访问地址：http://127.0.0.1:5000（占用则自动回退）
```

### 评论 #5 (作者: GC81559, 时间: 1个月前)

关于「信号正交性」在组合中的关键作用：两个Sharpe=1.5的alpha，如果相关性=0，组合Sharpe≈2.1；如果相关性=0.7，组合Sharpe≈1.7。差异巨大。建议在构建alpha组合时，按数据集类别确保多样性：基本面、量价、情绪、另类数据各选1-2个alpha。不同数据类别的alpha天然相关性低，组合效果最好。

### 评论 #23 (作者: ZW26474, 时间: 2天前)

这个课前必做提示词把 Python 检查、安装 cnhkmcp、定位入口、创建快捷方式、启动 Flask 和结果汇报拆成六步，并要求每步确认、失败如实说明，对零基础同学比较友好。结合评论里的建议，发布前可以再补几个检查点：

1. **安装隔离与版本记录** ：评论里有人建议不要直接对系统 Python 执行  `pip install cnhkmcp` ，而是先确认是否用专用 venv、记录确切版本，并在升级前展示变更；如果课程不要求统一环境，至少让 AI 汇报  `pip show cnhkmcp`  的结果，避免影响现有 WQB 环境。
2. **镜像安装后自检** ：有评论提醒清华镜像对某些依赖（如 playwright）同步可能有延迟，安装后可以加一步  `python -c "import cnhkmcp"` ，确认不是半装状态。
3. **快捷方式失效检查** ：评论里提到快捷方式指向 site-packages 中的中文脚本，包升级后路径或文件名变化可能导致失效；也有评论建议旧版快捷方式先删。可以在第 4 步加一句：若已存在同名快捷方式，先确认目标是否仍指向当前 APP 目录，再决定跳过或重建。
4. **AI 权限逐项确认** ：有评论建议不要一律“允许”，而是确认它只在预期目录创建文件、没有修改包内源码或暴露凭据；这和“如实汇报”配套。
5. **汇报时贴实际端口** ：第 5 步已写明 5000 被占用则回退，汇报时最好直接附终端实际打印的访问地址，不只写默认  `127.0.0.1:5000` 。

如果你希望课程当天大家环境一致，建议先明确：统一系统 Python，还是允许各自 venv？这个确认后，再补 venv 和版本固定会更有针对性。
