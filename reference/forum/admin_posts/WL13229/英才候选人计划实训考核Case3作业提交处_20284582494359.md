[【Alpha灵感】 计数启发法](../参与回复的帖子/[Commented] 【Alpha灵感】 计数启发法_20237862981399.md)

**模板1：**

SKEW =  **Call**  -  **Put** ;

group1 = bucket(rank(ts_std_dev(returns,252)),range='0,1,0.1');

group2 = bucket(rank(cap),range='0,1,0.1');

condition = if_else(SKEW - group_mean(SKEW,opt4_total_volume,group1)>0, 1, 0);

group_neutralize(ts_decay_exp_window(ts_mean(condition,3),20,factor=0.95),group2)

**数据集：** Option Volatility，Call和Put选择的都是不同期限、不同delta的波动率数据，对应匹配后得到了150组数据

**模板解释：** 如果看涨和看跌期权的隐含波动率差扩大，看涨期权价格更高，需求更大，有可能是股价即将上涨的信号，但波动率之差的大小本身受到自身股价波动的影响，无法直接比较，因此依照收益波动率分组，计算截面差距，如果大于0就计数为1，统计过去20天的衰减计数和，并对市值中性化

**Alpha改进：** 选取数据implied_volatility_call_150 和implied_volatility_put_150，同时对截面均值乘以1.5倍，在USA Top3000上得到了 **1个** 可提交的Alpha。

**模板2：**

market_returns = group_mean(returns,cap,market);

modified = vec_sum( **Analyst** );

short_term_excess_return = ts_mean(returns-market_returns,5);

**数据集：** Analyst包括分析师对公司基本面的预测、评级、推荐等数据
