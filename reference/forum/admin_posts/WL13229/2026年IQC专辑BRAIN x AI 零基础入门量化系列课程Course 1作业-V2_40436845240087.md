### 评论 #13 (作者: chenming(MC54303), 时间: 4个月前)

![图片](../images/img_11bf42223e.png)  ![图片](../images/img_7207163aed.png)

- **中性化（Neutralization）** ：平台通过回归或减去均值的方式，消除特定风险因素的暴露。Market 中性化旨在让投资组合的 Beta 接近 0，即多头和空头头寸的风险敞口大致相等。
- **截断（Truncation）** ：防止单一股票权重过大，确保组合分散化，控制风险。这项设置在平台中是可配置的。
- **市场中性** ：最终目标就是让多空市值相等，因此如果截断后不相等，平台会自动进行二次调整。
- **符号含义** ：平台根据 Alpha 表达式的最终值决定交易方向，正值代表做多，负值代表做空。由于  `-close`  天然会让高价股拥有更负的值，因此最终结果中高价股（66、85）被做多，低价股（5、15）被做空。

### 平台实现方式补充

在实际平台上，这个计算过程完全自动化，你可能只需在设置中把 Neutralization 选为 "Market"，系统就会自动完成上述所有步骤

### 评论 #17 (作者: LY66597, 时间: 4个月前)

作业1：

![图片](../images/img_a19d2c5a05.png)

作业2：

作业3：

根据题意，条件如下：

1.全市场共5个股票，收盘价(即close)分别为[5,15,66,85,25]

2. Alpha表达式为 **"-close'（注意负号)**

3.Neutralization Setting为Market的情况，也就是说对全市场进行中性化。

第一步：计算alpha向量

根据表达式为"-close'：

股票1： 5=-5

股票2：15=-15

股票3：66=-66

股票4：85=-85

股票5：25=-25

alpha向量就是：[-5, -15, -66, -85, -25]

第二步：中性化

计算平均值：(-5 -15 -66 -85 -25) ÷ 5 = -39.2
每支股票减去平均值：
股票1：-5 - (-39.2) = 34.2
股票2：-15 - (-39.2) = 24.2
股票3：-66 - (-39.2) = -26.8
股票4：-85 - (-39.2) = -45.8
股票5：-25 - (-39.2) = 14.2
中性化后向量：[34.2, 24.2, -26.8, -45.8, 14.2]
验证：（34.2+24.2-26.8-45.8+14.2 = 0）总和为0

第三步：标准化权重

计算绝对值的总和：|34.2| + |24.2| + |-26.8| + |-45.8| + |14.2| = 145.2
每个值除以这个和，得到归一化权重：
股票1：34.2 ÷ 145.2 ≈ 0.2355
股票2：24.2 ÷ 145.2 ≈ 0.1667
股票3：-26.8 ÷ 145.2 ≈ -0.1846
股票4：-45.8 ÷ 145.2 ≈ -0.3154
股票5：14.2 ÷ 145.2 ≈ 0.0978

这5个值就是各个股票的交易权重。

根据上面的权重，Long count为3，即股票1、2、5做多；Short count为2，即股票3和4做空。

根据给定的 Alpha 表达式和 Market 中性化设置，计算过程如下：

**1. 计算原始 Alpha** 
Alpha 表达式为  `-close` ，因此 5 只股票的原始 Alpha 值为：
 `[-5, -15, -66, -85, -25]`

**2. 市场中性化处理** 
Market 中性化通常指在横截面上减去所有股票 Alpha 的均值，以消除市场整体涨跌的影响。
原始 Alpha 均值 =  `(-5 -15 -66 -85 -25) / 5 = -39.2` 
中性化后 Alpha = 原始 Alpha - 均值：
 `[34.2, 24.2, -26.8, -45.8, 14.2]`

**3. 计算交易权重** 
对于市场中性组合，通常以中性化后的 Alpha 按绝对值和归一化得到最终权重，使组合多空总杠杆为 100%（即总多头权重 = 0.5，总空头权重 = -0.5）。
绝对值和 =  `34.2 + 24.2 + 26.8 + 45.8 + 14.2 = 145.2`

各股权重 = 中性化 Alpha / 绝对值和：

- 股票1 (close=5)： `34.2 / 145.2 ≈ 0.2355`
- 股票2 (close=15)： `24.2 / 145.2 ≈ 0.1667`

- 股票5 (close=25)： `14.2 / 145.2 ≈ 0.0978`
  **4. 多空数量** 权重 > 0 为做多，权重 < 0 为做空：

- Sharpe (夏普比率)

◦ 通俗解释： 衡量你每一分钱的风险换来了多少超额收益。

◦ 现状分析： 你这里是 -0.00，说明策略目前几乎没有收益，甚至跑输了无风险收益（比如存银行）。优秀的策略通常要求 > 1。

- Turnover (换手率)

◦ 中译： 换手率 / 周转率

分子： 你这一天里所有买卖操作的资金总额（不管买还是卖，都算进去，不抵消）。

分母： 你的总资金（比如你拿了 100 万，分母就是 100 万）

◦ 通俗解释： 你“折腾”了多少资金。

◦ 现状分析：0.93% 说明策略比较稳定，不会频繁买卖（一把梭哈），这对于控制交易成本是好事。

今天把所有 100 万的股票全卖了，又瞬间用这 100 万全买了新的股票。

分子 = 100万（卖） + 100万（买） = 200万元

分母 = 100万元

Turnover = 200%

含义： 你一天内就把整个账户的仓位整个翻了个底朝天。

◦ 中译： 适应度 / 得分

多头市值 (Long Value)：你现在买入持有的股票总价值。

1、Neutralization中性化：

中性化是用于使我们的策略市场/行业/子行业中性的操作。当中性化 =“市场”时，它执行以下操作:

Alpha = Alpha – mean(Alpha)

其中 Alpha 是权重向量.

实际上，它使 Alpha 向量的平均值为零。因此，与市场相比没有净头寸。换句话说，多头暴露完全抵消了空头暴露，使我们的策略市场中性。

当中性化 = 行业或子行业时，Alpha 向量中的所有股票都分组到对应的行业或子行业中，并分别应用中性化。有关行业/子行业分类的说明，请参见 GICS （注意：这不一定是 BRAIN 平台使用的相同分类标准）。

2、ts_std_dev(x, d)

运算符返回输入序列 x 过去 d 天的标准差。标准差是一个重要的统计指标，用于量化数据集的变异程度或离散程度。在时间序列的上下文中，它可以帮助您了解某个变量（例如收益率或价格）在指定时间段内的波动性或稳定性。

标准差越低，表示数值越接近平均值；而标准差越大，表示数值分布越分散。

计算示例

假设您有某股票过去 5 天的每日收益率：

x = [0.01, 0.02, -0.01, 0.00, 0.03]

计算 5 天标准差：

计算平均值：

(0.01 + 0.02 + -0.01 + 0.00 + 0.03) / 5 = 0.01

计算平方偏差：

(0.01 - 0.01)² = 0

(0.02 - 0.01)² = 0.0001

(-0.01 - 0.01)² = 0.0004

(0.00 - 0.01)² = 0.0001

(0.03 - 0.01)² = 0.0004

平方偏差的平均值：

(0 + 0.0001 + 0.0004 + 0.0001 + 0.0004) / 5 = 0.0002

取平方根：

sqrt(0.0002) ≈ 0.0141

因此，ts_std_dev(x, 5) 将返回约 0.0141。

示例

ts_std_dev(returns, 21)

计算每日收益率的 21 天滚动标准差；作为一个月股票波动率的代理指标。

- 无计算公式，是股票筛选规则

### 5. Delay（延迟）

**定义**：数据可用性相对于决策时间的时间差。

| Delay 值 | 含义 |

|---------|------|

| **0** | 当天收盘前看到数据，当天交易（最激进） |

| **1** | 今天看到数据，明天交易（保守，1天滞后） |

**公式表达**：

```

持仓日期 = 数据日期 + Delay

```

---

### 6. Decay（衰减）

**定义**：将今天的值与前 n 天的衰减值相结合，执行线性衰减函数。

**公式**：

Decay\_linear(x,n)=x[date]⋅n+x[date−1]⋅(n−1)+⋯+x[date−n+1]⋅1n+(n−1)+⋯+1

**简化形式**：

Decay\_linear(x,n)=∑i=0n−1x[date−i]⋅(n−i)n(n+1)2

**参数约束**：

- $n \geq 0$，必须为整数

- 使用负数或非整数值会破坏回测

---

### 7. Truncation（截断）

**定义**：整体组合中每只股票的最大权重。

**公式**：

Weighti=min(Weighti,Truncation)

**参数约束**：

- $0 \leq \text{Truncation} \leq 1$

- 推荐值：0.05 ~ 0.1（涵盖 5%-10%）

**作用**：防止过度暴露于个别股票的波动。

---

### 8. Neutralization（中性化）

**定义**：使策略在市场/行业/子行业中性的操作。

#### (1) 市场中性化（Market）

Alpha=Alpha−mean(Alpha)

**效果**：Alpha 向量平均值为零，与市场相比没有净头寸。

#### (2) 行业/子行业中性化（Industry/Subindustry）

Alphai=Alphai−mean(Alphagroup)

其中 $\text{group}$ 为股票所属的行业或子行业分类。

---

### 9. Pasteurization（消毒）

**定义**：将不在 Alpha 股票池中的输入值替换为 NaN。

| 设置 | 行为 |

|-----|------|

| **On** | 未在 Universe 中选择的股票，其输入转换为 NaN |

| **Off** | 不发生此操作，使用所有可用输入 |

**公式逻辑**：

```

if Pasteurize == "On":

if stock not in Universe:

value = NaN

```

### 10. NaN Handling（NaN 处理）

**定义**：将 NaN 值替换为其他值。

| 设置 | 时间序列运算符 | 群组运算符 |

|-----|-------------|----------|

| **On** | 所有输入为 NaN → 返回 0 | 单只股票输入为 NaN → 返回该组均值 |

| **Off** | 所有输入为 NaN → 返回 NaN | 单只股票输入为 NaN → 返回 NaN |

### 11. Unit Handling（单位处理）

**定义**：在运算符中使用不兼容的量纲时发出警告。

- 例如：试图将价格加上成交量，会显示警告

- 无具体计算公式，是数据校验机制

## 二、IS Summary（样本内测试摘要）

### 关键绩效指标

| 指标 | 计算公式 |

|-----|---------|

| **Sharpe（夏普比率）** | $\text{Sharpe} = \frac{R_p - R_f}{\sigma_p}$，其中 $R_p$ 为策略收益，$R_f$ 为无风险利率，$\sigma_p$ 为收益标准差 |

| **Turnover（换手率）** | $\text{Turnover} = \frac{\sum_{t} \sum_{i} |\text{Weight}_{i,t} - \text{Weight}_{i,t-1}|}{2}$ |

| **Fitness（适应度）** | $\text{Fitness} = \text{Sharpe} \times \sqrt{|\text{Returns}|} \times \text{稳定性因子}$（平台自定义公式） |

| **Returns（收益率）** | $\text{Returns} = \frac{\text{期末价值} - \text{期初价值}}{\text{期初价值}} \times 100\%$ |

| **Drawdown（最大回撤）** | $\text{Drawdown} = \max_{t} \left( \frac{\text{峰值}_t - \text{当前值}_t}{\text{峰值}_t} \right) \times 100\%$ |

| **Margin（保证金/利润率）** | $\text{Margin} = \frac{\text{总收益}}{\text{总交易额}} \times 1000‰$ |
