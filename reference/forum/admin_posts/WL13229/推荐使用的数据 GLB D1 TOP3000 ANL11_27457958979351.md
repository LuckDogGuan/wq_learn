### 评论 #2 (作者: ZZ47696, 时间: 2个月前)

感谢分享 ANL11 这组 ESG/治理字段。补一条从  **GLB 高换手（HTVR / Liquid 子主题）** 角度的实测边界，供想拿它冲 HTVR 的同学避坑：

**1. ESG/治理/分析师类 model 集在"降相关"上确实对口，但换手率是硬约束。** 这类字段与纯技术面（价量）内核异源，PROD_CORR 天然低——这正是"换数据集降 PC"的刚需。但它们更新频率偏低（季度/年度 backfill 到日频），直接建因子换手率上不去，对需要  `Tvr>0.20`  且  `ht_ratio>0.75`  的 HTVR Liquid 线不对口。

**2. 我方对照实测：** 纯技术面短反转×放量内核在 GLB 能稳过 ht>0.75，但同一 kernel 的 PROD_CORR 被生产书结构性钉死在 0.66~0.71，提交一条后同族全撞 SELF_CORRELATION（一个 kernel 只能交一条）。反过来，低频 model 集（本帖 ANL11、以及 analyst16 实测 PROD_CORR 仅 0.2070）PC 虽极低，却栽在 Investability Constrained Sharpe / 换手不足。

**3. 结论——高换手(ht)与低相关(PC)在数据集维度上也是对立的：** 纯技术面拿 ht 丢 PC，低频 model 集拿 PC 丢 ht/investability。唯一能同时满足二者的落点＝ **事件/新闻驱动的【日频】异源单数据集** （新闻舆情评分/事件信号类），既日频高换手、又与技术面异源低相关。

**4. 若坚持用 ANL11 建高换手因子：** 先用  `ts_std_dev`  常数线检测 backfill 造成的"假日频"（连续常数段＝无真实更新），再外套  `ts_zscore(x,250)`  或  `x-ts_mean(x,d)`  这类高通把有效更新的短波提出来才可能顶起 ht——但 coverage/更新频率仍是天花板，不要期望它同时给到 HTVR 级别的换手。
