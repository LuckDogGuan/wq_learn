### 评论 #1 (作者: LA79055, 时间: 6天前)

遇到 429 时先区分认证失效和请求频率触发限流，会比直接套用某个并发控制方案更稳。这个专题把 429、session/cookie 复用、OAuth token 过期和 4xx/5xx 处理分散保留在独立原帖，正好支持这种排查顺序：先看 token/session 是否还有效，再看是不是并发或触发速率限制。2025 到 2026 年多篇 429 相关帖子并列，指数退避、动态并发、复用 session cookie 与 cookie 文件等方法的前提和边界从目前信息看并未在目录中展开，建议进入原帖先确认适用环境与版本。香港地区 API 登录和 EUR 地区解析 warning 这类条目也提示地区或环境差异值得单独核对。目录已注明不认证代码安全性、平台规则与活动时效，涉及权限、保密规则或可直接运行的代码时，仍应以对应原帖和现行规则为准。
