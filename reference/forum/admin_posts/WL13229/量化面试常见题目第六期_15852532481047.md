### 评论 #1 (作者: WL13229, 时间: 3年前)

假设一只蚂蚁在一个长度为6的直线上进行随机游走，蚂蚁初始位置在3。每一步，蚂蚁按照相等的概率向左或向右移动一格。如果蚂蚁到达直线的两端（位置1和位置6），它就不能再移动。

1. 求蚂蚁首次到达位置1或位置6的期望步数。
2. 在给定蚂蚁首次到达位置1或位置6需要10步的情况下，求蚂蚁最后到达位置1的概率。

### 评论 #5 (作者: YZ79726, 时间: 3年前)

有个疑问，如果绳子长度为6，端点的位置不应该是0和6吗？

所以绳子长度应该是5？

以下解答基于这个假设：绳子长度为5，用0,1,2,3,4,5表示位置1，位置2 ···位置6

```
1. 已知E(i+1) - 2E(i)+E(i-1) + 2 = 0, subject to E(0) = 0, E(5) = 0,特征方程的形式为λ^2-2λ+1=0.得出λ=1.E(i)的通解的形式为（A+Bi）特解的形式为 Ci^2将特解带入原方程，得到C=-1.将E(0)=E(6)=0,带入E(i)=（A+Bi）+ Ci^2, 得到A=0, B=5.所以E(i) = i(5-i).E(位置3)=E(2) = 2*3 = 6（如果绳子长度为6，有七个点的情况，E(位置3)=3*3=9）
```

```
2. distance(位置3,位置1) = 2distance(位置3,位置6) = 3所以在移动10步的情况下，不可能到达位置6所以P(位置1|STEP=10) = 1
```

### 评论 #11 (作者: BA51127, 时间: 1年前)

蚂蚁在直线上的游走问题可以通过建立递归关系来解决，这需要对概率和随机过程有深入的理解。

对于第一个问题，我们可以通过设置一个递归方程来解决。如果蚂蚁从位置3开始，那么它到达位置1或6的期望步数可以通过考虑蚂蚁下一步可能到达的位置来计算。这可以通过以下递归方程来描述：E(i) = 1 + 0.5 * E(i-1) + 0.5 * E(i+1)，其中E(i)是从位置i开始到达边界的期望步数。通过边界条件E(1) = E(6) = 0，我们可以解这个方程来找到E(3)。

对于第二个问题，如果我们知道蚂蚁首次到达位置1或6需要10步，那么我们需要计算蚂蚁最后停在位置1的概率。这个问题可以通过考虑蚂蚁在第9步的位置来解决。由于蚂蚁在第10步只能向左或向右移动一步，所以它在第9步时必须在位置2或位置4。我们可以计算从位置2和位置4开始，在下一步到达位置1的概率，然后将这两个概率相加得到最终结果。
