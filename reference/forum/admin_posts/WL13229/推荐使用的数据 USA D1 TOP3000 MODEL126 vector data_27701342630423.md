### 评论 #10 (作者: YX37105, 时间: 2个月前)

原帖里大量使用  `ts_corr` 、 `ts_covariance`  和  `ts_regression`  组合，表面看是想量化 country 因子与 industry、sector、revision 等属性之间的同步或领先关系。但有一个容易被忽略的坑： `ts_corr`  默认对两个序列做滚动相关，窗口长度  `d`  的选择会直接影响结果稳定性，尤其当底层因子是 rank 或 score 的混合时，两者的尺度差异会让相关系数对异常值非常敏感。
