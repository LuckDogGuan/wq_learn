## 帖子正文

![图片](../images/img_ee8681e22e.jpeg)

Alpha implementation 是实现一个Alpha想法的核心步骤。同样的想法，在不同的写法中，可能会获得不同的效果，以return为例，数据字段"returns"，给我们提供了每日的收益率。但是，除了使用内置的数据字段，我们也可以自己计算return。现在让我们探寻4种不同的周度收益率计算方法！

方法1：直接计算

计算周收益率最直接的方法是考虑一周内的价格差异。你可以使用ts_delta()操作符来计算当前值与N个周期前的值之间的变化。

周收益率的公式是：ts_delta(close, 5) / ts_delay(close, 5)

在这里，ts_delta(close, 5)计算了5天（一周）内收盘价的差异，ts_delay(close, 5)获取了5天前的收盘价。除法给出了相对于一周前价格的变化比例。

方法2：累计收益率

计算周收益率的另一种方法是将每日收益率相乘。当每日收益率较小时，这种方法很有用，但是当每日收益率较大时，可能引入较大的误差。

周收益率的公式是：ts_product(returns + 1, 5) - 1

在这里，returns + 1将每日收益率转换为增长率。ts_product(returns + 1, 5)计算了一周内的累计增长，减去1将其转换回收益率。

方法3：对数收益率

这种方法使用增长因子的对数来计算收益率。与方法2类似，它可以计算一段时间的累计收益率，它在收益率很大时仍具有更为稳定的数值距离。

周收益率的公式是：exp(ts_sum(log(returns + 1), 5)) - 1

log(returns + 1)计算每天的对数收益率。ts_sum(log(returns + 1), 5)对一周内的对数收益率求和，exp函数将累计的对数收益率转换回增长因子，然后减去1以获得收益率。

方法4：使用ts_returns操作符

简单地使用ts_returns(close, 5)就可以得到周收益率。

### 评论 #1 (作者: WD90077, 时间: 2年前)

感谢老师的分享，受益匪浅！！！

一种简单的收益率计算方法是使用内置函数计算平均收益率，即使用 ts_mean(returns, d)。这种方法能够平滑收益率的波动，但可能忽略极端值的影响。因此，可以考虑使用 ts_median 来计算收益率的中位数，以减少极端值对结果的影响。

此外，延伸思考到 ts_std_dev 和 ts_skewness 的使用。ts_std_dev 可以用于分析收益率的波动性，而 ts_skewness 则可以提供收益率分布形状的信息。虽然这两个指标不能直接提供具体的收益信息，但它们在一定程度上能够揭示市场的潜在信息，有助于发现和发掘市场机会。
