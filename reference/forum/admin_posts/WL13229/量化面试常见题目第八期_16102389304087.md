感谢大家对往期问答的积极参与，现在让我们发布第八期量化面试常见题目。

**本期问题：**

一个醉汉在直角坐标系的原点 (0,0) 开始随机游走。他的每一步都是随机的，有四个可能的方向：上，下，左，右，每个方向的概率相同。每一步的长度为1。

定义函数d(n)表示醉汉在n步后离原点的期望距离。

1. 请给出d(1)和d(2)的值。
2. 请推出d(n)的一般形式。
3. Reality check: 在面试中，面试官可能会循序渐进地向你提问，以不断深入考察你的抽象思维和数学能力。

**提示：**

你可以使用马尔可夫链理论和数学期望的性质来解决这个问题。

### 评论 #4 (作者: WL13229, 时间: 3年前)

对于最后一题。让我们尝试使用代码解决：

```
import randomimport mathimport numpy as npimport matplotlib.pyplot as pltdef random_walk(n):    x, y = 0, 0    for _ in range(n):        direction = random.choice(["上", "下", "左", "右"])        if direction == "上":            y += 1        elif direction == "下":            y -= 1        elif direction == "左":            x -= 1        elif direction == "右":            x += 1    return x, ydef calculate_distance(n, num_simulations):    total_distance = 0    for _ in range(num_simulations):        x, y = random_walk(n)        distance = math.sqrt(x ** 2 + y ** 2)        total_distance += distance    return total_distance / num_simulationsnum_simulations = 10000step_range = range(1, 51)  # 计算1到50步的平均距离average_distances = [calculate_distance(n, num_simulations) for n in step_range]plt.plot(step_range, average_distances, marker='o')plt.xlabel("步数 (n)")plt.ylabel("与原点的平均距离")plt.title("醉汉游走：步数与平均距离的关系")plt.grid(True)plt.show()
```

### 评论 #5 (作者: YZ61104, 时间: 3年前)

等了一段时间没有看到后续的解答，附上一个网上看到的解答：原网址如下 [Expected Value of Random Walk - Mathematics Stack Exchange](https://math.stackexchange.com/questions/103142/expected-value-of-random-walk)

在d维的随机游走,第N步距离原点的距离在N趋向于无穷时大概是

\sqrt{2N/d}*Gamma((d+1)/2)/Gamma(d/2)
