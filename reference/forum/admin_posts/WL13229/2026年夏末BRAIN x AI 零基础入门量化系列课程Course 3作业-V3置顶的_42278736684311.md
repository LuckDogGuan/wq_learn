### Task 1：任选一数据集，使用 AI 为数据集提供至少 3 个模板

我选择的数据集是  **analyst4** 。该数据集主要包含分析师预测、预期修正和预测分歧等信息。基于该数据集，我使用 AI 设计了以下 3 个 Alpha 模板。

#### 模板一：分析师预期修正

```
group_rank(ts_delta(<analyst_field>, <lookback>), <group>)

```

该模板用于衡量分析师预测字段在一段时间内的变化，并在行业或子行业内部进行排名。

核心逻辑是：如果分析师近期持续上调对某家公司的预测，可能说明市场对该公司未来基本面的预期正在改善。

#### 模板二：分析师预期的历史位置

```
group_rank(ts_rank(<analyst_field>, <lookback>), <group>)

```

该模板用于衡量当前分析师预测值，在该公司自身历史数据中所处的相对位置，再在同行业内进行排名。

核心逻辑是：如果当前预测值处于历史较高位置，可能说明公司当前的盈利或经营预期相对较强。

#### 模板三：分析师预测分歧

```
group_rank(-ts_mean(<dispersion_field>, <lookback>), <group>)

```

该模板用于计算一段时间内分析师预测分歧的平均水平，并对其取负后进行组内排名。

核心逻辑是：分析师分歧越小，代表市场对公司未来表现的判断越一致，信号可能更加稳定。

### 模板中的可替换参数

```
<analyst_field>：analyst4 中的分析师预测字段
<dispersion_field>：analyst4 中的分析师分歧字段
<lookback>：5、20、60、120
<group>：sector、industry、subindustry

```

以上三个模板分别对应：

```
预期变化
历史相对位置
分析师分歧

```

它们都可以在后续通过替换字段、时间窗口和分组方式，展开成多个具体 Alpha 表达式。

## Task 2：选择一个模板，使用代码将其展开并拼装成多个表达式，并阐述其搜索空间

我选择 Task 1 中的“分析师预期历史位置”模板：

```
group_rank(ts_rank(<analyst_field>, <lookback>), <group>)

```

该模板先使用  `ts_rank`  判断当前分析师预测值在公司自身历史数据中的相对位置，再使用  `group_rank`  在板块、行业或子行业内部进行排名。

核心假设是：

> 当分析师对某家公司的预测处于该公司自身历史较高位置时，可能说明当前基本面预期较强；在相似公司中排名较高的股票，未来可能具有更好的相对表现。

### 代码展开

```
analyst_fields = [
    "field_1",
    "field_2",
    "field_3"
]

lookbacks = [20, 60, 120, 252]

groups = [
    "sector",
    "industry",
    "subindustry"
]

expressions = []

for field in analyst_fields:
    for lookback in lookbacks:
        for group in groups:
            expression = (
                f"group_rank("
                f"ts_rank({field}, {lookback}), "
                f"{group}"
                f")"
            )
            expressions.append(expression)

print("共生成表达式数量：", len(expressions))

for expression in expressions:
    print(expression)

```

### 生成的表达式示例

```
group_rank(ts_rank(field_1, 20), sector)

group_rank(ts_rank(field_1, 20), industry)

group_rank(ts_rank(field_1, 20), subindustry)

group_rank(ts_rank(field_1, 60), sector)

group_rank(ts_rank(field_2, 120), industry)

group_rank(ts_rank(field_3, 252), subindustry)

```

### 搜索空间说明

本次搜索空间由三个维度构成：

维度
数量

分析师字段
3

时间窗口
4

分组方式
3

因此总共可以生成：

```
3 × 4 × 3 = 36

```

个候选 Alpha 表达式。

搜索空间可以表示为：

```
Alpha Space
=
Analyst Fields
× Lookback Windows
× Grouping Methods

```

其中：

- `analyst_fields` ：用于比较不同类型的分析师预测信息；
- `lookbacks` ：用于比较短期、中期和长期历史位置；
- `groups` ：用于比较板块、行业和子行业内部的相对强弱。

不同时间窗口的含义大致为：

```
20：约一个月
60：约一个季度
120：约半年
252：约一年

```

这组搜索并不是随机拼接运算符，而是在保持“分析师预期历史位置”这一经济逻辑不变的前提下，对字段、观察周期和分组方式进行系统化展开。

> 放量不涨 = 出货/阻力，后续倾向于下跌。

```

```

- **核心字段** ： `returns` ,  `volume` ,  `adv20`
- **核心算子** ： `ts_corr`

- **Turnover** ：中高
- **与主线相关性低** ，适合做多样性补充

> 短期内上涨过多的股票可能回调，短期内下跌过多的股票可能反弹。

```
-ts_delta(close, 3)
```

- **核心字段** ： `close`
- **核心算子** ： `ts_delta`
- **逻辑** ：过去3天涨得多 → 因子值低 → 倾向做空；过去3天跌得多 → 因子值高 → 倾向做多
