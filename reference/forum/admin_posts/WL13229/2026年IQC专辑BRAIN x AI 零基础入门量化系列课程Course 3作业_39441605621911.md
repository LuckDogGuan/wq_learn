模板 1：变化型模板
<group_compare_op>(<sign><ts_compare_op>(<company_fundamentals>, <days>), <group>)

含义：先看某个基本面字段在一段时间内的变化，再在行业或板块内部比较。

模板 2：历史位置型模板
<group_compare_op>(<ts_position_op>(<company_fundamentals>, <days>), <group>)

含义：先看当前基本面字段在其自身历史中的相对位置，再在组内比较。
例如，当前现金流是否处于过去一年中的高位。

模板 3：稳定性型模板
<group_compare_op>(<sign><ts_risk_op>(<company_fundamentals>, <days>), <group>)

含义：先衡量某个基本面字段在过去一段时间内的波动，再在组内比较稳定性。
例如，EBITDA 波动越小，通常说明经营更稳定。

group_rank(ts_zscore(revenue, 20), market)

下面我将用代码将其展开为多个变体表达式，并阐述这些变体构成的搜索空间。

## 一、代码：展开并拼装多个因子表达式

python

```
# 参数搜索空间定义
fields = ['revenue', 'net_profit', 'eps', 'gross_margin']   # 可选财务字段
windows = [10, 20, 40, 60, 120]                             # 滚动窗口长度
transformations = ['ts_zscore', 'ts_sum', 'ts_mean', 'ts_delta']  # 时序变换函数
ranking_groups = ['market', 'industry', 'subindustry']      # 排名分组

expressions = []

# 遍历所有组合，生成 Fast Expression 字符串
for field in fields:
    for win in windows:
        for trans in transformations:
            # 构建内层变换表达式
            if trans == 'ts_zscore':
                inner = f"ts_zscore({field}, {win})"
            elif trans == 'ts_sum':
                inner = f"ts_sum({field}, {win})"
            elif trans == 'ts_mean':
                inner = f"ts_mean({field}, {win})"
            elif trans == 'ts_delta':
                # ts_delta 需要滞后长度，这里用 win 作为 delta 步长
                inner = f"ts_delta({field}, {win})"
            else:
                continue

            for group in ranking_groups:
                expr = f"group_rank({inner}, {group})"
                expressions.append(expr)

# 打印前 10 个示例
for i, e in enumerate(expressions[:10]):
    print(f"{i+1}: {e}")

print(f"\n总共生成表达式数量: {len(expressions)}")
```

**输出示例** （前10个）：

text

```
1: group_rank(ts_zscore(revenue, 10), market)
2: group_rank(ts_zscore(revenue, 10), industry)
3: group_rank(ts_zscore(revenue, 10), subindustry)
4: group_rank(ts_sum(revenue, 10), market)
5: group_rank(ts_sum(revenue, 10), industry)
6: group_rank(ts_sum(revenue, 10), subindustry)
7: group_rank(ts_mean(revenue, 10), market)
8: group_rank(ts_mean(revenue, 10), industry)
9: group_rank(ts_mean(revenue, 10), subindustry)
10: group_rank(ts_delta(revenue, 10), market)
...
```

**总数量** ： `4个字段 × 5个窗口 × 4种变换 × 3种分组 = 240个表达式` 。

## 二、搜索空间阐述

上述代码定义的搜索空间包含  **240 个不同的 Fast Expression 因子** 。该空间由以下四个维度构成：

### 1. 财务字段维度（4种）

- `revenue` （营业收入）
- `net_profit` （净利润）
- `eps` （每股收益）
- `gross_margin` （毛利率）

每个字段代表公司财报的不同基本面切片，对股票未来收益的预测能力不同。例如， `eps`  突变常被市场快速反应，而  `gross_margin`  趋势可能预示长期竞争力。

### 2. 时序变换维度（4种）

- `ts_zscore(x, w)` ：滚动 z-score，度量当前值偏离历史均值的标准差倍数，捕捉异常变化。
- `ts_sum(x, w)` ：滚动求和，累计效应（如近一季度总营收）。
- `ts_mean(x, w)` ：滚动平均，平滑噪音。
- `ts_delta(x, w)` ：当前值与 w 期前的差值，直接反映变化量。

不同变换提取信号的不同数学特征。例如  `ts_zscore`  对波动敏感， `ts_mean`  更稳定。

### 3. 窗口长度维度（5种）

- `[10, 20, 40, 60, 120]` （交易日，约对应 2周～6个月）

窗口决定信号的时间尺度。短窗口（10）捕捉短期财报冲击，长窗口（120）反映长期趋势。财务数据通常按季披露，窗口长度应大于季报间隔（约60个交易日），否则易产生大量缺失值。

### 4. 排名分组维度（3种）

- `market` ：全市场排名（最宽泛）
- `industry` ：行业内部排名（消除行业差异）
- `subindustry` ：子行业内部排名（更细粒度中性化）

`group_rank`  输出 0~1 的排名信号，分组排名可以控制信号对行业暴露的敏感度。子行业排名通常能获得更纯的选股效果。

### 1. 模板 A：分歧度加权偏离模板 (Risk-Adjusted Surprise)

**逻辑：**  单纯的预期修正（Surprise）可能带有随机性。该模板通过分析师分歧度（Dispersion）进行加权，只有在分析师意见趋同（分歧小）的情况下，出现的预期偏差才被视为强信号。

> **`group_rank(ts_av_diff(datafield, 20) / (snt1_d1_dtstsespe + 0.01), industry)`**

- **适用字段：**   `snt1_d1_earningssurprise` ,  `snt1_d1_earningsrevision`
- **优化点：**  使用  `ts_av_diff`  自动处理 NaN，通过分母惩罚高波动/不确定性。

### 2. 模板 B：双重平滑动量模板 (High Stability Momentum)

**逻辑：**  分析师情绪具有惯性。该模板通过  `ts_zscore`  识别极端情绪跳变，再通过  `ts_decay_linear`  进行线性衰减平滑。这是降低  **Turnover**  并提升  **Sharpe**  的杀手锏。

> **`group_rank(ts_decay_linear(ts_zscore(datafield, 20), 10), sector)`**

- **适用字段：**   `snt1_cored1_score` ,  `snt1_d1_netrecpercent` ,  `snt1_d1_stockrank`
- **优化点：**   `ts_zscore`  捕捉统计显著性， `ts_decay_linear`  过滤噪音，让信号“慢下来”。

### 3. 模板 C：置信度准入复合模板 (Coverage-Filtered Alpha)

**逻辑：**  只有当覆盖该股票的分析师达到一定数量（如 5 人以上）时，信号才具有统计学意义。同时通过  `ts_delta`  捕捉情绪的变化量而非存量。

> **`if_else(snt1_d1_analystcoverage > 5, group_rank(ts_delta(datafield, 5), industry), NaN)`**

- **适用字段：**   `snt1_d1_buyrecpercent` ,  `snt1_d1_uptargetpercent`
- **优化点：**  使用  `if_else`  暴力剔除“僵尸股”或孤儿股，通过  `ts_delta`  寻找边际变化最剧烈的标的。

- **分子 (Signal):**  所有的动量和占比指标（如  `earningsrevision` ,  `netrecpercent` ,  `stockrank` ）。
- **分母 (Risk/Filter):**  除了  `snt1_d1_dtstsespe` （估值离散度）外，还可以尝试  `ts_std_dev(datafield, 20)` （指标自身波动率）或  `snt1_d1_analystcoverage` （作为权重的倒数）。

- **偏离度周期:**   `ts_av_diff`  中的 $d$。搜索范围：$d \in \{10, 20, 40, 60\}$。
  - $d=10$ 捕捉财报季期间的快速反应。
  - $d=60$ 捕捉分析师由于行业基本面改变而进行的缓慢调仓。

#### 3. 分组维度空间 (Grouping Space $\mathcal{G}$)

- 根据数据集覆盖范围，尝试不同的中性化层级：
  - `industry` : 较细颗粒度，适合捕捉个股在细分领域的相对优势。
  - `sector` : 较粗颗粒度，适合捕捉大板块的情绪轮动。

#### 4. 非线性变换空间 (Transformation Space $\mathcal{T}$)

- **平滑处理:**  如果产生的 Alpha 换手率过高，可以将整个表达式嵌套进  `ts_decay_linear(alpha, 10)` 。
- **准入过滤:**  结合  `if_else` 。例如： `if_else(snt1_d1_analystcoverage > 5, alpha, NaN)` 。
- **惩罚项常数:**  表达式中的  `+ 0.01` 。搜索范围：$\{0.001, 0.01, 0.1\}$。这个常数决定了你对低分歧个股的奖励程度。

#### 5. 算子替代空间 (Operator Space $\mathcal{O}$)

- 将  `ts_av_diff(x, d)`  替换为  `ts_zscore(x, d)` 。
  - `ts_av_diff`  侧重于 **绝对偏离** 。
  - `ts_zscore`  侧重于 **统计显著性** （已经自带了标准差除法）。

三、搜索空间阐述

搜索空间指的是：在构建模板时，某些关键参数可以取不同值，这些参数的所有可能取值组合构成的空间。

对于模板二，搜索空间由以下维度组成：

参数 含义 搜索空间（可能取值）
T 情绪异常阈值 {1.5, 2.0, 2.5, 3.0}
R 量能激增阈值（增长率） {1.0, 1.5, 2.0, 3.0} (即100%,150%,200%,300%)
W 量能比较基准 {前1日, 前3日均值, 前5日均值}

搜索空间大小 = 4 × 4 × 3 = 48 种组合

例如：

· 组合1：T=2.0, R=2.0, W=前1日 → 当前模板
· 组合2：T=1.5, R=1.5, W=前3日均值 → 更敏感的监控模板
· 组合3：T=3.0, R=3.0, W=前5日均值 → 更保守的监控模板
