今天，让我们深入探讨如何利用市盈增长比率（Price/Earnings to Growth，PEG）来发现 Alpha 思想。PEG 比率是一种股票估值指标，它在传统市盈率（P/E）的基础上加入了公司的盈利增长率。这个指标帮助分析师判断市场是否低估或者高估了股票价格与其盈利增长前景之间的关系。

```
📊 基本PEG公式PEG 比率的基本公式是：PEG = P/E/G其中：(P/E) = 市盈率(G) = 预期年度盈利增长率
```

🔍  **各组成部分解释** 
 **市盈率 (P/E)：**  这是公司当前股价与每股收益（EPS）的比率。它显示了投资者今天为每赚取一美元盈利愿意支付的价格。

P/E ＝ 当前股票价格 ÷ 每股收益

```
预期盈利增长率 (G)： 这是公司盈利预期的年度增长率。你可以通过历史盈利增长率、分析师预测或公司指导进行估算。G = (E(t+1) - E(t)) / E(t)其中：(E(t+1)) = 预期下一年的盈利(E(t)) = 本年度盈利
```

🔗  **利用PEG寻找Alpha** 
PEG 比率使你可以在相同基础上比较拥有不同增长率的公司估值情况：

📐  **第一种模板** 
一种常见方法是识别PEG比率低于1的股票，这通常显示该股票相对于其增长潜力可能被低估。相反，PEG比率高于1可能暗示被高估。

例如，你可以使用下面的模板来创建一个捕捉行业内部相对低估或高估情形的 Alpha：

```
 -group_zscore(P / E / G - 1, industry)
```

这个模板计算了基于PEG估值的行业标准化差异。

你可以从现有数据字段中获取 P/E 和 G，或者使用上面的公式自行计算。

或者，你也可以将其构造为：

```
  <group_compare_op>(<cs_compare_op>(P/E , G), <group>)
```

其中：

•  `<cs_compare_op>` ：计算 PEG 比率与市场价格之间差异或比率的操作（例如：减法、除法、向量中性化、回归中性化……）
•  `<group_compare_op>` ：在一个分组内进行比较的操作（例如：group_zscore、group_rank）
•  `<group>` ：分组标准（例如：行业、部门）

✨  **关键点** 
 **数据灵活性：**  变量 (P/E) 和 (G) 可以基于不同的数据源进行估计。你可以使用历史盈利、分析师预估或不同模型来推导预期增长率。或者你可以参考我们之前的帖子，其中讨论了增长率的估算方法！

**抽象操作符：**  操作符和分组变量是占位符，用来代表最符合你假设的选项。例如，如果你更倾向于使用排名而非z分数进行比较， `<group_compare_op>`  可能可以采用 group_rank。

**模型假设：**  请记住，PEG 比率假设增长率保持恒定，因为它只考虑了下一年的增长情况，而这并不一定适用于所有公司。它最适用于盈利增长可预测的公司。

📐  **第二种及更多方法** 
肯定还有更多方法！

和我们之前帖子中提到的类似，这种财务公式的优势在于它为跨不同公司及不同行业之间进行估值指标的比较提供了依据。例如，你可以在不同的预测期内分析 P/E/G 之中的 G 差异，以捕捉公司的增长前景。

### 评论 #5 (作者: BJ10003, 时间: 1年前)

**构建Alpha的两种方法** ：

1. **标准化差异法** ：使用  `<group_zscore(P/E/G - 1, industry)>`  模板，计算行业内部PEG的标准化偏离度，捕捉相对估值机会。
2. **动态比较法** ：结合  `<cs_compare_op>(P/E, G)`  与  `<group_compare_op>` ，例如通过分组排名（ `group_rank` ）或Z-score分析，量化不同周期或风格下的增长预期差异。

**关键注意事项** ：

- **数据灵活性** ：G值可基于历史盈利、分析师预测或模型推导，需结合多源数据增强鲁棒性。
- **模型假设** ：PEG默认增长率恒定，适用于盈利可预测的行业（如消费、科技），但对周期性行业需调整预期。

### 评论 #6 (作者: CM94532, 时间: 2个月前)

帖子把 PEG 的核心逻辑和模板拆解得很清楚，尤其是对 G 的多种数据来源和行业分组的使用，让公式从理论变成了可测试的思路。有个地方值得进一步讨论：PEG 公式里默认把 P/E 和 G 放在除法关系里，但反映增长溢价时，除法和减法其实隐含了不同的假设——除法假设估值与增长成比例变化（比如增长翻倍则合理 P/E 也翻倍），减法假设估值随增长线性平移。对于高增长或低增长的股票，这两种算子筛选出来的股票池差异可能会很大，特别是在跨行业做 group_zscore 之前，P/E/G-1（源自除法）和 P/E - G（减法）虽然是同一种“低估”直觉，实际操作中可能对应着不同的风险暴露和换手率。如果是一个对非稳态增长更敏感的回测周期，减法构造的风险收益特征可能不一样。想确认一下：你们在测试这种模板时，有没有比较过除法与减法这两种算子对最终信号衰减速度或行业中性化后选股集中度的影响？
