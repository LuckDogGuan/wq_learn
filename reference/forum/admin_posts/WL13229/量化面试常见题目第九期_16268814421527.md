## 帖子正文

感谢大家对往期问答的积极参与，现在让我们发布第九期量化面试常见题目。

**本期问题：**

假设我们有一个非均匀的硬币，其在单次抛掷中正面朝上的概率为 p（0 < p < 1）。我们连续抛掷这枚硬币 n 次。

1. 求在 n 次抛掷中，正面朝上恰好 k 次（0 <= k <= n）的概率。
2. 求在 n 次抛掷中，正面朝上至少 1 次的概率。
3. 给定在 n 次抛掷中，正面朝上了 k 次，求下一次抛掷正面朝上的概率。
