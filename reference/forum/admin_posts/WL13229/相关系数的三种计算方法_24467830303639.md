## 帖子正文

相关性是金融建模中使用的一种重要的分析工具。它有助于理解各种证券相互之间的变动情况。接下来，我们将探讨三种计算相关性的不同方法。😄

方法1：Pearson Correlation皮尔逊相关性

皮尔逊相关性测量两个变量之间的线性关系。当变量正态分布并且具有线性线性时，此方法最为有效。

公式如下：

```
ts_corr(x, y, d)
```

在这个公式中，ts_corr(x, y, d) 用来计算 x 和 y 之间的皮尔逊相关性。

方法2：Spearman Correlation斯皮尔曼相关性

与皮尔逊相关性不同，斯皮尔曼相关性并不假设正态分布，它基于变量的排名进行计算，而不是变量本身。当处理有序变量或变量之间的非线性关系时，这种方法特别有用。

你可以使用 group_rank 和 group_mean 运算符来计算斯皮尔曼相关性：

公式如下：

```
rank_x = group_rank(x, group)rank_y = group_rank(y, group)mean_rank_x = group_mean(rank_x, 1, group)mean_rank_y = group_mean(rank_y, 1, group)stddev_rank_x = group_std_dev(rank_x, group)stddev_rank_y = group_std_dev(rank_y, group)spearman_corr = group_mean((rank_x - mean_rank_x) * (rank_y - mean_rank_y),group) / (stddev_rank_x * stddev_rank_y)
```

在这个公式中，group_rank(x, group) 和 group_rank(y, group) 将变量在其组内进行排名。接下来，计算这些排名与其平均值的偏差，将它们相乘，然后得到结果的平均值。这个过程提供了排名的协方差。最后，除以排名的标准差的乘积，得到相关性。

方法3：象限记数比（QCR）

QCR 是一种非参数方法，可以捕捉非线性关系，包括当变量为分类变量时。它根据  **x**  和  **y**  的均值或中位数将 x-y 平面划分为四个象限，并计算每个象限中的点数。

你可以按照以下方式实现它：

```
mean_x = group_mean(x, 1, group)mean_y = group_mean(y, 1, group)I   = group_count((x > mean_x) & (y > mean_y), group)II  = group_count((x < mean_x) & (y > mean_y), group)III = group_count((x < mean_x) & (y < mean_y), group))IV  = group_count((x > mean_x) & (y < mean_y), group))QCR = (I + III - II - IV) / group_count(1, group))
```

这段代码使用 group_mean(x, group) 和 group_mean(y, group) 计算了 x 和 y 的组内平均值。它使用 group_count 计算每个条件下的点数。然后，从这些计数中计算 QCR。

### 评论 #1 (作者: WD90077, 时间: 2年前)

谢谢老师的分享，又受到新的启发！

在考量变量间非线性相关性中，除了Spearman Correlation，还想到Kendall Rank Correlation，主要作用在于评估变量之间的关联性强弱及其方向，而不需要假设变量的分布情况。

优点是：无需正态分布假设，处理非线性关系，具有较强的抗异常值能力，适用于小样本，并且比较易于理解。但缺点是：只关注顺序关系，会使得信息损失，并且不适用于高维数据。

尝试表达如下：

```
rank_x = group_rank(x, group)rank_y = group_rank(y, group)concordant_pairs = group_sum((rank_x < rank_y) * (rank_x - rank_y), group)discordant_pairs = group_sum((rank_x > rank_y) * (rank_x - rank_y), group)kendall_corr = (concordant_pairs - discordant_pairs) / (concordant_pairs + discordant_pairs)
```
