## 帖子正文

大家好，👋。今天分享一个模板的想法，这个想法来源于将分析师的预测与实际收益数据进行比较。这个想法基于这样的观察：当实际基本数据发布与分析师的预测不同步时，市场往往会出现过度反应。用BRAIN表达式表示如下：

Alpha Expression

```
group_zscore(subtract(group_zscore(<act_data>, industry), group_zscore(<est_data>, industry)), industry)
```

这个模板计算了组间归一化的实际数据与估计数据之间的差异。你可以在像 [analyst7](https://platform.worldquantbrain.com/data/data-sets/analyst7?delay=1&instrumentType=EQUITY&limit=20&offset=0&region=USA&universe=TOP3000) 这样的数据集中探索实际数据和估计数据的各种配对。

以下是一个对数据操作的简要总结：

1. **归一化处理：**  模板在行业内对实际财务数据和分析师预测进行归一化处理，使得跨公司间的比较更加公平。
2. **差异识别：**  它突出了归一化的预测数据和实际数据之间的差异，以确定市场预期与现实的偏差，提示潜在的过度反应。
3. **行业比较：**  最后在行业范围内进行一次归一化处理，评估这些差异对行业标准的影响，识别那些显著受到收益意外影响的公司。

这个模板在探索分析师相关数据集方面已经非常有效。请分享你对这个模板如何进一步扩展的想法，并在下面讨论你在使用过程中发现的任何有趣的发现！
