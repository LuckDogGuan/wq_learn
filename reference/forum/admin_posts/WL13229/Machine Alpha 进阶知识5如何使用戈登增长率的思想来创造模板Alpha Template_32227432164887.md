今天，让我们深入探讨如何利用著名的  **戈登增长模型（Gordon Growth Model, GGM）**  来挖掘 Alpha 投资理念。戈登增长模型，也称为  **股息贴现模型（Dividend Discount Model, DDM）** ，是一种基本估值方法，通过基于未来一系列以恒定增长率增长的股息计算股票的内在价值。该框架帮助分析师评估股票相对于当前市场价格是否被低估或高估。

### 📊  **GGM 基本公式**

戈登增长模型的基本公式为：

```
P = D(t=1) / (r - g)
```

其中：

- **P** ：当前股票价格
- **D(t=1)** ：下一年度预期股息
- **r** ：投资者要求的回报率（股权成本）
- **g** ：股息的恒定增长率

### 🔍  **组成部分解析**

1. **预期股息 (D(t=1))** ： 这是公司在下一期预计支付的股息，可以通过将最近的股息  **D(t=0)**  乘以  **1 + g**  计算得出：
   ```
   D(t=1) = D(t=0) * (1 + g)
   ```
2. **要求回报率 (r)** ： 表示投资者对股票投资的预期回报率，通常通过  **资本资产定价模型（CAPM）**  估算：
   ```
   r = R_f + beta * (R_m - R_f)
   ```
   - **R_f** ：无风险利率（可以忽略或设置为常数）
   - **beta** ：股票的 Beta 系数
   - **R_m** ：预期市场回报率
3. **股息增长率 (g)** ： 表示股息预计以恒定速率无限增长。可以基于历史股息增长率或可持续增长率估算：
   ```
   g = b * ROE
   ```
   - **b** ：留存率（保留的收益比例）
   - **ROE** ：股本回报率

### 🔗  **利用 GGM 寻找 Alpha**

一个显而易见的模板是将通过 GGM 计算的内在价值与当前市场价格进行比较：

### 📐  **第一个模板**

从这里开始，你可以构思相关的 Alpha 投资理念。例如，考虑创建一个 Alpha 来捕捉行业内的相对低估或高估。

一个潜在的模板可以是：

```
group_zscore(<D(t=1)> / (<r> - <g>) - ts_mean(close, 21), industry)
```

此模板计算了基于 GGM 的内在价值与当前市场价格之间的行业标准化差异。

其中， `<D(t=1)>` 、 `<r>`  和  `<g>`  可以使用现有数据字段，或者你可以根据上述公式从基础数据中推导出这些值。

或者，你可以将其结构化为：

```
<group_compare_op>(<cs_compare_op>(<D(t=1)> / (<r> - <g>), ts_mean(<price>, 21)), <group>)
```

其中：

- **<cs_compare_op>** ：操作符，用于计算内在价值与市场价格之间的差异或比率（例如： `subtract` 、 `divide` 、 `vector_neut` 、 `regression_neut`  等）
- **<group_compare_op>** ：操作符，用于在组内进行比较（例如： `group_zscore` 、 `group_rank` ）
- **<group>** ：分组标准（例如：行业、板块）

### ✨  **关键点**

1. **数据灵活性** ： 变量  **D(t=1)** 、 **r**  和  **g**  可以根据不同的数据来源进行估算。你可以使用预测股息、分析师对增长率的估算，或者使用不同的模型来估算要求回报率。
2. **抽象化操作符** ： 操作符和分组变量是占位符，用于选择最能捕捉假设的选项。例如， `<group_compare_op>`  可以是  `group_rank` ，如果你更倾向于使用排名而不是标准分数进行比较。
3. **模型假设** ： 请记住，GGM 假设股息以恒定增长率永久增长，这可能并不适用于所有公司。该模型最适用于稳定、成熟且股息增长可预测的公司。

### 📐  **第二个模板及更多**

是的，还有更多！

这种财务公式的美妙之处在于，它为你提供了一个比较两个不同数据点的锚点。例如，你可以比较  **r**  和  **g**  的差异。这个差异捕捉了公司的盈利增长与投资者需求之间的关系。

看了好些个模板和模板的策略，有个很模糊的感觉：很多的因子模板的底层运算逻辑都是在构造某个不同或比较，可以是单个数据字段，也可以是两个数据字段，或者三个或者更多，通过“某种比较”来刻画某个差异性，构造一组向量，最终通过这组向量来实现中性化交易。运算符的作用则是对这种差异化进行定制和深化，使得这种不同具备金融学的现实意义。

我不是很喜欢诸如

```
0.2*a + 0.3*b + 0.3*c
```

形式的因子，因为单个因子乘以一个浮点数，对其所能构造的向量的离散是没有影响的。而通过加法进行组合，在概率层面是代表一个事件的不同方法数量的累加，而乘以一个浮点数则是明显的人工干预，或者，人为的强行叙事。正如CAPM理论只能在完全理想化的市场情景下完美成立一般。
