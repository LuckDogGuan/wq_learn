首先可以通过我的另一篇帖子的方法，查到你要保留或者剔除的某个国家/行业的对应的id编号是什么

[[L2] 通过Labs查看group类型字段的字符串与对应数字id的方法附部分对应表格代码优化_42160653418647.md]([L2] 通过Labs查看group类型字段的字符串与对应数字id的方法附部分对应表格代码优化_42160653418647.md)

这里以EUR TOP2500 delay1的Country字段为例，假设我们要剔除掉英国，查表可以看到英国对应的id是75

![图片](../images/img_5180b1f13b.png)

这里跑一个简单的实例:只回测字段returns，一个版本正常回测不做国家筛选，另一个版本只剔除掉英国，还有一个版本只保留英国，在None中性化下开Visualization进行回测：

```
#全国家from brain.alphas import alphaimport numpy as npimport numpy.typing as npt@alpha(    data=["returns"],    store=[],)def alpha_func(data, store) -> npt.NDArray[np.float32]:    return data.returns[-1].astype(np.float32)
```

```
# 剔除英国from brain.alphas import alphaimport numpy as npimport numpy.typing as nptEXCLUDED_COUNTRY = 75@alpha(    data=["returns", "country"],    store=[],)def alpha_func(data, store) -> npt.NDArray[np.float32]:    returns = data.returns[-1]    country = data.country[-1]    result = np.where(country == EXCLUDED_COUNTRY, np.nan, returns)    return result.astype(np.float32)
```

```
# 只保留英国from brain.alphas import alphaimport numpy as npimport numpy.typing as nptINCLUDED_COUNTRY = 75@alpha(    data=["returns", "country"],    store=[],)def alpha_func(data, store) -> npt.NDArray[np.float32]:    returns = data.returns[-1]    country = data.country[-1]    result = np.where(country == INCLUDED_COUNTRY, returns , np.nan)    return result.astype(np.float32)
```

剔除UK版本回测：UK消失，只剩15个国家

只保留英国版本：结果中有且只有英国

![图片](../images/img_8fdfd1d7c5.png)

**但需要注意的是，上述结果仅限None中性化/非风险中性化(比如market)的时候完美成功，当使用其他风险中性化，比如RAM的时候，由于中性化的存在，似乎即使代码中剔除了英国，回测结果还是能看到英国的部分。**

你观察到的「RAM 下英国还在」是对的，但根因不是回测 bug，而是中性化≠剔除。np.where 把英国信号设成 NaN，平台默认把它当成「不持仓」处理，但 RAM 这类中性化是做回归残差，不是把名字从宇宙里删掉——残差里英国还在，所以可视化里还能看到它。想在信号层彻底让它零仓位，得叠加 trade_when(country != 75, ...) 强制 0，光靠 np.where 不够。另外提醒一个点：你在 alpha 层 np.where 剔除英国，它其实还留在模拟宇宙里（只是信号 NaN→默认 0 仓位），覆盖率指标仍按 EUR TOP2500 全样本算；真要英国彻底出宇宙、覆盖率重算，得在 simulation 设置的 universe filter 里踢，而不只是 alpha 里。最后一个坑：剔除英国后截面构成变了，剩下名字的均值/行业占比都偏移，如果你中性化没跟着重新 baseline，可能只是「砍掉了一个拖累桶」导致 IS 虚高——所以剔除前后都要重跑中性化对比，别只看「UK 消失了」就以为更干净。

### 评论 #11 (作者: MY27687, 时间: 2个月前)

好帖！Python alpha 的 `np.where` mask 法在 None 中性化下的验证结果很清晰，三个版本（全国家/剔除/保留）的对比非常有说服力。

补充几个实际使用中的想法：

**1. 中性化穿透问题的根源**
RAM/STATISTICAL 中性化会穿透 NaN mask，本质是因为这些中性化方法在计算因子载荷时会对全截面做回归或统计估计，NaN 被忽略后剩余股票的权重会被重新分配。这导致 mask 失效。所以如果确实需要在特定中性化下做国家筛选，目前更可行的路径可能是：在 FastExpr 中用 `group` 类操作符在信号生成阶段就做条件处理，再配合中性化使用。

**2. 行业筛选的潜在价值**
国家 mask 的思路完全可以迁移到行业（industry）字段。EUR 区域中，很多时候 Alpha 的表现是被少数几个行业撑起来的（比如金融或能源权重高）。用同样的 `np.where` 方法做行业级剔除/保留，可以快速诊断信号来源的集中度。

**3. 实战建议：诊断而非过滤**
如楼上所说，country/industry mask 更大的用途是"归因诊断"而非"永久过滤"——先跑一版全国家/全行业的基准，再用 mask 逐个剔除看哪些国家/行业对 Sharpe 贡献最大。如果剔除某个国家后 Sharpe 塌了，说明信号过度集中，可能不适合提交；如果剔除后 Sharpe 更稳定，说明那个国家在拖后腿，可以考虑针对性优化表达式。

**4. FastExpr 中的近似实现**
对于 GLB 或需要兼容更多中性化方法的场景，FastExpr 虽然没有原生的 `np.where`，但可以用 `group_rank` 配合条件过滤来实现类似效果。虽然不如 Python alpha 直观，但胜在跨区域和中性化兼容性更好。
