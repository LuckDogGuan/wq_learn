# 【AI工具】新版AI打工人配置指南 - PC & Mac & Linux

- **链接**: https://support.worldquantbrain.com/hc/zh-cn/community/posts/41020681850519
- **作者**: JL11546
- **发布时间/热度**: 1个月前, 得票: 168

## 帖子正文

更新日志：

1. 使用uv统一管理虚拟环境，不需要再卸载重装特定版本的系统级Python

2. 在运行一开始/过程中主动申请提权，避免用户因没有使用管理员权限运行导致无法输入

3. 允许用户配置自己的模型，模型选择更多样

4. 可选自动构建基础知识库

---------------------------------------------以下为PC版本--------------------------------------------------

### 1. 下载安装包

```
通过网盘分享的文件：AI打工人链接: https://pan.baidu.com/s/19GghIxf1BwNdBf056eifgA?pwd=7rmy 提取码: 7rmy
```

### 2. 安装AI打工人

双击"BRAIN *工具一键安装* windows版本.exe" - 以管理员身份运行，选择(强烈建议新建)一个文件夹一键安装

### 3. 安装完成后配置打工人

a. 选择你用的大模型(Kimi/DeepSeek)或手动输入你的模型配置

b. 输入你的API Key

c. 选择你的模型

d. (重要！) 重启终端

e. 在新的终端里切换到你的打工人目录，输入claude，进入Claude Cli测试一下是否配置成功

---------------------------------------------以下为Mac和Linux版本--------------------------------------

### 1. 下载安装包

```
通过网盘分享的文件：AI打工人链接: https://pan.baidu.com/s/19GghIxf1BwNdBf056eifgA?pwd=7rmy 提取码: 7rmy
```

### 2. 解压安装包

```
cd ~/Downloadsmkdir -p ~/AIWorker && unzip "AIWorker_MacLinux.zip" -d ~/AIWorker && cd ~/AIWorker
```

### 3. 安装AI打工人

```
# 如果说 Permission Deined 你需要切换一下所有权ls -ld AIWorker_MacLinuxsudo chown -R $USER:$USER AIWorker_MacLinux# 运行脚本zsh/bash install.sh# 如果无法执行脚本运行以下命令给脚本执行权限chmod +x install.sh
```

### 4. 安装完成后配置打工人

a. 选择你用的大模型(Kimi/DeepSeek)或手动输入你的模型配置

b. 输入你的API Key

c. 选择你的模型

d. (重要！) 重启终端

e. 在新的终端里切换到你的打工人目录，输入claude，进入Claude Cli测试一下是否配置成功

---------------------------------------------其他--------------------------------------------------

一、更新cnhkmcp的方法: 终端按照以下两步输入：

1. uv lock --upgrade-package cnhkmcp

2. uv sync

二、如何更换模型

Mac & Linux：终端输入命令vim ~/.zshrc 或 nano ~/.zshrc

Windows: 终端输入 notepad $PROFILE

def _salvage_json_array(text: str):
    """Try parse JSON, or salvage the first JSON array in a text blob."""
    # 1. 移除 <think>...</think> 标签
    import re
    cleaned = re.sub(r"<think>.*?</think>", "", text, flags=re.DOTALL)

    # 2. 尝试直接解析
    try:
        return json.loads(cleaned)
    except Exception:
        pass

# 3. 尝试抓取第一个 JSON 数组
    m = re.search(r".∗", cleaned, flags=re.DOTALL)
    if m:
        try:
            return json.loads(m.group(0))
        except Exception:
            pass

# 4. 如果文本是以 { 开头、} 结尾，且内部有多个用逗号分隔的顶层对象，则手动包裹成数组
    stripped = cleaned.strip()
    if stripped.startswith('{') and stripped.endswith('}') and not stripped.startswith('['):
        wrapped = '[' + stripped + ']'
        try:
            return json.loads(wrapped)
        except Exception:
            pass
