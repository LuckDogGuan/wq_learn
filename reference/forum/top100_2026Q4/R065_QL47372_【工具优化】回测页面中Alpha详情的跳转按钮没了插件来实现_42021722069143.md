# 【工具优化】回测页面中Alpha详情的跳转按钮没了？插件来实现！

- **发布时间/热度**: 2个月前, 得票: 41

## 帖子正文

平台在最近的一次更新中删除了 ***Open alpha details in new tab***  这个非常好用的按钮（问号脸.jpg），好在我们有华子哥插件（最新版），用AI加点料即可实现，效果如图，点击即跳转：

![图片](../images/img_468bbb4510.png)

找到插件目录中 ***src/content/platform/prodmemo*** 这个文件夹修改其中的文件：

1. 修改 ***prodmemo.js*** 
在顶部常量区加一行：

```
const ALPHA_DETAIL_BASE = 'https://platform.worldquantbrain.com/alpha/';
```

在  `normalizeAlphaId`  后面加函数：

```
function getAlphaDetailUrl(alphaId) {    return `${ALPHA_DETAIL_BASE}${encodeURIComponent(alphaId)}`;}
```

然后把  `renderCard()`  里的原始 ID 文本：

```
<div class="wqp-prod-alpha" title="${normalizedId}">${normalizedId}</div>
```

改成：

```
<a class="wqp-prod-alpha" href="${getAlphaDetailUrl(normalizedId)}" target="_blank" rel="noopener noreferrer" title="Open alpha details: ${normalizedId}">${normalizedId}</a>
```

并且把 header 结构从：

```
<div class="wqp-prod-header">    <div>        <div class="wqp-prod-title">ProdMemo</div>        <div class="wqp-prod-alpha" title="${normalizedId}">${normalizedId}</div>    </div></div>
```

改成：

```
<div class="wqp-prod-header">    <div class="wqp-prod-title">ProdMemo</div>    <a class="wqp-prod-alpha" href="${getAlphaDetailUrl(normalizedId)}" target="_blank" rel="noopener noreferrer" title="Open alpha details: ${normalizedId}">${normalizedId}</a></div>
```

2. 修改 ***prodmemo.css*** 
把 .wqp-prod-alpha 原样式替换成：

```
.wqp-prod-alpha {
    display: inline-block;
    max-width: 150px;
    padding: 2px 7px 3px;
    overflow: hidden;
    border: 1px solid #c7edf2;
    border-radius: 5px;
    background: #f0fdff;
    color: #0891a1;
    font-size: 13px;
    font-weight: 800;
    text-decoration: none;
    text-overflow: ellipsis;
    white-space: nowrap;
    font-variant-numeric: tabular-nums;
}
```

```
.wqp-prod-alpha:hover {
    border-color: #67dfe8;
    background: #dffaff;
    color: #036f7d;
    text-decoration: none;
}

.wqp-prod-alpha:focus-visible {
    outline: 2px solid rgba(34, 199, 212, 0.45);
    outline-offset: 2px;
}
```

wqp-prod-header 最好确认是这样：

```
.wqp-prod-header {    display: flex;    align-items: flex-start;    justify-content: space-between;    gap: 10px;    margin-bottom: 12px;}
```

两个文件修改并保存后，重新加载插件即可。

感谢华子哥的插件。以上代码部分均由AI生成，欢迎大佬们指教。

### 评论 #1 (作者: GC81559, 时间: 2个月前)

`group_mean`  vs  `group_median`  的选择取决于数据分布。金融数据通常是厚尾的，用 median 比 mean 更稳健。如果你的截面数据有明显离群值（如某些股票 P/E 巨大）， `group_median(x, industry)`  比  `group_mean`  受影响更小，生成的信号更稳定。实测 turnover 能降低 2-3 个百分点。
