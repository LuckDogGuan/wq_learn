## 帖子正文

最近平台更新了新功能, alphas页面可以用id过滤了

这里还有一个隐藏技巧, **多个id用逗号分割, 可以批量查询**

如图: (图片来自JG15244佬)

![图片](../images/img_aca3f4f9be.jpeg)

代码里怎么调用呢?

以前只能用alpha_id一个一个调用接口查看, 10个alpha就要调用10次接口, 速度非常慢

现在可以批量查询了, 一次性查询多个alpha_id的详情

示例代码:

```
# 登录
s = login()

# 这里替换为真实的alpha_id
alpha_ids = ['123','456']

id_string = '%1f'.join(alpha_ids)

url = f'https://api.worldquantbrain.com/users/self/alphas?limit=100&offset=0&id={id_string}'
res = s.get(url)

print(res.json())

```

说明:

- 一次做多查询100个, 超过100个要自己处理分页
- 这个接口是alphas页面的接口, 可以按需增加其他条件
