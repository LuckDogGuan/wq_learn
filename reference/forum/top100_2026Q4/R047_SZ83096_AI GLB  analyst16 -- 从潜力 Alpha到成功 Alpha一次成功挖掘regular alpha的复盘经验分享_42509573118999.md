## 帖子正文

这篇帖子复盘一次真实的研究经历，用一组真实的指标数字展示"潜力候选 → 提交级成功"的完整链条。不贴具体表达式，重点讲每一步发生了什么、数字怎么变的、以及为什么那样做。

### 一、起点：字段初筛（先筛 2Y 健康度，而不是 Sharpe）

拿到数据集后，先用同一套简单结构批量模拟全部候选字段， **以 2Y Sharpe≥1.58 为硬筛条件** 。结果非常有规律：大部分字段族直接淘汰（估计水平、覆盖度、分歧度类字段 2Y 只有 0.3~1.25）；活下来的只有少数几个围绕"预期变化"的字段家族——经济含义自洽，说明 2Y 健康不是偶然。

但此时它们只是"可用的信号"，离潜力候选还差得远： **Sharpe 大致在 1.0~1.6，Sub-universe 全部不通过（0.61~0.83，要求 1.0 左右）** 。

### 二、潜力候选：结构（嵌套分组）是关键一跃

初筛信号的 Sub 不过，是因为单层分组无法剔除行业共同波动。改为嵌套分组（内层行业细分 + 外层国家/区域）后：

**Sub-universe：0.61~0.83（FAIL）→ 1.25（PASS）** 
Sharpe：1.0~1.6 →  **1.68** 
Fitness：→  **1.01** 
2Y Sharpe：→  **1.78** 
Margin：→  **0.00179**

到这里拿到第一个"潜力候选"，达到粗筛标准：Sharpe≥1、Fitness≥0.6、2Y≥1.58、Margin≥0.0015。

### 三、参数优化：把候选逼到极限（换手 vs 2Y 的精细拉锯）

接下来系统扫描平滑类操作符的两个参数方向（目标换手率 / 成交量限幅），逐项把检查拉进限内。实测经验：成交量限幅类在同等 2Y 提升下对 Sharpe 损耗更小；参数存在精确平衡点，差一档相关性或 2Y 比值就过线或破线。

最终在原 Universe 上优化到： **Sharpe 1.64 / Fitness 1.01 / 2Y 1.79 / Margin 0.00168 / Turnover 0.0568 / Sub 1.27 / 生产相关性 0.6237 / 自相关 0.396 / 回撤比 0.834** ，提交检查 15/16 通过。

但剩下 3 项怎么调都过不去，而且它们同源于一个问题—— **EMEA 子区域弱** ：
EMEA Sharpe： **0.50** （要求 ≥1.0）
CLUSTER_TEST： **1.29** （要求 ≥1.58，与 EMEA 强相关）
2Y/Sharpe 比值： **1.09** （要求 >1.2）

换平滑参数、换外层分组、换窗口长度都无效。这时候的判断是： **这不是参数问题，而是这个股票池里该信号的区域覆盖天然不足** ——该换池了。

### 四、换 Universe：打破僵局

同样的字段、同样的结构，只把 Universe 从 TOPDIV3000 换到 MINVOL1M：

Sharpe：1.64 →  **2.91** 
Fitness：1.01 →  **2.18** 
2Y Sharpe：1.79 →  **2.52** 
Turnover：0.0568 →  **0.0507** 
Sub-universe：1.27 →  **1.95** 
CLUSTER_TEST：1.29 →  **1.68（PASS）** 
三个子区域：Amer 2.05 / Apac 1.58 /  **Emea 0.50 → 1.90（全部过线）**

之前所有"怎么调都不行"的检查项，换池后自动消失了。但换池也暴露了一个新缺口： **生产相关性 0.7510（要求 <0.7）** ——低波动池与生产库的重叠度更高。

### 五、临门一脚：分布操作符（signed_power）补齐最后一项

参数已经扫到极限，剩下唯一办法是改变信号的分布形态。引入 signed_power 重塑信号后：
 **生产相关性：0.7510 → 0.69（PASS）** 
Sharpe：2.91（保持）
Fitness：2.18 →  **2.28** 
Margin：0.00276 →  **0.00293** 
Turnover：0.0507 →  **0.0522** 
Sub-universe：1.95 →  **2.05** 
CLUSTER_TEST：1.68 →  **1.61（保持 PASS）** 
三个子区域：Amer 2.21 / Apac 1.62 /  **Emea 1.42（全部过线）** 
IS-Ladder：2.51（PASS）

至此，全部成功标准达成。

### 六、关键经验

1. **先筛 2Y 健康度，再谈 Sharpe** ：字段层用统一结构批量测，2Y 差的家族直接砍掉，活下来的家族经济含义自洽。
2. **结构决定下限，参数决定上限** ：嵌套分组（行业内层 + 区域外层）解决 Sub 与相关性；参数扫描只负责把检查逐项拉进限内。
3. **把优化做到极限再判断"可调"还是"固有"** ：当只剩单一维度（某个子区域）过不去，换结构换参数都无效时，大概率是池子属性。
4. **换 Universe 是最大质变** ：信号没变，变的是池子——区域覆盖、聚类测试、整体 Sharpe 全部质变。但前提是你已经证明信号本身没问题。
5. **相关性缺口用分布操作符补** ：参数到极限后，signed_power 这类重塑信号形态的操作符能在不牺牲其他指标的前提下补齐相关性。
6. **全程用完整提交检查验收** ，而不是只看 Sharpe。

### 评论 #3 (作者: LY43440, 时间: 1个月前)

这篇复盘把「2Y 硬筛 → 结构 → 参数 → 换池 → 分布操作符」的链路讲得很完整，尤其「EMEA 弱子区是池子属性、该换池」这段很有参考价值。补一个分布操作符的小观察： `signed_power`  是单调变换（sign(x)·|x|^p，p>0 时保持排序），所以它不改变信号排序，但跨截面权重会随 |x|^p 重新分配——帖子里的数字正好说明这一点：套  `signed_power`  后 Sharpe 稳定在 2.91，但生产相关性 0.751→0.69、Margin 0.00276→0.00293、Turnover 0.0507→0.0522 其实都在动。也就是说，分布操作符不是「零代价」，它是靠改变权重分布来换相关性下降。

这跟本论坛另一篇《使用 tail 降低 PC》帖子是互补的两条路线：那边是直接对中间信号置 0（截断重塑，改动更剧烈，通常还要配 decay 把 margin 拉回来），而  `signed_power`  是保序重塑，适合相关性缺口不大、想保住信号排序的场景。两条路线各有实测数字，选哪条可以先问一句：你的信号是不是天然双尾、只在两端有信息？是就截断重塑，否则用保序重塑更稳妥。

import numpy as np
from scipy.stats import rankdata

def signed_power_py(x, gamma=0.5):
    """Python 侧等效 signed_power：保号、拉伸尾部、压缩中间"""
    sign = np.sign(x)
    abs_x = np.abs(x)
    # 防止 0 值报错
    abs_x = np.where(abs_x == 0, 1e-12, abs_x)
    transformed = sign * (abs_x ** gamma)

这套流程把「从数据集拿到字段 → 产出潜力候选」的周期从人工 2-3 天压缩到 2-3 小时，且漏掉的优质字段极少（回测复核漏报率 < 3%）。

楼主的六条经验已把 Regular Alpha 从 0 到 1 的完整方法论讲透了，Python Alpha 侧的实测数据点基本形成互证。感谢分享，已收藏反复研读。
