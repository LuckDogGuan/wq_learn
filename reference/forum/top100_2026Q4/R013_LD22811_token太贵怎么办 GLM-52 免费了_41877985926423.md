## 帖子正文

英伟达有一个开发者平台叫 build.nvidia.com，上面托管了 141 个 AI 模型，其中 77 个提供免费 API 端点。你没看错，77 个免费模型。DeepSeek-V4-Pro 在里面，Kimi-K2.6 在里面，MiniMax-M2.7 在里面，Qwen3.5 也在里面。 ![图片](../images/img_813d6971d2.png)

GLM-5.2 也在里面。标签写着  **Free Endpoint**  加  **Downloadable** ，提供方是 Z.ai（智谱），排在最新模型列表的第一位。上线才 1 天，下载量就冲到了 200 万。 ![图片](../images/img_ee2e411fe1.png)

这个免费 API 跟前两篇文章里的工具有一个根本区别。CatPaw 和 QoderWork 都是成型的产品，下载安装打开就能用，但模型被封装在产品内部，你只能在它们的界面里调用。英伟达给你的是纯的 API 接口，它兼容 OpenAI 的格式，你可以把它接入任何支持这个格式的工具里。

任何工具。

包括 Claude Code。

我知道读到这里有些人可能会觉得：API 这种东西离我太远了，我又不是程序员。别急，往下看。有一个叫 CC Switch 的图形化工具，帮你点几下鼠标就能完成所有配置。

但先说怎么拿到这个免费 API Key。整个过程大概五分钟。

PART 02

五分钟拿到 Key

国内手机号可以验证，一次生成用一整年

打开 build.nvidia.com，注册账号。如果你有 Google 账号或者 GitHub 账号可以直接授权登录，不用单独注册。登录之后你需要验证手机号才能生成 API Key，重点来了，它支持中国大陆手机号。Location 下拉菜单里选 China，填 +86 开头的号码，点 Send Code to Phone，手机上收到一个六位数的验证码，输入进去，验证通过。 ![图片](../images/img_67fc6b4f59.png)

这一步很多人以为中国手机号不行，其实完全没问题。我亲测的，短信几秒就到了。

验证完手机号之后，在页面右上角找到个人中心，进入 API Keys 管理页面，点 Generate API Key。给你的 Key 起个名字，比如 freeapi，系统会生成一个以 nvapi- 开头的密钥字符串。注意，这个密钥只显示一次，页面关了就再也看不到了，一定要立刻复制保存好。

看到有效期了吗。2027 年 7 月 5 号。

我给这个 Key 有效期设置了一年。当前也有永不过期的选项，只是不知道这个活动啥时候就给"拉闸"了。

对比一下前两篇的免费额度。CatPaw 的 500 次额度用完了要提交表单申请重置，等审核。QoderWork 的 2000 积分只有 30 天有效期，过期作废(留言区很多网友反馈，根本不会用满一个月，快的话可能几天就消耗完2000积分了)。英伟达直接给你一把无限用钥匙，而且验证页面上写的是  **Unlimited API requests without daily limits** ，没有每日请求上限。

当然  **无限**  这个词要打个问号，免费的东西背后通常都有隐性限制，我后面会说到缺点的地方。但至少从官方描述和我实际使用的情况来看，确实没有弹出过额度耗尽的提示。 ![图片](../images/img_06ba6597b3.png)

PART 03

接入 Claude Code

三个参数 + CC Switch，GLM-5.2 顶替 Sonnet

好了，Key 拿到了。接下来是关键的一步，怎么把这个 Key 用起来。

打开 GLM-5.2 在英伟达平台上的模型页面，你会看到它列出了三个关键参数。base_url 是  [https://integrate.api.nvidia.com/v1(后续实际测试/v1不需要填写)，api_key](https://integrate.api.nvidia.com/v1(%E5%90%8E%E7%BB%AD%E5%AE%9E%E9%99%85%E6%B5%8B%E8%AF%95/v1%E4%B8%8D%E9%9C%80%E8%A6%81%E5%A1%AB%E5%86%99)%EF%BC%8Capi_key)  就是你刚才生成的那个 nvapi- 开头的密钥，model 名称是 z-ai/glm-5.2。

如果你是程序员，到这一步就结束了。拿着这三个参数去调用 OpenAI 兼容格式的 API 就行，Python、Node、Shell 的示例代码页面上都有。但大多数人不是程序员，也不想折腾命令行。

这时候 CC Switch 就派上用场了。

CC Switch 是一个图形化的模型供应商管理工具，专门用来切换 Claude Code 的底层模型。打开它你会看到一个密密麻麻的供应商列表，几十个选项，SiliconFlow、OpenRouter、GitHub Copilot、Codex 都在里面。英伟达也是其中之一。你在列表里点 Nvidia 那个蓝色按钮，它就帮你把请求地址预填好了，你只需要粘贴自己的 API Key。

配置有四个要点。第一，API Key 填你的 nvapi- 密钥。第二，请求地址填  [https://integrate.api.nvidia.com](https://integrate.api.nvidia.com) ，这个 CC Switch 已经帮你预填了。第三，API 格式一定要选  **OpenAI Chat Completions（需开启路由）** ，不选这个的话请求格式对不上。第四，模型映射这里最关键，把 Sonnet、Opus、Haiku 三个角色全部映射到 z-ai/glm-5.2。这样不管 Claude Code 用哪个模型角色发请求，实际跑的都是 GLM-5.2。

保存之后，打开 Claude Code，输入 /model，你会看到模型列表里原来写着 Sonnet 4.6、Opus 的位置，现在都变成了 z-ai/glm-5.2。选中第 4 项 Custom Sonnet model，打个 hi 测试一下。

流程跑通了。

你现在拥有的是 Claude Code 的完整界面和 Agent 工作流，但底下跑的是英伟达免费提供的 GLM-5.2。Claude Code 的多文件编辑、自动化执行、上下文管理、工具调用这些能力全都还在，只是推理引擎换成了 GLM-5.2。

反正你不说，别人从界面上是完全看不出来的。终端里一样显示 Claude Code 的 logo，一样的交互方式，一样的 /model 命令。但每一次对话请求走的都是英伟达的 GPU 集群，调用的都是智谱的 GLM-5.2。

这笔账怎么算

你想想看，Claude Code 正常使用的话，最低也要 Max 套餐 100 美元一个月，或者走 API Usage Billing 按量付费。现在你用英伟达的免费 API 加上 CC Switch，同样的界面同样的工作流，底层模型的调用费用是零。这对于想体验 Claude Code 工作流但预算有限的人来说，是一个相当实用的替代方案。
