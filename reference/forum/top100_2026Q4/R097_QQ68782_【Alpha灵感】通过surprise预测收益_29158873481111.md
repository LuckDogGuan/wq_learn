## 灵感来源

Valuation ratios, surprises, uncertainty or sentiment: How does financial machine learning predict returns from earnings announcements

[https://papers.ssrn.com/sol3/papers.cfm?abstract_id=3577132](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=3577132)

## Alpha 核心思路

- 盈利与营收超预期的小盘成长股往往表现优于大盘。

- 盈利与营收不及预期的大盘价值股往往表现不佳。

实现思路: 市值小、超预期, 做多, 市值大,预期差, 做空;

字段:

- cap 市值
- star_eps_surprise_prediction_fq1 盈利惊喜
- star_rev_surprise_prediction_fq1 收入惊喜，字段没权限，先不考虑

核心表达式：

group_neutralize(star_eps_surprise_prediction_fq1, bucket(rank(cap),range="0,1,0.5"));

cap以0.5为步长，分为两组，区分大小市值。

## 增强Alpha的信号

进一步优化：

1.论文提到成长股的表现更突出；

2.存在延迟漂移效应，影响时间达到60天。

优化后的表达式：

growth_factor = group_rank(

fnd17_price2bk * sales_growth,  # 高PB且高增长的成长股

subindustry

);

# 3. 市值分组内的信号计算

main_signal = group_rank(

star_eps_surprise_prediction_fq1 * (1 + growth_factor),  # 成长股的惊喜信号权重更大

bucket(rank(cap), range="0,1,0.1")

);

# 4. 延迟漂移效应

drift_signal = ts_mean(

main_signal,

60  # 使用更长的时间窗口捕捉完整的漂移效应

);

# 5. 最终信号

result = group_neutralize(

drift_signal,

bucket(rank(cap), range='0.1, 1, 0.1')

);

### 评论 #9 (作者: AS53518, 时间: 2个月前)

按我理解，核心逻辑应该是这样:

- 盈利与营收超预期表现更好，不及预期的表现更差

-预测公告当天，小盘股对于表现的兑换更猛烈

-预测公告当天，成长股对于表现的兑换跟温和，会拉长时间逐步兑换

-预测公告后中长期收益时，模型会纳入更多指标，以基本面财务比率、预期偏差为主

基础因子：   star_eps_surprise_prediction_fq1

优化小盘股的影响:     group_neutralize(star_eps_surprise_prediction_fq1, bucket(rank(cap),range="0,1,0.5"))

优化成长股的影响：

main_signal = group_rank(

star_eps_surprise_prediction_fq1 * (1 + growth_factor),  # 成长股的惊喜信号权重更大

bucket(rank(cap), range="0,1,0.1")

);

# 延迟漂移60天

drift_signal = ts_mean(

main_signal,

60  # 使用更长的时间窗口捕捉完整的漂移效应

);

预测公告后中长期收益时，模型会纳入更多指标，以基本面财务比率、预期偏差为主

drift_signal = ts_mean(

main_signal*(ts_rank(fundamental_matric)+0.0001)*(ts_rank(预期偏差)+0.00001),

60  # 使用更长的时间窗口捕捉完整的漂移效应

);
