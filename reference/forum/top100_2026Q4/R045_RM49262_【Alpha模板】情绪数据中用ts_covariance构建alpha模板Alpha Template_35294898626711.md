## 帖子正文

1. 模板内容及效果

基本模板：

```
ts_covariance(<datafield1>,<datafield2>,<days>)
```

其中datafield1/datafield2均选自Sentiment21 dataset。

这个idea的出现其实是因为我用了Genius rank插件发现自己没用过ts_covariance。在论坛里直接搜索了ts_covariance试图省事想直接找个模板套用，跳出来的是Weijie老师之前发过的一系列" **推荐使用的数据 USA D1 TOP3000 NEWS12__partXXX（未检查数据类型）** "的帖子。News数据集和Sentiment数据集有一定相似性，所以为了降低Corr我就又找了个还没什么人用的Sentiment21数据集跑了跑，效果还是可以的。

这个基础模板只算是个一阶模板，大家外面可以自行再套signed_power/hump/trade_when等等进行进一步优化。除此之外我为了优化六维没有进一步再加operator优化效果了。下图是我在EUR/TOP2500提交的其中两个Alpha示例

![图片](../images/img_3cb51f6b5a.png)

![图片](../images/img_3bd838df5e.png)

虽然模板简单，跑出来效果还是不错的，交出来的alpha还能当RA，说明新数据集跑的人应该不多。

2.模板内容分析

```
ts_covariance(y, x, d) 
```

协方差(covariance)是衡量两个变量如何一起变动的统计量。如果两个变量倾向于同时高于或低于它们的平均值，则协方差为正。如果一个变量倾向于高于其平均值而另一个变量倾向于低于其平均值，则协方差为负。 ![图片](../images/img_ac81ee99af.png)

比如说我们的alpha是

```
-ts_covariance(负面情绪，正面情绪，d)
```

那么，当d天内负面情绪得分明显降低，正面情绪得分明显升高时，这个表达式的值就会明显增大提示做多；反之则提示做空。

3.个人对该模板的想法

其实一开始我在脑补跑这个模板的结果的时候，还以为这个模板跑出来alpha的会是turnover非常高的alpha(捕捉短期情绪的剧烈波动从而做多/做空)。但最后根据结果来看，单就这个模板而言days较短时跑出的alpha结果都比较一般。我最后交的几个alpha 的days 都是设定在63/252/504等等中长期时间。

我简单查了一篇文献来寻找原因(还没仔细读)

**Investor Sentiment in Asset Pricing Models: A Review of Empirical Evidence**

文献中提到

> The prevalence of the reversal effect of the sentiment, which means that the impact of sentiment on returns usually was reversed  **with the same magnitude after 4 or 5 days** .

所以我猜，我设想的那种短期的这种剧烈情绪波动可以用来设计一些均值回归的alpha来获利？

4.总结

可以看到这个模板最初的idea其实只是来源于论坛的老帖子，只是换了个新dataset就跑出了不错的结果，这对大家来说都是一个比较简单易行的方法，可以多多尝试。

同时，我这个模板其实只是一个非常原始的想法，肯定还有很大的提升空间，也欢迎大家一起发表意见！

### 评论 #28 (作者: ZZ47696, 时间: 2个月前)

感谢分享，这个模板我这两天正好在相邻的方向上做实测（GLB / delay1 / TOPDIV3000，冷门新闻情绪集 ai_news_scores），有几条可以直接回答楼里的疑问，也给想复现的同学省点仿真额度。

**一、回答楼上「情绪数据要不要回填」——必须回填，而且窗口要够长**

这是新闻/情绪类数据集和量价类最大的区别：它是 **事件驱动的稀疏序列** ，很多票很多天根本没有新闻，字段就是 NaN。直接丢进去跑等于让平台按 0 处理，把「没消息」误当成「情绪中性且刚刚发生」。我用同一条表达式做过对照（同一字段、同一 settings，只差有没有  `ts_backfill` ）：

- 不回填：Sharpe 0.89，ht_ratio 0.64
- `ts_backfill(f, 120)` ：Sharpe 1.53，ht_ratio 0.83

另外实测  `ts_backfill`  窗口 20 和 120 出来的 alpha 指标 **逐位相同** ，说明只要覆盖到「上一条新闻」就够，不必纠结窗口取值；但完全不填是真的会废掉。所以复现说「效果不好」的同学，先补这一步再下结论。

**二、楼主第 3 节那个「短期剧烈情绪波动」的猜想，我这边测出来是成立的，而且反转窗口和你引的文献几乎对上**

楼主引的文献说情绪对收益的冲击「大约 4~5 天后同幅度反转」。我做的正是短周期版本：先高通提纯出冲击项，再做截面标准化，

`ts_zscore( rank( ts_backfill(f,120) - ts_mean(ts_backfill(f,120), W) ), 250 )`

W=10 是甜点，两侧都掉——这和「情绪冲击寿命约一周」的说法是自洽的。而直接对情绪 **水平值** （不做减均值）跑  `ts_zscore` ，Sharpe 只有 0.38、ht_ratio 甚至为负，差了一个量级。 **结论：情绪数据的信息在「变化量」里，不在「水平」里** ，楼主用 covariance 其实也是在抓联动的变化结构，同源。

顺带排一个雷： `ts_delta(f,1)`  这种最锐的高通反而直接跑死（Sharpe -0.52、Turnover 1.2）。 **高通存在最优带宽，不是越短越好。**

**三、给要打高换手主题（HTVR）的同学一个提醒：楼主的 d=63/252/504 这条路在这个主题下不能用**

长窗口本质是低通滤波，会把信号的日频翻转成分磨掉。我实测过一批低通类算子对 ht_ratio（ `HT_HIGH_TURNOVER_RETURNS_RATIO` ）的伤害： `ts_decay_linear` 、快慢腿混合、 `ts_target_tvr_decay`  全部把 ht 从 0.83 压到 0.59~0.78，直接掉出 0.75 的门槛。 **想用这个 covariance 模板打 HTVR，d 必须往 5~22 走，并且外面套的应该是高通/截面算子，不是平滑算子。**

另外提醒一个查指标的坑： `/check`  里名字叫  `HIGH_TURNOVER`  的那条只是 turnover 的复读，真正的换手收益占比是  `HT_HIGH_TURNOVER_RETURNS_RATIO` ，别拿错字段自嗨。

**四、为什么我认为楼主这个方向值得砸额度：它是「换信息源 + 换内核」的双重正交**

我在量价内核上试遍了保序形变（quantile 各 driver、signed_power、normalize）和换分组/自定义桶中性化，Prod Correlation 全部死钉在 0.66~0.71 的窄带里，一次都没掉下去过——因为 PROD_CORRELATION 比的是  **PnL 曲线形状** ，任何保序变换都改不动它。真正把它打下来的只有换数据源：同样的高通结构换到新闻情绪集上，PC 从 0.70 直接掉到  **0.44** ，而 ht_ratio 还稳在 0.83+。

`ts_covariance(neg, pos, d)`  相对于常见的「加权求和」是 **双线性** 的，不是任何单腿的单调变换，理论上能在 PC 上再拿一层增益。楼主如果方便的话，能不能贴一下这两条 EUR alpha 的 Prod Correlation？如果也在 0.4 附近，那就能确认「二阶算子 + 冷门情绪集」是一条独立的低相关赛道，而不只是运气。

**五、一个还没解决的坑，希望有人有经验**

新闻情绪线在我这里表现出很强的 **区域偏科** ：GLB 拆三个子区看，APAC 的 Sharpe 稳定在 1.2~1.77 全部 PASS，AMER 只有 0.12~0.65、EMEA 在 -0.25~0.91 之间，全部 FAIL。而且高通窗口 W 还是个 **隐性的区域选择器** ——W 从 10 加到 44，AMER 单调塌（0.48→0.27→0.12），APAC 反而单调升（1.53→1.77→1.76）。我的解释是 AMER 定价效率高、新闻脉冲寿命更短，但换中性化维度（MARKET / COUNTRY / STATISTICAL）去修 AMER 全部失败，反而比 SUBINDUSTRY 更差。楼主在 EUR 单区跑是不是就没这个问题？做情绪类因子的同学，如果有把 AMER 腿救回来的经验，很想听听。

顺手补个免回测的诊断口径： `/check`  返回里  `LOW_GLB_AMER_SHARPE`  /  `LOW_GLB_EMEA_SHARPE`  /  `LOW_GLB_APAC_SHARPE`  的  `value`  字段，就是三个子区各自的 Sharpe（limit 恒为 1），一次 check 全拿到，不用另外跑三遍区域回测。
