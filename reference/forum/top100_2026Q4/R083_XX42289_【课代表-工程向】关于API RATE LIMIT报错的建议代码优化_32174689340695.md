## 帖子正文

最近很多小伙伴都报了一个错误API RATE LIMIT

不论是自己做的工程代码，还是WQB库，都有人遇到。

那么这是为什么呢？究其原因是因为2025年5月7日北京时间晚上17~23点之间，WorldQuantBrain对中国区顾问/用户的登录API做了限制，也就是下面这个url，他每分钟可能只能同时存在3个（用户），8个（顾问），否则就会报错。这个数字是我的估计，并不准确，但是可以作为参考。

```
https://api.worldquantbrain.com/authentication
```

## 解决办法

那么怎么办呢？解决办法很简单，只需要降低同时登录的session就行了。

在python中，只需要用global，就可以全局复用，然后你后面就不要再登录别的session了，只有遇到报错的时候才需要重新刷新session。

```
global sessionsession = login()
```

有的同学用的是WQB库，这里也给一个例子

```
global wqbwqb = WQBSession((username,password))
```

另外，如果你开启了多个py或者ipynb文件，请减少同时运行的数量，否则也会报错。

总而言之，一定要减少同时登录的个数（你网页端登录的也算！）

相信你一定也会解决这个报错的！
