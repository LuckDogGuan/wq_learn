## 帖子正文

在我们平时大量回测数据的时候，最激动人心的一刻莫过于最后的goldbag开alpha盲盒阶段，以往的view_alphas阶段会在控制台打印出一条条alpha的具体表现情况，这个时候总感觉看起来有点乱，不少朋友都是手动复制出来完后整理格式再做比较。

我把这里改了下，可以直接让获取到的alphas进入到excel表格中，我把代码贴出来！因为本人没有什么编程基础，代码较笨拙但能用，谢谢大家指教！

首先是咱们的 ipynb 文件里可以在最下面加上：

```
now = datetime.datetime.now()# 获取年、月、日year = str(now.year)month = str(now.month)day = str(now.day)riqi = year+month+dayview_alphas_excel(gold_bag, '文件名'+riqi)
```

上面的代码中 文件名可以自己起，我这里加了个日期方便自己辨识。

接着我们在 lib 文件中加上以下两个函数：

def locate_alpha_excel(s, alpha_id):

while True:

alpha = s.get(" [https://api.worldquantbrain.com/alphas/](https://api.worldquantbrain.com/alphas/) " + alpha_id)

if "retry-after" in alpha.headers:

time.sleep(float(alpha.headers["Retry-After"]))

else:

break

string = alpha.content.decode('utf-8')

metrics = json.loads(string)

dateCreated = metrics["dateCreated"]

sharpe = metrics["is"]["sharpe"]

fitness = metrics["is"]["fitness"]

turnover = metrics["is"]["turnover"]

margin = metrics["is"]["margin"]

decay = metrics["settings"]["decay"]

exp = metrics['regular']['code']

returns = metrics["is"]["returns"]

drawdown = metrics["is"]["drawdown"]

triple = [alpha_id, sharpe, turnover, fitness, margin, returns, drawdown, decay, dateCreated, exp]

return triple

def view_alphas_excel(gold_bag, excelname):

s = login()

sharp_list = []

for gold, pc in gold_bag:

triple = locate_alpha_excel(s, gold)

info = str(triple[0])+"|"+ str(triple[1])+"|"+ str(triple[2])+"|"+ str(triple[3])+"|"+ str(triple[4])+"|"+ str(triple[5])+"|"+ str(triple[6])+"|"+ str(triple[7])+"|"+ str(triple[8])+"|"+ str(triple[9])+"|"+str(pc)

sharp_list.append(info)

df = pd.DataFrame([item.split('|') for item in sharp_list], columns=['alpha_id', 'sharpe', 'turnover', 'fitness', 'margin', 'returns', 'drawdown', 'decay', 'dateCreated', 'exp', 'pc'])

# 写入Excel文件

df.to_excel('alphas/'+excelname+'.xlsx', index=False)

print("写入Excel完成！")

这样每当直行到 view_alphas_excel 的时候，我们就可以直接在excel文件中看到具体alpha的表现情况了。
