**Part 4 : 其他内容**

回到提交alpha数量最多的数据集这个部分，我们可以发现，对于两个地区，pv1数据集的alpha都是最多的。

但同时，一旦我们根据ATOM进行筛选，使用pv1的alpha的数量就会出现明显下降。

对于GBR：使用pv1的共717个alpha，其中ATOM 66个，非ATOM 651个。该地区共3534个alpha， **相当于该地区有18%的alpha都是由pv1+其他数据集组合而成的信号。**

对于DEU：使用pv1的共195个alpha，其中ATOM 67个，非ATOM 128个。该地区共358个alpha， **相当于该地区有35%的alpha都是由pv1+其他数据集组合而成的信号。**

不难看出，pv1+其他数据集联用已经成为了不少顾问的做法之一。但这究竟算“混信号”还是“结合起来做出了有经济学含义的信号”只能看各位顾问的表达式自行判断了。

### 评论 #9 (作者: SL81184, 时间: 1个月前)

楼主的首周聚合数据很有参考价值。作为微观对照，分享一组今天（08.14）刚跑完的 GBR 首日实测——fundamental17（楼主统计中 GBR 第 8 热门数据集，已提交 205 个）。

**实测设置** ：GBR / delay1 / TOP700，fundamental17，FAST 中性化，统一  `ts_backfill(x,120)`  +  `winsorize(std=4)`  预处理，8 个字段×算子组合变体同时模拟。

**结果：全部离提交线尚远，确实"不出货"** （呼应帖题；IS Sharpe 最高仅 0.24，按常规提交标准（约 1.25+）仍有量级差距）：

- 最好： `ts_zscore(ts_scale(winsorize(ts_backfill(net_income_incl_extraordinary,120),std=4),11),122)`  → IS Sharpe 0.24 / Fitness 0.06 / Turnover 0.238 / Return 1.49bp
- 其次： `ts_std_dev(ts_ir(winsorize(ts_backfill(fnd17_10_rhsfcfq,120),std=4),3),122)`  → IS Sharpe 0.21
- 最差： `ts_max_diff(ts_ir(winsorize(ts_backfill(annual_net_income_excl_extraordinary,120),std=4),504),66)`  → IS Sharpe  **-0.35**

**两个与楼主数据对照的观察** ：

1. **换手率与收益在组内并不单调** ：收益最好的变体 Turnover 0.238 / Return 1.49bp，最低换手变体（ `ts_arg_max(ts_sum(...annual_debt_to_total_capital...))` ，TO 0.056）Return 0.49bp——两点之差约 3 倍，方向上与楼主"GBR 换手提升显著带来收益提升（p < 0.001）"一致；但组内最高换手变体（TO 0.344）收益为负（-0.75bp），收益最差的变体（TO 0.142 → -3.09bp）也并非低换手，8 变体且字段、算子混杂，与楼主 3534 样本的 10 分组单调趋势不可比。小样本上更像是"换手-收益非线性"，而非简单的正相关。

1. **距提交线的差距** ：楼主给的已提交 Margin 中位数 11.9bp，而我最好的变体 IS Return 仅 1.49bp（IS Return 与提交后 Margin 口径不完全一致，仅作量级参考；且已提交样本通过了提交检查、存在选择偏倚）——我这批变体要够到提交线还有明显距离，也提示该数据集 205 个提交里能出货的占比值得观望。

**字段敏感性初印象** （单组 8 变体小样本，供参考）：同预处理下更换字段/算子组合，IS Sharpe 范围 -0.35 ~ +0.24；income 类字段两极分化（最佳 0.24 与最差 -0.35 都出现在 income 类），资产/负债类 3 个变体全为正但幅度小（0.10~0.17）。字段与算子未隔离，"筛选字段优先于调算子"目前只是待验证的假设，值得后续做字段×算子交叉验证。
