# 一个避免连续回测streak中断的方法代码优化

- **链接**: https://support.worldquantbrain.com/hc/zh-cn/community/posts/32575045035159
- **作者**: QQ68782
- **发布时间/热度**: 1年前, 得票: 57

## 帖子正文

最大连续回测天数(Max simulation streak)在genius里独占一个维度, 而且每个季度 **不重置** , 对genius的评级的影响还是很大的

但是有时候工作太忙, 或出门在外, 可能忘记回测, 意外中断

这里提供一个脚本, 定时检查回测状态, 如果一段时间内没有回测就自动回测一次, 最大程度避免streak中断

**## 示例代码**

```
def simulate_if_need():
    '''
    1小时内没有回就跑一次
    '''
    # 查询最近一小时的回测
    from wqb import WQBSession, wqb_logger, FilterRange
    logger = wqb_logger(name="wqb-generator")
    wqbs = WQBSession((config.username, config.password), logger=logger)
    now = datetime.datetime.now(datetime.timezone.utc)
    start_time = now - datetime.timedelta(hours=1)
    response = wqbs.filter_alphas_limited(
        date_created=FilterRange(lo=start_time, hi=now),
        limit=1,
    )
    res_json = response.json()
    if res_json and res_json['count'] > 0:
        logger.info(f"has simualte in 1h {res_json}")
        return
    logger.info("no simualte in 1h, start simulate")
    # 回测一次
    data_list = [
        {
            "settings": {
                "instrumentType": "EQUITY",
                "region": "USA",
                "universe": "TOP200",
                "delay": 1,
                "decay": 0,
                "neutralization": "NONE",
                "truncation": 0.08,
                "pasteurization": "ON",
                "unitHandling": "VERIFY",
                "nanHandling": "ON",
                "language": "FASTEXPR",
                "visualization": False
            },
            "type": "REGULAR",
            "regular": f'''# {datetime.datetime.now().strftime("%Y-%m-%d %H:%M")}
            {time.time()}
            '''
        }
    ]
    simulate(data_list)
```
 **说明:** 
- 这里使用了wqb, 根据自己的情况配置username、password; 也可以根据自己的情况改造为直接调用brain的api查询
- 可以用python定时执行这个函数, 或者linux里用crontab定时调用脚本

### 评论 #3 (作者: DZ31817, 时间: 1年前)

这个方法绝了。以前出门在外没法回测，可能就用手机登上平台回测个close，但这种方法可能导致跟以前的回测相同而失败，导致痛失streak。楼主这个方式不仅使用独一无二的时间戳作为alpha表达式的注释，而且还使用该时间戳对应的浮点数直接作为表达式（实际回测的效果应该等同于1），从而保证每次回测都不是重复的。我以前最多想到让注释不同，没想到可以直接用时间作为表达式。实际上如果只是注释不同，表达式和设置仍相同的话，仍有可能会回测失败。楼主这个方法真是从根本上解决了问题。
