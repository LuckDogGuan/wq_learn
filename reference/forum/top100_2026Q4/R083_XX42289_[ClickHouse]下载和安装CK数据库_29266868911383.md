**系列主页面： [使用[ClickHouse📕]建设你的大型数据库 – WorldQuant BRAIN]([L2] 使用[ClickHouse]建设你的大型数据库_29266895095063.md)**

这是一个系列，用于创建ClickHouse数据库。 **ClickHouse**  是一个开源的列式数据库管理系统（DBMS），专为在线分析处理（OLAP）场景设计。它由俄罗斯的 Yandex 公司开发，最初用于支持 Yandex.Metrica（一个类似于 Google Analytics 的网站分析工具）。ClickHouse 以其卓越的查询性能和高效的数据压缩能力而闻名，特别适合处理大规模数据的实时分析查询。

Linux的用户可以用下面的代码，但是Windows的用户就需要自己问一下GPT了。

```
sudo apt updatesudo apt upgrade -ysudo apt-get install -y apt-transport-https ca-certificates dirmngrsudo apt-key adv --keyserver hkp://keyserver.ubuntu.com:80 --recv E0C56BD4echo "deb https://packages.clickhouse.com/deb stable main" | sudo tee /etc/apt/sources.list.d/clickhouse.listsudo apt-get updatesudo apt-get install -y clickhouse-server clickhouse-client# 默认存储在/var/lib/clickhouse/，可以通过/etc/clickhouse-server/config.xml配置文件修改# 监听端口<listen_host>0.0.0.0</listen_host>，可以通过/etc/clickhouse-server/config.xml配置文件修改sudo service clickhouse-server startsudo systemctl enable clickhouse-serversudo service clickhouse-server statusclickhouse-client
```
