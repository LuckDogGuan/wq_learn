## 因子简介

钱德动量摆动指标（Chande Momentum Oscillator, CMO）是由Tushar Chande在1994年提出的一种技术分析指标，用于衡量价格动量的强度。CMO通过计算一段时间内价格上涨和下跌的累积差值，来判断市场的超买或超卖状态。CMO的取值范围在-100到+100之间，数值越高表示市场动量越强，数值越低表示市场动量越弱。CMO常用于识别趋势的强度和潜在的反转点。

## 因子复现

以下是将钱德动量摆动指标（CMO）因子转化为WorldQuant Brain代码的实现：

```
cz1 = if_else(close - ts_delay(close, 1) > 0, close - ts_delay(close, 1), 0)cz2 = if_else(close - ts_delay(close, 1) < 0, abs(close - ts_delay(close, 1)), 0)su = ts_sum(cz1, 20)sd = ts_sum(cz2, 20)cmo = (su - sd) / (su + sd) * 100-group_rank(cmo, industry)
```

### 代码解析

cz1: 计算当日收盘价与前一日收盘价的差值，如果差值为正，则取该差值，否则取0。
cz2: 计算当日收盘价与前一日收盘价的差值，如果差值为负，则取该差值的绝对值，否则取0。
su: 计算过去20天内所有正差值的累积和。
sd: 计算过去20天内所有负差值的累积和。
cmo: 计算钱德动量摆动指标，公式为 (su - sd) / (su + sd) * 100，结果范围在-100到+100之间。
-group_rank(cmo, industry): 对CMO指标进行行业内排序，并取负值，以便在策略中使用。

### 评论 #2 (作者: XL31477, 时间: 1年前)

[BA51127](/hc/en-us/profiles/8958551180311-BA51127)  大佬问得好啊，关于CMO与其他动量因子结合使用以及它在不同市场周期的表现，确实是很值得探讨的问题。

先说CMO与其他动量因子结合吧，像价格动量（Price Momentum）和成交量加权平均价格（VWAP）等因子，和CMO结合起来是有不少好处的。比如说结合价格动量，价格动量主要是看价格在一段时间内的涨跌幅度来判断趋势，而CMO则是通过计算上涨和下跌的累积差值来衡量动量强度，两者结合可以从不同角度捕捉市场的趋势和强度变化，有可能提高策略的准确性和稳定性。再比如和VWAP结合，VWAP反映了市场在一段时间内的平均交易成本，当价格高于VWAP时市场可能强势，低于时可能弱势，结合CMO后，可以更全面地判断市场的超买超卖状态以及趋势的可持续性，比如当CMO显示超买且价格高于VWAP时，可能预示着市场短期内回调的风险较大 。

再说说CMO在不同市场周期的表现。在牛市中，市场整体向上，价格上涨趋势明显，CMO的值通常会比较高，能够很好地捕捉到这种上涨动量，帮助我们筛选出强势的股票，从而获得较好的收益。不过呢，也得注意牛市中的回调风险，不能仅仅依赖CMO，还得结合其他指标和风险控制手段。在熊市中，市场下跌趋势为主，CMO的值一般会比较低甚至为负，这时候它能帮助我们识别出那些下跌动量较强的股票，以便及时规避风险。但如果市场出现短暂的反弹，CMO可能会出现一些误判，所以在熊市中使用CMO也需要结合其他因素综合判断。而在震荡市中，市场缺乏明确的方向，价格波动较小，CMO的值会在0附近波动，这时候它的信号可能会比较频繁且不太稳定，容易产生错误的交易信号，导致交易成本增加和收益受损.
