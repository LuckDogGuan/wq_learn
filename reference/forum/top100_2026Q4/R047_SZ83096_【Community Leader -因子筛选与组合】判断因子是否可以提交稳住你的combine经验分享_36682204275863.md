## 帖子正文

分享下我判断因子是否值得提交的一些经验，希望小伙伴们能有所收获。

一个因子值不值得提交，一个是看因子本身的指标，一个是对组合的增益情况。

对我个人而言，后者的重要性一般会大于因子本身的指标（这是在 **因子指标合格的情况下** 的）；

一般很难找到所有指标对performance都是正面明显的。所以你需要在各个指标之间权衡。

## 根据is performance 的正负面影响判断：

### 可提交的情况

1. fitness 是排首位的，一般fitness有明显增益，margin和sharpe的增益不明显，或者稍微一点负面影响，我会选择提交；
2. 95%的情况下，fitness 对最近3-5年 的performance 有明显的负面影响（比如-0.1），不提交;
3. sharpe 和fitness,margin有增益，但是returns稍微有些负面影响，提交；

![图片](../images/img_3cb48ccb4b.png)

### 什么情况下不会提交：

1、margin不符合地区的最低要求，不提交

3、fitness 最近几年明显负面影响，不提交( 超过1个年份<-0.1)

4、sharpe  最近几年明显负面影响 ，不提交( 超过1个年份 <-0.1)

3、多个指标对组合负面明显过大，即使自相关性低，也不提交

很难一一列举对performance 影响的所有情况，是否提交这个因子，根据组合影响，个人情况判断。

### 从因子本身的指标来看：

1、sharpe>=1 ,fitness>=0.6 的前提下

margin 必须达到各地区margin要求的最低标准，我一般要求比最低标准高万分之五（USA，eur）,glb和ASI 地区的margin有时候比较难找到超过15的，在没有选择的情况下，一般ASI 最低14，15；GLB 14，15（少部分情况下会只要求>10【点塔】）

2、pnl线的波动比较小，向上，sharpe线 **不往下走；**

3、ASI 地区 还会观察下jpn的表现，如果jpn明显表现不佳或者或者kor表现明显大于其他地区的表现，不会提交

以上是我个人的一些经验，可能考虑还欠缺一些其他的点， **如果小伙伴有其他好的 判断方法，期待你评论区的分享**

**如果想要保证combine 的稳定，我个人的经验是 绝对不要提交margin不合格、fitness 负面影响过大、最近3年sharpe 线明显下降，pnl趋于厂 的因子（个人经验）**

**最后，给大家看看我现在的combine 情况，希望国区顾问的combine 都能保持稳定增长。**

### 评论 #39 (作者: ZZ47696, 时间: 2个月前)

感谢分享，这套判据我们在 GLB 高换手线上做了大量实测，正好可以给帖子里两条经验补上量化证据，供后来者少走弯路。

**一、「最近 3 年 sharpe 明显下降的不要提交」在平台上有对应的硬闸门：LOW_2Y_SHARPE。** 

需要提醒的是，IS 面板零 FAIL 并不等于能提交 —— 我们有 6 条 alpha 在 IS 面板上零 FAIL，但直接调  `GET /alphas/{id}/check`  后全部出现 FAIL， **IS 里的 WARNING 会在 /check 口径下升级为 FAIL** 。其中 LOW_2Y_SHARPE 是 6/6 的共同阻塞项，实测阈值大约要 1.55 才轻松过。所以楼主凭 pnl 曲线判断的经验，其实和平台的 2Y 检查是同一件事，只是平台把它量化了。

**二、「靠压换手去凑 margin」恰恰会制造楼主说的那种「近几年 sharpe 下降」的因子。** 

我们用  `ts_target_tvr_decay(EXPR, target_tvr=0.22)`  做了 13 条降换手探针（GLB / TOPDIV3000 / delay1），结论比较统一：

- **margin 提升是次线性的** ：换手砍到 1/2.29（0.67 → 0.21），margin 只涨到 1.53 倍（4.22bp → 6.46bp）。想从 4bp 冲到 7bp，Tvr 得压到 0.21 附近。
- **2Y 是 100% 的代价** ：13 条探针 LOW_2Y_SHARPE 全部 FAIL，缩窗（120 / 180 / 250）无一例外。同一个内核不降换手时 2Y 是 PASS 的（S=2.62 / F=1.12 / 零 FAIL），套上降换手后 Sharpe 掉到 1.0~1.21、2Y 掉到 0.49~0.82。也就是说降换手不是在「优化」，是在把一个 2Y 健康的因子改造成 2Y 不健康的因子。

**三、margin 和另外两个指标在中性化维度上是对立的（同一表达式、只换 neutralization 的对照）：**

- `COUNTRY` ：margin 4.7bp →  **8.75bp（+86%）** ，但 PROD_CORRELATION 从 0.65 顶到  **0.777（FAIL）** ；
- `STATISTICAL` ：PROD_CORRELATION 最优（0.658~0.661）、Fitness 也最高（1.14~1.18），但 margin 只有 4.6~4.8bp；
- `SUBINDUSTRY` ：居中，margin 6.7~6.9bp / PC 0.653~0.665。

所以「margin 达标」和「PC < 0.7」在这条线上要分两步拿，指望一个中性化维度同时满足基本不现实。

**四、一个几乎零代价的小工具： `signed_power(x, 0.5)` 。** 

同配置严格对照（只加这一层），五项指标同时改善：2Y 0.91 → 1.02（+0.11）、PROD_CORR 0.777 → 0.743（−0.034）、Fitness 1.18 → 1.24、margin 8.75 → 8.96bp、Sharpe 1.78 → 1.85。指数取 0.5 比 0.7 稳，这点和论坛里其他同学的实测一致。

**五、一条踩坑提醒：truncation 不一定 binding。** 

我们按「调低 truncation 修 2Y」的思路做了双向对照（0.005 / 0.01 / 0.03），三点结果 **逐位完全相同** ——在 COUNTRY 中性化 + 降换手之后权重分布已经足够分散，截断根本没起作用。所以调 truncation 之前建议先做个双向对照，确认它真的在生效，否则会白白消耗仿真格子。

另外想请教楼主一个口径问题：您提到 GLB 的 margin 一般要求 14~15bp（点塔部分场景 >10）。我们在高换手主题（HTVR）这条线上观察到的 margin 水位要低得多，国区已提交的该主题 alpha 平均 margin 约 3.36bp、中位 2.61bp。想确认一下： **14~15bp 这条线是针对普通 PPA 提交的，主题/比赛线是否另有更低的口径？** 如果是两套标准，建议大家在筛选时先明确自己走的是哪条线，免得用错标准把好因子筛掉、或者把不该交的交上去。
