# 因子模板：风险 / 波动 / 流动性

## 为什么这样变换

风险字段会被规模、行业和市场状态影响。先计算波动、换手或风险调整收益，再按行业或规模桶中性化，才能得到可比较的风险信号。

## 变成什么样子

| 模板 | 变换结果 |
|---|---|
| `ts_std_dev(returns,20)` | 近期实现波动。 |
| `ts_mean(returns,20)/ts_std_dev(returns,20)` | 短期风险调整收益。 |
| `volume/sharesout` | 换手率。 |
| `ts_corr(volume/sharesout,abs(returns),10)` | 换手与波动联动。 |
| `group_neutralize(ts_std_dev(returns,20),bucket(rank(cap),range="0,1,0.1"))` | 规模中性波动。 |
| `trade_when(ts_rank(ts_std_dev(returns,10),252)<0.9,{A},-1)` | 避开极端波动后的可交易信号。 |

## 论坛补充：小而稳、流动性与成本

| 评分 | 模板 | 经济学解释 | 建议参数 |
|---:|---|---|---|
| 5 | `-rank(ts_mean(volume/sharesout,20))-rank(ts_std_dev(volume/sharesout,20))` | 低换手且换手稳定，通常意味着较低交易摩擦和拥挤度。 | 窗口 `10/20/60`；分 `TOP3000/TOP1000/TOP500` 检查。 |
| 4 | `ts_zscore(volume/sharesout,60)` | 个股自身换手异常，反映注意力冲击或拥挤变化。 | `20/60/120`；方向不要预设。 |
| 4 | `-ts_corr(volume/sharesout,abs(returns),20)` | 换手与波动的关系可区分流动性吸收和价格冲击。 | `10/20/60`；只作辅助信号。 |
| 4 | `group_neutralize(ts_std_dev(returns,20),bucket(rank(cap),range="0,1,0.1"))` | 去除规模对波动和交易成本的机械影响。 | 规模桶 `5/10/20` 组；对比行业中性。 |
| 4 | `ts_rank(ts_std_dev(returns,10),252)` | 近期波动处于自身历史高位，代表风险状态切换。 | `10/20` 波动窗口，`126/252/504` 历史窗口。 |
| 3 | `ts_mean(returns,20)/ts_std_dev(returns,20)` | 短期风险调整收益，兼顾方向和稳定性。 | `20/60/120`；检查是否只是低波动暴露。 |

## 论坛参数提示

台湾第一的高赞 After Cost Performance 经验强调：不能只看平均 turnover，还要看最大日 turnover；可以用 `trade_when`、`hump`、`ts_target_tvr_delta_limit`、`ts_delta_limit` 控制峰值。覆盖率应优先在流动性较好的股票中检查，不能让 short count 明显压过 long count。上述建议是成本和稳健性检查，不是因子方向本身。
