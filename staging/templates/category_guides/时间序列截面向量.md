# 因子模板：时间序列 / 截面 / 向量

## 为什么这样变换

原始字段不可直接比较。时间序列算子提取趋势和异常，截面算子提取相对位置，向量算子把多值字段压成可计算标量，最后用中性化减少共同暴露。

## 变成什么样子

| 模板 | 变换结果 |
|---|---|
| `ts_zscore({F},252)` | 历史标准化信号。 |
| `ts_rank({F},252)` | 历史相对位置。 |
| `ts_regression(ts_zscore({A},500),ts_step(1),500,rettype=2)` | 滚动趋势斜率。 |
| `ts_corr(rank({A}),rank({B}),20)` | 两字段的动态联动。 |
| `vec_avg({VECTOR})` | 向量字段的均值信号。 |
| `group_neutralize({A},sector)` | 去行业暴露后的信号。 |
| `regression_neut(regression_neut({A},{B}),{C})` | 分层回归残差。 |

## 论坛补充：同向极值匹配

贺六浑的高赞帖子给出了一个比“向量一律用 `vec_avg`/`vec_sum`”更具体的规则：外层要找最小值时，内层优先使用 `vec_min`；外层要找最大值时，内层优先使用 `vec_max`。逻辑是避免内层平均或求和稀释外层要捕捉的极值。

| 评分 | 模板 | 适用逻辑 | 建议参数 |
|---:|---|---|---|
| 5 | `ts_min(vec_min({VECTOR}),d)` | 向量中的最小值在过去窗口的最低状态。 | `d=20/60/120`。 |
| 5 | `ts_max(vec_max({VECTOR}),d)` | 向量中的最大值在过去窗口的最高状态。 | `d=20/60/120`。 |
| 4 | `ts_arg_min(vec_min({VECTOR}),d)` | 最低信息出现距今的时间位置。 | `d=60/120/252`。 |
| 4 | `ts_arg_max(vec_max({VECTOR}),d)` | 最高信息出现距今的时间位置。 | `d=60/120/252`。 |
| 3 | `ts_max({F},d)-ts_min({F},d)` | 历史区间宽度，刻画信息/价格波动范围。 | `d=20/60/120`；注意不是方向信号。 |

帖子中的单变量对比在 USA/TOP3000、Fast Expression、Delay 1、Decay 0、Truncation 0.08、Neutralization Fast 的截图中，`vec_min` 版本 Sharpe 1.81、Fitness 1.05，高于 `vec_avg` 的 1.71/0.96 和 `vec_sum` 的 1.73/0.98；这是原帖样本，不是当前账户复现结果。

## 二阶变化

`ts_delta(ts_delta({F},d),d)` 可作为小虎模板保留。`d=5` 是帖子示例；字段更新频率较慢时应改为 `20/63/126/252`，并同时检查 PnL 衰减和样本外稳定性。
