# 第二季度 Alpha 挖掘思路经验总结

*本总结基于 WQ 论坛资深玩家的分享提炼，旨在提供高效率、高转化率的挖掘方法论。*

## 核心指导思想：先筛数据再干活，拒绝盲目试错

### 1. 数据集勘探（重中之重）
每天开始干活前，请先用 **30 分钟** 勘探数据。
- 借助工具（如华子哥插件或网页提交热度图）寻找提交多、通过率高的“绿色”优质数据集。
- 也可以反向思考，寻找冷门、竞争少的新数据集/宇宙，相关性往往更低。
- **一旦在某个数据集上跑了几万次回测，发现出货极低（用我们的可视化直方图看发现 sharpe 几乎都在 0 附近），必须立即止损换数据，绝不头铁。**

### 2. 回归本源：0 阶信号是稳定出货的基石
很多新手喜欢一上来就用极度复杂的算子去“堆”出高 Sharpe，但 **80% 稳定出货并在 OS 和 PPA 表现坚挺的因子，都源自 0 阶原始信号**。
- **什么是 0 阶模板？**
  - 最原始的字段清洗去极值
  - 简单的 `rank(field)` 或 `ts_rank(field, 5)`
  - 两个强逻辑相关字段的除法/差值运算：`field_A / field_B`
- **实战打法**：对每个新数据集，直接把所有字段套入纯 0 阶模板批量跑一遍，挑出 `Sharpe > 0.8`、`Fitness > 0.5` 的字段建立你的**【种子字段库】**。

### 3. AI 的正确使用边界
AI 是提效神器，但不是万能药。AI 缺乏金融直觉，很容易陷入过度拟合。
- **正确用法**：
  - 让 AI 基于数据集描述，生成有经济学逻辑解释的 0 阶基础信号。
  - **参数调优**：用 AI 写脚本，在合理范围内对你的优质 0 阶因子做参数网格遍历（例如搜索最佳的时间窗口大小、中性化条件）。
  - **噪声过滤**：让 AI 帮忙加入流动性过滤或异常值剔除等常规手段。
- **错误用法**：
  - 盲目相信 AI 生成的复杂长公式，大概率是过拟合。

### 4. 高阶模板的定位
1阶、2阶、3阶模板并不是用来无中生有的，它们是**“信号放大器”**。
- 只有你的 0 阶种子信号足够优秀干净，套入 1/2/3 阶模板后，才能放大出符合 PPA 或高要求 RA 的优质因子。
- 用垃圾字段套入 3 阶模板，只是在放大噪音。

### 5. 聚焦与深耕
- 建议在一个月内，将精力聚焦在 **2 ~ 3 个国家地区** 进行深耕。
- 频繁跨区会带来极大的中性化环境切换噪音，也不利于你建立该地区的专属“种子字段库”。

### 6. 手搓与反思
- 每天花 1 小时手动构造和修正 Alpha。
- 理解每一个成功因子的经济逻辑，明白它为什么赚钱。这不仅能提高命中率，还能应对未来平台规则的变化。
- **宁缺毋滥**：不要因为焦虑去提交大量勉强及格的垃圾 RA，这会极大降低你的过审优先级。严格把关提交质量（例如利用 Prod 相关性检测器卡死相关性）。
