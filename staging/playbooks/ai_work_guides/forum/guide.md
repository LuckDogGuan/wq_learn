# 指引：论坛浏览与贡献

## 用途
逛论坛、搜索帖子、阅读、发帖 / 评论 / 点赞（贡献）。

## 最少路径
- 搜索：`search_specific_forum_fast`（中文论坛默认 topic `12913416465431`）；结果少时 `search_all_forum_slow`。
- 浏览 / 发现：`list_forum_topics`、`list_forum_posts_in_topic`、`list_help_center_articles`。
- 读帖：`read_forum_post` / `read_full_forum_post`。
- 贡献（写）：`create_forum_comment` / `create_forum_post` / `upvote_forum_comment`。

## 限制
- 论坛信息一律以 MCP 读取为准，禁止编造帖 / 评论 / 投票。
- 帖子正文用论坛原生 HTML（非 Markdown）；中文撰写。
- 写操作（发帖 / 评论 / 点赞）必须先经用户确认。
- 删除类操作（`delete_forum_*`）非必要不使用。
