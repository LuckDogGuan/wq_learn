## 四、10 大参数化通用模板

基于 1541 个通关因子的公式结构聚类分析，归纳出以下 10 个高效通用模板：

### T01 子行业截面 ZScore 模板

**公式结构：**
```
group_zscore($signal_field, subindustry)
```
- **描述**：在子行业截面做 Z-Score 标准化，是消除行业效应最干净的方式
- **推荐参数**：neutralization=MARKET/SUBINDUSTRY, decay=4-8, truncation=0.01-0.05
- **适用地区**：EUR, GBR, USA
- **推荐数据类型**：Analyst/Fundamental 字段（预测值、意外度等）
- **历史效果**：avg Sharpe ~2.0-3.5
- **实例数量**：通关因子中有 126 个类似结构

### T02 时序 Rank + 子行业中性 模板

**公式结构：**
```
group_rank(ts_rank($signal_field, $window), subindustry)
```
- **描述**：先做时序排名再做子行业截面排名，双重标准化，信号稳定
- **推荐参数**：window=20-60, decay=0-5, neutralization=SUBINDUSTRY/FAST
- **适用地区**：EUR+TOP2500, USA+TOP2000
- **推荐数据类型**：PV 字段（volume, turnover_ratio, close 等）
- **历史效果**：avg Sharpe ~2.0-4.0
- **实例数量**：通关因子中有 0 个类似结构

### T03 时序衰减平滑模板

**公式结构：**
```
ts_decay_linear($signal_expr, $decay_window)
```
- **描述**：对信号做线性衰减平滑，降低换手率，提升 Sharpe_2Y 稳定性
- **推荐参数**：decay_window=5-20, neutralization=INDUSTRY/SUBINDUSTRY
- **适用地区**：所有地区通用
- **推荐数据类型**：任何高频信号字段
- **历史效果**：降低 TO 50%，损失 Sharpe 约 0.1-0.2
- **实例数量**：通关因子中有 353 个类似结构

### T04 多因子加权组合模板

**公式结构：**
```
$weight1 * group_zscore($field1, subindustry) + $weight2 * group_zscore($field2, subindustry)
```
- **描述**：两个信号在子行业截面标准化后加权合并，降低相关性
- **推荐参数**：weight1=0.5-0.8, weight2=0.2-0.5, decay=4-8
- **适用地区**：EUR, USA
- **推荐数据类型**：Analyst 字段 + PV 字段（常见组合）
- **历史效果**：avg Sharpe ~2.5-4.0（组合效应提升约 0.3-0.8）
- **实例数量**：通关因子中有 4 个类似结构

### T05 国家截面排名模板

**公式结构：**
```
group_rank($ts_signal, country)
```
- **描述**：在国家截面做排名，消除国家效应，适合全球因子
- **推荐参数**：neutralization=MARKET/NONE, decay=0-8
- **适用地区**：GLB, EUR（多国市场）
- **推荐数据类型**：任何跨国可比字段
- **历史效果**：GLB 场景 avg Sharpe ~1.8-3.0
- **实例数量**：通关因子中有 22 个类似结构

### T06 时序动量 + 截面排名模板

**公式结构：**
```
rank(ts_sum($return_field, $window) / ts_std_dev($return_field, $window))
```
- **描述**：时序 Sharpe 比率（信息比率）做截面排名，经典动量信号
- **推荐参数**：window=20-60, decay=0-5, neutralization=SUBINDUSTRY
- **适用地区**：EUR+TOP2500, USA+TOP2000
- **推荐数据类型**：returns / ret 相关字段
- **历史效果**：avg Sharpe ~1.8-3.0
- **实例数量**：通关因子中有 0 个类似结构

### T07 分析师预测意外度模板

**公式结构：**
```
group_zscore(($actual_field - $estimate_field) / $abs_estimate, subindustry)
```
- **描述**：标准化的分析师预测意外度（Earnings Surprise），在子行业截面归一化
- **推荐参数**：neutralization=SUBINDUSTRY/INDUSTRY, decay=0-5
- **适用地区**：EUR, USA, GBR
- **推荐数据类型**：Analyst 数据集字段（actual vs estimate）
- **历史效果**：avg Sharpe ~2.0-3.5
- **实例数量**：通关因子中有 0 个类似结构

### T08 成交量正交化辅助模板

**公式结构：**
```
$main_signal + $alpha * group_rank(ts_rank($volume_field, $vol_window), subindustry)
```
- **描述**：在主信号中加入成交量正交化成分，降低集中度和生产相关性
- **推荐参数**：alpha=0.1-0.3, vol_window=20-50, neutralization=SUBINDUSTRY
- **适用地区**：GBR, EUR（易集中度失败的市场）
- **推荐数据类型**：主信号任意 + volume/turnover_ratio
- **历史效果**：帮助通过 CONCENTRATED_WEIGHT 检验，Sharpe 略降 0.05-0.1
- **实例数量**：通关因子中有 45 个类似结构

### T09 时序 Delta 反转模板

**公式结构：**
```
-1 * group_zscore(ts_delta($signal_field, $window), subindustry)
```
- **描述**：信号变化量的反转（均值回归），需配合足够 Decay 控制换手率
- **推荐参数**：window=5-20, decay=8-20, neutralization=SUBINDUSTRY
- **适用地区**：EUR, GLB
- **推荐数据类型**：Fundamental/Analyst 的变化量字段
