# 静态隔离与待验证代码的边界

审计日期：2026-10-12。`forum_blocks.json` 保存代码及来源，不删除原帖或旧模板。`EXCLUDED_STATIC` 表示当前研究规则不允许直接进入轮动，不表示收益失败、字段无价值、管理员错误或正式黑名单。

当前盘点 3768 个去重代码块中，2655 个有一项或多项静态隔离理由，1113 个暂未命中扫描规则而标为 `UNVALIDATED`。一个块可同时命中多项理由，分类计数不能直接相加。数量以同层上级 `inventory_summary.json` 为准。

扩展扫描覆盖全部 2598 篇源文件，原始哈希全数复核未变。新 `full_scan_excluded.json` 保存 74310 个严格检查未通过实例及其单条原因；224 个不同骨架、966 个出处实例仅获得 `LOCAL_PASS_UNVALIDATED`，见上级 `admin_verified_catalog.json`。新扫描包含非围栏及嵌套 JSON，所以计数口径与原 3768 围栏去重块不同。新工具另行采用严格总算子检查、词汇交集、单字段证明、本地 validator 和独立 AST 参数域检查，原始静态两份目录保留作历史审计输入。

## 当前自动分类并不覆盖所有上述类别

工具 `Core/tools/forum_template_audit.py` 当前只自动检查禁用函数、函数调用数、括号/花括号计数、部分 Python/NLP 特征和若干数据家族前缀。因此：

- 论坛目录的函数调用次数没有包含算术、比较和一元负号，也不是平台 operator count；新管理员实现已另行使用保守总计函数。PEG 防护版本总数 8，已在注册表 `enabled=False` 隔离；六个启用模板生成候选时检查总计 `<6`，仍需平台实际验证。
- 未命中这些正则规则的自然语言、JSON、未知函数、权限问题、零信号或语义错误仍可能在 `unvalidated_blocks.json`；该文件不是可执行白名单。
- 跨数据集检查可能漏掉通用价量字段，也可能将前缀误认成不同数据集，需真实元数据复核。
- 括号数量相等不能保证嵌套、参数、类型或语法有效；无围栏公式不会自动提取。
- 目录关系只记录帖子关系，BODY/COMMENT 只记录章节；评论作者及转载来源仍需读取原帖。管理员发表合集、管理员回复或关联帖都不能推定代码原创。

每条代码保留 `source/post_id/line/section/relation/block_index/block_sha256/origins`，可返回源帖复核。去重基于空白规范化文本 SHA256，无法代替 AST 等价或策略风格去重。正文与评论的历史收益叙述是作者自述，缺少当前完整指标和实时检查证据。

## 旧模板保留登记

`forum_advanced_solutions.resolve_reversion_component` 是原样返回输入的 no-op；`apply_rank_by_side_and_diff` 有历史权限提醒；`pc_control_rank_by_side_wrapper` 第二参数签名与本地 validator 不一致；内外中性化辅助函数只返回建议设置。它们均保留，不能自动进入管理员模板轮动，也不能由函数名推断功能或收益成立。详见上级模板目录 `README.md` 登记表。

真正淘汰字段/数据集只使用 `总结/优化复盘_20260802/操作符_字段黑名单登记表.md` 和规定的有效样本证据。此处隔离没有形成 `FIELD_VERDICT=GARBAGE_CANDIDATE` 或 `DATASET_VERDICT=STOP_DATASET`。`PENDING/RESULTS_UNOBSERVED`、429、超时、认证失败、无 Alpha ID、响应不完整不能当作失败样本，更不能当作通过。恢复实验须读取 `总结/active/` 并只读对账，禁止重建已记录批次。
